# 知行 ZhiXing 密码助手（浏览器扩展）

在你**按下网站的登录按钮**时，把该表单的账号密码交给本机的知行应用保存。

## 它不是键盘记录器

这一点决定了这个扩展要什么权限：

| | 全局键盘钩子 | 这个扩展 |
| --- | --- | --- |
| 能看到什么 | 你在**任何程序**里敲的**每一个键** | 只在你提交某个网站的表单时，读到**那个表单**的两个输入框 |
| 权限 | 系统级、需要原生模块、杀软报毒 | 普通扩展权限 + 访问 `127.0.0.1` |
| 数据去向 | —— | 只发到 `http://127.0.0.1`，不联网 |

`content.js` 是普通的页面脚本，拿不到别的标签页、别的窗口、别的应用里的任何东西。

## 安装

未上架商店，用开发者模式加载：

1. Chrome 打开 `chrome://extensions/`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录

## 配置

1. 打开知行 ZhiXing 桌面应用
2. 进入「保险箱」，解锁后点右下角的「连接浏览器」
3. 复制显示的令牌
4. 在扩展的「详细信息 → 扩展程序选项」里粘贴令牌并保存
5. 点「测试连接」应显示端口

## 工作原理

```
网页表单提交
   ↓ content.js 读到用户名与密码
background.js
   ↓ 扫描 127.0.0.1:47821–47830，用 /vault/ping 确认对面是知行
   ↓ POST /vault/capture   带 x-vault-token
桌面应用
   ↓ 校验令牌；**保险箱锁定时拒收（423）**
   ↓ 按主机名建条目（已存在则更新），用保险箱密钥加密后落库
```

## 几个设计决定

**端口固定 + 扫描一段**：桌面应用原先用 `listen(0)` 让系统分配端口，但扩展没法知道随机端口。现在应用默认起在 47821，被占用就顺延；扩展扫描 47821–47830，并用 `/vault/ping` 确认对面确实是知行（而不是别的程序占了这个端口）。

**锁定时拒收凭据**：返回 `423 Locked`。如果锁定时还接收，那就等于绕过了主密码。

**同站点更新而不是新建**：按主机名找已有条目，命中就更新账号密码，避免反复登录堆出一串重复项。

**令牌**：任何本机程序都能访问 `127.0.0.1`，所以写入类端点要令牌。令牌只显示在应用设置页里，由用户手动粘贴一次。它不是主密码 —— 拿到只能往保险箱里**写**，且锁定状态下写不进去。

## 已知限制

- **只能捕获登录表单**：注册页、改密码页填的密码不会被记录（那时你还没点登录）
- **拿不到已经保存过的旧密码**：那部分用「从 Chrome 导入」功能
- **未上架商店**：需要开发者模式手动加载

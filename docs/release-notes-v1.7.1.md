本地优先的个人待办 + 知识图谱桌面端（Windows x64）。数据只存在本机的一只 SQLite 文件里：无需注册账号，不联网也能完整使用。

### 本版要点：提醒什么时候提醒、提醒几次，都能自己定

设置 → 任务与提醒里新增一组「提醒策略」（「到点提醒」打开后可见）：

- **提前提醒**：按「截止时刻 − 提前量」触发。填 30 就是提前半小时叫你，填 0 则到点才提醒。
  只对**没有手动设过提醒时刻**的任务生效 —— 手动设过的一律以手动为准（在任务编辑面板里设的那个时刻）。
- **哪些任务自动提醒**（两个开关 + 一个下限）：
  - *有截止时刻的任务* —— 默认开。写了具体时刻本就是要人提醒。
  - *只有截止日期的任务当天提醒* —— 默认关，并可指定当天几点。**刻意默认关**：打开它等于把每一条「只有截止日期」的历史任务都变成提醒，升级那一刻会弹出一堆。要用请自己开。
  - *只自动提醒优先级 ≥ N* —— 0 表示不限；只筛自动提醒，手动设的提醒不受影响。
- **提醒次数与间隔**：同一条任务最多提醒几次、每次隔多久。默认「1 次」，即与之前完全一致。
  点「知道了」或「查看」即视为处理过，不再重复；改掉截止时间会重新开始计数。

### 另外两处

- **到点提醒的卡片与删除确认、捕获面板这些弹框现在是同一张卡片**（同一套圆角 / 描边 / 底色），换主题一起变。
- **修复：悬浮表情的提醒气泡此前不跟随主题。** 气泡跑在独立窗口里，没有应用当前主题 —— 主窗口是浅色、气泡却是深色。

### 兼容性

- 数据库仍是 schema v12；新增的两列（提醒次数的记账）由初始化逻辑自动补齐，无需迁移。
- 升级安装不会动你的数据；默认设置下提醒行为与本版之前**完全一致**。

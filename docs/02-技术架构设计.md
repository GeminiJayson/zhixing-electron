## 1. 技术选型

| 层 | 选择 | 理由 | 备选（否决理由） |
| --- | --- | --- | --- |
| 语言 | Python 3.11+ | 开发效率；既有 PySide6 技能栈 | C++（迭代慢，个人项目不必要） |
| GUI | PySide6 (Qt 6.x) | 用户指定；官方绑定、LGPL | PyQt6（GPL/商业双协议麻烦） |
| **架构模式** | **MVC（Qt Model/View 语义）** | 界面与数据彻底解耦；Qt 的 QAbstractItemModel 天然承载 M-V；见 §2 | MVP/MVVM（PySide6 生态无成熟绑定框架，收益低） |
| UI 组件库 | **PySide6-Fluent-Widgets (qfluentwidgets)** | 纯 Python、Fluent 2 设计、组件全（NavigationInterface、InfoBar、Flyout、主题引擎）、中文文档友好 | FluentQt C++ 绑定（Python 生态不成熟）；Qt Quick（QML 学习成本） |
| 存储 | SQLite 3（WAL 模式） | 单文件、零运维、事务安全、FTS5 全文检索 | JSON 文件（无事务/查询能力）、PostgreSQL（过重） |
| ORM | SQLAlchemy 2.0 | 成熟、可写原生 SQL 兜底 | peewee（FTS/迁移生态弱）；裸 sqlite3（模型同步易错） |
| 全文检索 | SQLite FTS5 | 内置零依赖 | Whoosh（项目停滞）、Tantivy（需额外二进制） |
| 图谱渲染 | QGraphicsView 自绘 | 原生流畅、无重依赖、可控交互 | QWebEngineView+ECharts（+100MB 包体、内存高） |
| 统计图表 | QtCharts（PySide6 自带） | 零依赖、够用 | pyqtgraph（科学风不搭） |
| **图标** | **QtSvg + 自研 SvgIconEngine** | 单一 SVG 图标族、运行时按主题 token 着色、高分屏无损 | 位图多套切图（主题换色需重出图）；emoji（不可着色） |
| 全局热键/划词 | macOS: pyobjc(Quartz) · Windows: ctypes | 模拟复制读剪贴板，跨平台一致 | Accessibility 读选区（平台差异大、实现重） |
| 打包 | PyInstaller（onedir） | 成熟 | Nuitka（编译慢） |

> 中文检索：FTS5 默认分词对中文不友好。方案：入库分词用 **jieba**（可选依赖，缺省回退按字切分），并评估 `trigram` tokenizer，见 §12 ADR-3。

## 2. MVC 架构 ⭐

```
┌──────────────────────────────────────────────────────────────────┐
│ C  controller/   编排层：把用户输入翻译为对 Model 的调用，           │
│                  把 Model 事件路由到 View                          │
│   AppController（装配/导航/托盘/全局热键/划词与快速捕获编排/          │
│                  浮窗显隐联动/任务笔记快捷编辑/撤销/主题提醒备份生命周期）│
│   PomodoroController（番茄钟状态机 + 悬浮条）                        │
└───────────▲──────────────────────────────────┬───────────────────┘
     信号/调用│                                  │调用
┌───────────┴──────────────────────────────────▼───────────────────┐
│ V  view/         纯展示：页面、弹层、delegate、浮窗、捕获卡          │
│    view/kit/     共享视觉：icons(SVG图标) theme(主题) motion(动效)  │
│    规约：不 import domain/application，不写业务规则                 │
└───────────▲──────────────────────────────────────────────────────┘
     Qt Model/View 协议（dataChanged/layoutChanged…）
┌───────────┴──────────────────────────────────────────────────────┐
│ M  model/                                                        │
│   model/qt/            QAbstractListModel/TreeModel 子类 +        │
│                        QSortFilterProxyModel（TaskListModel 等）  │
│   model/application/   Service：task/note/flash/capture/graph/…  │
│   model/domain/        实体+业务规则（纯 Python，无 Qt，可单测）    │
│   model/infrastructure/ repositories(SQLAlchemy)/fts/hotkey/     │
│                        selection/backup/exporter/importer        │
└──────────────────────────────────────────────────────────────────┘
主数据流：View(信号) → Controller → Service → Repository → SQLite
刷新流：  Service → EventBus(领域事件) → Model 发 Qt 信号 → View 自动刷新
```

**MVC 规约（代码评审硬标准）**

1. **View 无业务**：`view/` 禁止 import `model.domain/application`；视图状态（选中、滚动、展开）也由 Controller 经 Model 管理。
2. **Controller 薄**：只做编排（校验转发、目标选择、导航、跨页联动），不写业务规则；规则一律下沉 `model/domain`。
3. **Qt Model/View 承载列表与树**：任务树 = `TaskTreeModel(QAbstractItemModel)`（直接装载「根任务 → 子任务」，reload 时一次性算好 `effective_done_map` roll-up 缓存，供 `RoleChecked`/`RoleOverdue` 及 delegate 使用）；笔记树 = `NoteTreeModel`（`view/note_tree.py`，文件夹父节点 + 笔记子节点 + 顶层「全部笔记」，配 `NoteTreeFilterProxy` 与 `NoteTreeDelegate`）；任务/笔记/闪念列表 = ListModel + `QSortFilterProxyModel`（搜索过滤、排序复用 Qt 原生）；行内绘制（优先级 pill、时间范围 chip、标签 chip、循环/streak/笔记计数 chip、悬浮胶囊按钮）在 `view/delegates/` 与 `view/note_tree.py` 的 delegate 中，delegate 只画不判；日历单元格胶囊自绘在 `view/pages/task_page.py` 的 `TaskCalendarWidget`。
4. **domain 零 Qt**：`model/domain` 禁止 import Qt/SQLAlchemy，业务规则 100% 单测覆盖。
5. **EventBus 是 Model 内部的领域事件通道**（`task_changed`、`flash_added`、`theme_changed`…）；Qt Model 据此发射 `dataChanged`，Controller 只在需要跨页联动/导航时订阅。
6. **后台规则**：>100ms 的工作（FTS 重建、导出、图谱布局、备份、力导向迭代）进 `QThreadPool`，worker 带取消令牌；结果经信号回主线程。

## 4. 线程与生命周期规约

| 场景 | 方案 |
| --- | --- |
| 常规 CRUD | 主线程同步（SQLite 本地 < 5ms），不假装异步 |
| FTS 重建/导入导出/备份/布局 | QThreadPool worker，进度信号 → InfoBar/进度条；取消令牌 |
| 定时提醒 | 主线程 QTimer 轮询（30s 粒度）到期任务 → 托盘通知 |
| 番茄钟 | QTimer + 状态机（idle/focus/break）；主窗关闭缩浮窗时继续 |
| **全局热键** | macOS：pyobjc `AddEventTap`/Carbon HotKey 回调（主线程派发）；Windows：`RegisterHotKey` + `QAbstractNativeEventFilter` 处理 `WM_HOTKEY`；注册失败→提示改键→降级应用内快捷键 |
| **划词** | 热键 → AppController.start_word_capture() 编排 → 后台线程模拟 Cmd/Ctrl+C（CGEvent/SendInput）→ 300ms 超时保护 → 备份剪贴板→读取→恢复；不动用户前台焦点 |
| 浮窗 | 独立 `QWidget`（`FramelessWindowHint|WindowStaysOnTopHint|Tool`）+ AppController 显隐联动（主窗 showEvent/hideEvent 信号）；只订阅事件不轮询 |
| 窗口/页面 | 导航页面常驻缓存保留视图状态；一次性弹窗用完 `deleteLater`；信号连接持引用防 GC（PySide6 常见坑） |
| 关闭 | 记忆窗口/浮窗几何与状态落库；有后台 worker 先请求取消 |

## 5. 数据模型

```
list_folder(id, parent_id→list_folder, kind[group|list],
            name, icon, collapsed, sort)          # 任务归属列表（UI 不再渲染分组树侧栏，仍供收件箱/智能清单）
task(id, title, notes_md, status[.todo|doing|waiting|done|abandoned],   # waiting(v0.15)+resume_at
     priority[0..8], due_date, start_date,        # 0=NONE、1..8=P1..P8（v8 升 8 级）；截止 + 开始时间（start_date 由 v2 迁移新增）
     reminder_at,
     resume_at,                                   # v7：waiting 的「恢复于」日期（nullable，v0.15）
     list_id→list_folder, parent_id→task,         # 子任务（邻接表；父任务即“大任务组”）
     repeat_period[none|daily|weekly|monthly],     # 循环任务/循环子任务
     streak, last_reset_date,                      # 打卡连续次数与上次重置日
     sort_key, completed_at, deleted_at,
     created_at, updated_at)
note_folder(id, parent_id, name, sort)
note(id, folder_id, title, content_md, format,    # format: markdown|richtext|word|excel|link（v6 归一；word/excel/link 的 content_md 存本地文件路径或 URL）
     pinned, word_count, deleted_at, created_at, updated_at)
flash(id, content, remark, source_app, source_url,     # 闪念（划词/快速捕获零散知识）
      status[inbox|archived|converted], converted_type, converted_id,
      deleted_at, created_at)
tag(id, name UNIQUE, color)
task_tag / note_tag / flash_tag
task_note_link(id, task_id, note_id)
task_note_context(id, task_id, note_id, block_key, snippet, created_at,
                  UNIQUE(task_id, note_id, block_key))    # v7：任务↔笔记段落级关联（v0.15）
note_link(id, src_note_id, dst_note_id, dst_title)    # dst 可空=待建链接（拉线建链复用此表）
pomodoro_session(id, task_id, started_at, minutes, completed)
attachment(id, note_id, path, kind, created_at)
settings(key PK, value)    # 含 ui_state：展开状态集合、浮窗几何/透明度、捕获默认目标
schema_version(version)    # 现为 8（v6 起：word/excel/link 归一；v7：resume_at + task_note_context；v8：优先级 4 级→8 级）
FTS: note_fts / task_fts / flash_fts
```

要点：

- **循环子任务**：`repeat_period≠none` 的子任务由 `task_rules.roll_recurring_subtasks()` 在每日启动/跨天事件时重置为 `todo` 并累计 `streak`（打卡语义）。
- **完成 roll-up**：`task_rules.effective_done_map()` 为纯派生值（不落库）——无子任务看自身 `DONE/ABANDONED`；有子任务仅当所有后代（递归）有效完成才算完成。供今日/逾期/四象限/收件箱/概览/日历与 `TaskTreeModel._effective_done` 缓存共用。
- **今日待办规则**：`task_rules.today_roots()` = 顶层 + 有效未完成 + 未逾期（无截止/截止≥今天）；`TaskService.today_tree()` 在其上闭包保留每个根的完整后代。
- **笔记五类型**：`format=markdown` 存纯文本、`richtext` 存 HTML 片段（图片内嵌 base64 data URI）、`word`/`excel`/`link` 的 `content_md` 存本地文件路径或 URL；Word/Excel 经 python-docx/openpyxl 解析为只读 HTML、链接经 `QDesktopServices` 打开，共用 `NoteService` 与 `note_link` 管线。
- **展开状态**存 `settings.ui_state`（JSON 集合），不改任务表结构。
- **捕获默认目标**（最近使用的分组/父任务）存 `settings.ui_state`，实现「再次划词一键直达」。
- 排序用 `sort_key`，拖拽只改受影响行；note_link 允许悬空（待建链接）。
- **笔记文件夹（NoteFolder）**：`parent_id` 支持嵌套；`NoteService.move_folder` 提交前做祖先链回溯环路校验（拒绝挂到自身/子孙下）；`delete_folder` 时其下笔记（含软删）解除 `folder_id` 外键回落「全部笔记」、子文件夹 `parent_id` 上移一级（否则 FOREIGN KEY 约束失败）；`ensure_default_folder` 空时建默认「我的笔记」。
- **图谱节点 id 空间**（避免与实体主键冲突）：dangling `-1` 递减；flash `-id - 1_000_000`；folder `-id - 2_000_000`；**anchor（段落锚）`-id - 3_000_000`（v0.15）**；task `id + 5_000_000`；note 直接用主键。
- **任务状态五态与 WAITING**：`TaskStatus{todo,doing,waiting,done,abandoned}`；waiting 语义=有效未完成但不触发到点提醒；`resume_at` 为 waiting 专属恢复日（编辑器离开 waiting 即清除），启动/跨天由 `TaskService.resume_due_today()` 自动恢复为待办；提醒轮询在 repositories 层过滤 waiting（`with_status_resume`）。
- **优先级 8 级（v0.17）**：`entities.Priority` = `NONE(0)+P1..P8`（数字即档位），兼容别名 `LOW=P2`/`MID=P5`/`HIGH=P8`（旧 `int>=MID` 判定语义不变）；`migrate_v8` 把旧值 1/2/3 映射为 2/5/8；语义纯函数 `priority_label`/`priority_is_important`（≥P5）在 domain，8 档色阶 `priority_color` 与 choices/label_map 在 `view/kit/priority.py`（走主题 token 派生，缺失回退固定色板）。
- **任务↔笔记段落上下文（task_note_context）**：独立于 task_note_link（不占「笔记↔任务」单条语义，避免 UNIQUE 冲突）；`block_key`=段落首行指纹（稳定定位）、`snippet`=引文快照（失配兜底展示）；图谱据此生成 anchor 节点、任务行 hover 取 snippet 首 60 字速读。
- 迁移：`schema_version` + 线性迁移脚本（`migrate_v2` 加 `task.start_date`、`migrate_v3` 加 `note.format`、`migrate_v4` 加 `note_revision`、`migrate_v6` 历史空 format 归一 markdown、`migrate_v7` 加 `task.resume_at` + 建 `task_note_context` 表、`migrate_v8` 优先级旧值 1/2/3→2/5/8（倒序分步 SQL UPDATE；无 priority 列的历史库 PRAGMA 防御返回）），启动自动升级，迁移前强制备份。

## 6. 双向链接与 Markdown 管线

```
编辑器输入 --(1s 防抖)--> NoteService.save()
  1. link_parser.extract_links(md) → [(title, range)]
  2. diff 旧链接集合 → 增删 note_link（悬空存 dst_title）
  3. fts.update(note)
  4. EventBus.note_links_changed(note_id) → 图谱增量更新 / 反链刷新
渲染反链：note_link WHERE dst=me → src 链接处 ±40 字上下文
补全：检测 "[[" → Flyout(FTS 标题模糊匹配) → 回车插入 [[标题]]
预览：markdown 库解析 + [[链接]] 前处理 → 可点击锚点；pygments 高亮
```

**段落级上下文管线（v0.15，`task_note_context`）**：笔记侧「选中段落 → 转为任务并关联段落」→ `NoteService.create_task_from_selection(block_key, snippet)` 一次完成建任务 + 关联；`block_key`=段落首行文本指纹（`title_hash` 去首尾空白 + 长度钳制），正文不注入任何锚字符（markdown 保持纯净可移植）；任务侧定位时按笔记全文逐块重算指纹定位，失配则安全打开笔记兜底；任务勾选/删除不级联删上下文，笔记删除软删后上下文保留供回收站还原。

## 7. 桌面浮窗架构（AppController + 浮窗视图）

```
AppContext ──共享──> WidgetWindow(QWidget, 独立顶层)
  ├── 单形态（约 290×380，去紧凑态）⇄ edge-peek(贴边半隐)
  ├── 数据: 浮窗视图绑定同一 TaskTreeModel(today_tree() 今日查询) → 主浮窗天然同源
  ├── 操作: 勾选/快速添加/行内编辑/快捷编辑 → AppController → TaskService → EventBus → 全局同步
  ├── 显隐: 主窗 showEvent → 隐藏浮窗；主窗 hideEvent → 显示浮窗；浮窗「打开主程序」→ 主窗显示（联动隐藏浮窗）
  ├── 外观: SvgIconEngine + ThemeEngine 联动（theme_changed 即时换肤）
  └── 几何: 拖拽位置/透明度/贴边方向持久化 settings.ui_state
```

- 窗口类型 `Qt.Tool`（不占任务栏）；`WA_TranslucentBackground` + 自绘圆角卡片。
- 快速添加复用 `capture_grammar` 语法糖解析，与主窗/捕获卡完全一致。
- 主窗「关闭」行为可配置：退出 / 缩到浮窗（配合托盘）。启动时只显示主窗、隐藏浮窗。

## 8. 全局捕获管线（划词 → 五去向）⭐

```
[任意应用划选文字] --Ctrl+Shift+S--> hotkey(平台层)
  → AppController.start_word_capture():
     1. selection.grab(): 备份剪贴板 → 模拟 Cmd/Ctrl+C → 读剪贴板(300ms超时) → 恢复剪贴板
     2. 弹出 CaptureCard（置顶迷你窗，鼠标附近）
     3. 用户选去向:
        F 存闪念      → FlashService.add(content, remark, source_app)
        T 转任务      → TaskService.quick_create(语法糖解析)
        N 存入当前笔记    → NoteService.append_to(note)
        G 加入分组    → 目标选择器(最近使用+FTS搜分组/列表) → TaskService.create(list_id)
        U 加为子任务  → 目标选择器(FTS搜任务) → TaskService.create(parent_id)
     4. 目标记忆: settings.ui_state.capture_last_target → 下次一键直达
  → EventBus.task_changed / flash_added → 主窗/浮窗/收件箱同步
降级: 无辅助功能权限 → selection.grab 返回 Unsupported → 改读当前剪贴板 + 设置页引导
```

- 目标选择器与命令面板共用 FTS 模糊搜索组件（Controller 编排、View 复用）。
- `G/U` 两去向产生的任务走与普通任务完全相同的 `TaskService` 入口——保证语法糖、事件、Model 刷新一条路。
- 捕获卡 ≤500ms 出现预算（目标 300ms）；捕获内容不写日志明文；`source_app` 由 `SelectionGrabber.frontmost_app_name()` 读取前台应用名（macOS 用 NSWorkspace、Windows 用 GetForegroundWindow），失败兜底“划词”；`source_url` 字段已建仍未取值。

## 9. 主题引擎

```
themes/*.json 自动加载（现 14 款：青竹/暮色/暖沙/墨黑 + 10 马卡龙，每款含 light/dark 两套）   # token 全量定义
        ↓ ThemeService.load()
ThemeEngine(view/kit): tokens{bg,fg,accent,border,success…} × mode(light/dark)
  ├── 色阶派生: accent → hover/pressed/disabled/soft（HSL 插值）+ v0.14 起
  │   accent_solid/accent_on/accent_solid_hover/accent_solid_pressed
  │   （WCAG 对比度驱动：_lum/_contrast/_best_on/_ensure_text_contrast/_accent_solid，
  │     solid 供实底按钮/选中底，on 由其上与底对比 ≥4.5:1 自动选白/近黑）
  ├── qss 模板渲染（全局 QSS）+ qfluentwidgets 主题对齐(setTheme/setThemeColor)
  └── theme_changed → 全窗口 repolish + SvgIconEngine 缓存失效 + 浮窗同步
切换: ≤200ms（纯内存字符串替换，无磁盘 IO）；强调色 8 选 1，实时预览
```

主题包 JSON 为公开格式，用户可自建放入 `themes/` 目录；Mica/Acrylic 材质为独立开关。

**统一组件层（A 路线，`zhixing/view/ui/`）**：`UButton`(tone×kind)、`UCard`(沉浸圆角，无边框+抬升羽影+顶部受光)、`UStatusPill`、`UTitle`(hero/title/sub/muted)。控件颜色一律读语义 token、订阅 `engine.changed` 自愈；页面不使用零散裸 `QPushButton/QToolButton` 自写样式（历史零散统一收编）。

**全局视觉/主题修复**：应用启用 `app.setStyle("Fusion")`（避免 macOS 原生高亮黑）；全局 `QPalette`（Active/Inactive/Disabled 三组）设 `Highlight=accent_soft`、`HighlightedText=fg`、`Base/Window/Text` 随主题；`QAbstractItemView/QComboBox` 的 `selection-background-color/selection-color` 与具体视图 `QTreeView::item:selected`(active/inactive) 统一 `accent_soft`+`fg`。列表/树/下拉选中、日期弹层、收件箱 Tab（关 `documentMode` 使 QSS 生效）、图谱按钮/关系图区、回顾 QtCharts（背景随主题 canvas 并随切换重刷）均随主题。

**全局控件高度 / 字号（`component_qss`）**：设置项「控件高度 24–48px」「字号 12–20px」由 `_apply_theme` 读入并传入 `component_qss(tokens, control_h, font_size)`，通过 QSS 盒模型折算（`min/max-height` 作用于 content 区，padding/border 叠加在外）按控件类型给出 content 高度（pb_h/cb_h/sb_h），使渲染高度精确等于设置值。曾引入 `ControlHeightStyle(QProxyStyle)` 强制 `sizeFromContents`，后因 QProxyStyle 在 `setStyle` 时遗留悬空 base 样式指针导致 macOS SIGSEGV 而弃用（类保留在 `view/kit/control_style.py`，仅 `clear_fixed_height` 仍用于解除 qfluentwidgets 内部 `setFixedHeight(33)`）。下拉箭头由 `_chevron_down_svg()` 运行时生成主题色 chevron SVG 写入临时目录并作为 `QComboBox::down-arrow` 等子控件 `image` 引用，替代 Fusion 灰箭头；`QRadioButton::indicator` 为圆角长方形随字号缩放；qfluentwidgets `SpinButton` 无边框。

**圆形复选框 + SwitchButton/SpinBox 主题化（`control_style.py`）**：全局 `QCheckBox::indicator` 改圆形（`border-radius: chk_h//2`），大小随控件高度缩放（`chk_h = clamp(control_h-14, 12, 22)`）；新增 `restyle_switch_button`（解除 SwitchButton 内部 `setFixedHeight(22)`，Indicator 保持 42×22 由内部布局垂直居中）、`restyle_spinbox`（解除 SpinBox `setFixedHeight(33)` 与 SpinButton `setFixedSize(31,23)`，按钮高 = control_h-8，`_center_spin_icon` 用 `paintEvent` 覆盖让加减图标居中）。

## 12. 关键技术决策记录（ADR 摘要）

| # | 决策 | 理由 / 放弃项 |
| --- | --- | --- |
| ADR-1 | 图谱用 QGraphicsView 自绘，不嵌 WebEngine | 包体与内存预算；交互统一原生 |
| ADR-2 | 链接按标题而非 id 引用 | 与 Obsidian 等文本互通；重命名需同步（已规划） |
| ADR-3 | 中文 FTS：jieba 入库分词 + 回退按字 | 精度与零依赖的折中；trigram 备选 |
| ADR-4 | 循环任务用「完成时克隆推进」，循环子任务用「到期重置」 | 任务是一次性行为→克隆；子任务清单是打卡→重置+streak |
| ADR-5 | domain 零 Qt 依赖 | 可单测、未来换壳成本最低 |
| ADR-6 | 导航页面常驻缓存 | 保留视图状态；7 页内存可控 |
| ADR-7 | 图标 = 单一 SVG 族 + SvgIconEngine 运行时着色 | 主题联动零重绘成本；否决多套位图与 emoji |
| ADR-8 | 划词 = 模拟复制 + 剪贴板备份恢复 | 跨平台一致、实现轻；Accessibility 方案作 macOS 增强 |
| ADR-9 | 主题包 = JSON token + 单一 ThemeEngine | 用户可扩展；避免样式散落各控件 |
| ADR-10 | 浮窗 = 同进程独立 QWidget，共享 AppContext | 数据实时一致；否决独立进程 |
| ADR-11 | **MVC：Controller 编排、View 纯展示、Qt Model/View 承载列表树** | 与 Qt 信号槽/Model 协议天然契合；View 禁触 Service、Controller 薄、规则下沉 domain，评审可硬性检查；否决 MVVM（无成熟绑定框架，纯手工属性绑定收益低） |
| ADR-12 | **完成递归判定（roll-up）用 `effective_done_map` 派生值，不落库** | 父子完成态是派生关系，落库易不一致；一次内存计算 + TaskTreeModel reload 缓存，供勾选态/逾期/四象限/收件箱/概览/日历共用；兼容树形与扁平输入 |
| ADR-13 | **富文本 = HTML 片段存 `content_md`，图片内嵌 base64 data URI** | 复用现有 note 表与 FTS/链接管线，避免 attachment 外部路径；贴图随笔记保存/导出；否决存 assets 目录（富文本引用图片易丢链） |
| ADR-14 | **全局控件高度改用纯 QSS 盒模型折算，废弃 QProxyStyle** | QProxyStyle wrap `app.style()` 在 `setStyle` 时遗留悬空 base 指针致 macOS SIGSEGV；QSS min/max-height 作用 content 区，按 border+padding 折算即精确 |
| ADR-15 | **图谱拉线建链复用 `note_link`（幂等/悬空补全）** | 与 `[[标题]]` 同一条数据源与渲染语义；已有链接（含悬空）仅补全 dst_note_id，反向已连不重复建行；闪念节点端点不建链 |
| ADR-16 | **图谱边分两类（ownership 归属 / reference 引用）+ `ALLOWED_CONNECTIONS` 矩阵 + 归属 DAG 破环** | 归属（folder/task 层级与包含、task→note）语义是「无环层级」，引用（note↔note）语义是「可成环链接」，二者视觉（实线/虚线）与拓扑约束不同必须分开；连接矩阵集中声明合法端点组合，非法拖拽直接拒绝；归属层级边三色 DFS 去回边（只可能被 folder.parent_id / task.parent_id 自引用破坏） |
| ADR-17 | **图谱增量同步用观察者模式（GraphService.subscribe → GraphDelta → bus.graph_delta → GraphPage.apply_delta）** | 领域事件只载「什么变了」，GraphService 按缓存参数重建 + `diff` 出最小变更集（added/removed/updated 节点与边），渲染层定点增删保留布局/pinned，避免全图重绘与力导向重跑；结构类事件统一走 `(change_id, op)` 载荷信号（EventBus D3 扩展） |
| ADR-18 | **任务↔笔记段落关联用独立 `task_note_context` 表 + 块指纹定位，不占 task_note_link、不改 markdown 正文** | task_note_link 的 UNIQUE(task_id,note_id) 语义是「一条任务↔一篇笔记」；段落级是「一对多/多对多」上下文，强行加 block 列会撞唯一约束并污染既有链接语义；正文注入 `^id` 锚字符虽省事，但破坏 markdown 纯净可移植性 → 指纹（首行哈希）+ snippet 引文快照双保险：指纹稳定定位、snippet 在内容变更时兜底展示与安全打开（v0.15） |
| ADR-19 | **段落上下文图谱呈现为 anchor 锚点子节点（负空间 −3e6），note→anchor/task→anchor 走引用虚线** | 上下文是「引用型」语义（指向文中某段而非整篇归属），复用 reference 虚线分类即可，无需新增边类型；锚点小圆点随宿主节点展开/收起避免主图被上下文刷屏（v0.15） |
| ADR-20 | **OS 深链 = 纯解析 `zhixing://`（core/deep_link.py）+ QLocalSocket/QLocalServer 单实例 IPC 转发** | 深链格式解析写成纯函数（无 Qt 依赖）可单测；第二实例启动即退出（单实例锁），把 argv 中 `deep-link:<url>` 经本机 QLocalSocket 转发主实例；主实例 QLocalServer 收到后排入队列，等 `show_main` 完成后统一派发，避免启动竞态（v0.15） |
| ADR-21 | **无边框弹窗终态 = 大圆角 16px 实色 + 无外阴影（UDialog/CommandPalette 统一）** | 首版双层观感来自 1px 硬边框 + drop-shadow（用户判为「两层边框」）；后改柔影 + 透明底，但透明底自绘与 QSS 背景并存致标题栏透明不可点/截图失真 → 终版 `WA_TranslucentBackground` + 全 QSS 实色 `layer` 底 + 四角 16px 圆角（标题栏顶角/body 底角分段实现），阴影全部移除（`attach_dialog_shadow` 保留未用）；圆角穿透由 QSS 承担，不引入 qframelesswindow（macOS offscreen SIGSEGV 平台限制）（v0.14–v0.16 演进） |
| ADR-22 | **任务优先级升 8 级：`entities.Priority` = `NONE(0)+P1..P8`（数字即档位，不引入字符串档位枚举），兼容别名 `LOW=P2`/`MID=P5`/`HIGH=P8`，`migrate_v8` 将旧库值 1/2/3→2/5/8（倒序分步 SQL UPDATE；无 priority 列的历史库 PRAGMA 防御返回）** | 扩档位属存量数据语义变更：改字符串档位会推倒既存 int 列与遍布 model/UI 的 `int>=MID` 判定；「数字即档位 + 别名解析 + 迁移映射」使 0..8 保持线性可排序、旧档位经迁移后「≥MID（现即 ≥5）即重要」判定语义不变，捕获语法糖 !1/!2/!3（!!!→P8、!!→P5、!→P2）同表对齐；8 档色阶 helper `priority_color`（`view/kit/priority.py`）从主题 token 派生、缺失回退固定色板，不在 UI 复制 8 组硬编码色值（延续 v0.14 对比度派生思路）（v0.17） |
| ADR-23 | **编辑/速览/反链等 UI 批共性决策：任务编辑面板 Tab 化（QTabWidget 三分区、各页独立滚动、对外调用面不变）；三视图子树展开集合页面级单源共享；反链建链/归属下沉 Service 幂等 API 以状态码表达；划选速记复用选区管线；QToolTip/LineEdit 高度主题化根因修复** | 大批 UI 进量时守住「视图状态不散落、写路径不重复造」：展开集合 `_expanded_ids` 由页面共享给 Quadrant/Calendar/Kanban（`expanded_ids=` 可选参 + `subtreeToggleRequested` 事件 + eff-done roll-up 定可见子树），避免各视图各维护一套互相漂移；反链主动链接 API 幂等化（`add_reference_link` 返回 added/dangling/bound/duplicate/invalid/self、`attach_note_to_task`/`attach_note_to_folder` 各发对应事件）后，「重复点击/悬空补建/归属移动」由仓储 (src,dst_title) 唯一约束与状态码表达，UI 弹窗只编排不判重；编辑面板 Tab 化只改外壳，task_page/_TaskEditDialog/浮窗调用面零改动；划选速记复用 SelectionGrabber 选区管线与剪贴板降级，全局热键注册失败退应用内 QShortcut 兜底；LineEdit 高度折算按 qfluentwidgets metaobject 类名选择器排在 QLineEdit 之后（治 widget 级 QSS 覆盖 app 级恒矮 10px 根因）+ QToolTip 双处主题化，延续「几何/主题归因引擎层」取向（v0.17） |

## 知行 ZhiXing 1.24.1

本地优先的个人待办 + 知识图谱桌面端（Windows x64）。数据只存在本机的一只 SQLite 文件里：无需注册账号，不联网也能完整使用。

### 下载

| 文件 | 说明 |
| --- | --- |
| **Zhixing-1.24.1-x64-setup.exe** | NSIS 安装包：可选安装目录、创建开始菜单/桌面快捷方式、可在设置里卸载 |
| **Zhixing-1.24.1-x64-portable.exe** | 便携版单文件：双击即用，不写注册表、不建快捷方式 |

> **构建说明**：在受限 / 无交互会话里打 NSIS 包，需要给 PATH 补上系统目录 ——
> 那种环境里可能连 `C:\Windows\System32` 都没有，而 electron-builder 收集模块时要调 `powershell.exe`。
> 这段补齐已经写在 `scripts/release.mjs` 里（只补齐、不重排已有项），普通运行会话不需要任何额外步骤。

### 修复：清单与收件箱的统计口径

- **计数纳入子任务**：侧栏各清单、收件箱徽标、收件箱页的分区 tab，一律按「该范围内所有**未有效完成**的任务（含子任务）」统计。
  此前只数顶层 —— 一个父任务带三个子任务时清单写 1、点进去却是 4 行。
- **收件箱徽标漏掉了任务**：它此前只统计闪念（实测徽标 7，而收件箱里躺着 41 行任务）。
  现在 = 未归档闪念 + 收件箱里未完成的任务，并且**写完即刷新**（此前概览只在挂载时算一次，整理完收件箱数字还停在旧值）。
- **已完成的行不再进收件箱列表**：与任务页清单视图同一条规矩（完成/放弃即从当前清单收走，统一进「已完成」入口）；
  空态会说明隐藏了多少。
- **孤儿根不再混进清单**：父任务被收走后，它的子任务会被建树逻辑**提升成根** —— 缩进与真顶层一样、还常常带着「已完成」，
  于是侧栏写 14、列表却有 18 行顶层，其中 14 行标着已完成。终态视图（已完成 / 已放弃）不做这一步剔除：
  那里本来就要显示已完成的行（否则「已放弃 2」只显示 1 条）。
- **工具栏「共 N 项」**改为视图实际行数（含子任务），与侧栏计数同口径；被聚焦 / 智能清单 / 过滤框收窄时补一句
  「/ 清单共 M 项」。此前写的是根数：已完成视图里侧栏 99、副标题 21，两个数字并排摆着像统计错了。

### 修复：数据库视图打开后没有替换笔记区

`.notes-wrap.is-hidden` 与整段 `.notetable*` 的样式在一次整理里被连带删掉了（类名还挂在 JSX 上），
于是打开数据库视图时笔记树与编辑区**照样显示**、表格被挤成一条。已补回：打开时笔记区隐藏（**隐藏而不是卸载** ——
切回来时未保存的草稿与滚动位置都还在），表格用 `.notetable` 自己撑满剩余高度。

### 修复：图谱「全部文件夹」的层级

此前是「顶层全列完、再把所有子文件夹堆在后面并统一缩进一格」：三层的文件夹看起来挂在最后一个顶层下面，
归属完全是错的。现在按**树序**铺平（父后面紧跟它的子 + 实际层级），抽成 `src/shared/folder-tree.ts`
供笔记页与图谱页共用，带 5 个单测（多层 / 乱序 / 孤立节点当顶层 / 成环不死循环 / 空输入）。

### 界面细节

- **逾期任务**：任务内容与逾期日期胶囊同色（`--danger`）；已完成的行不染。
- **已放弃任务**：勾选框改用与「已放弃」胶囊相同的 danger 色，且不画对勾 —— 它不是「做完了」而是「划掉了」，
  对勾换成一条横杠。
- **笔记编辑区标题行**：胶囊与运行环境下拉统一到 20px 一档（方向是**把控件压下来**，而不是把胶囊拉高 ——
  后者整行发虚）。
- **番茄钟页脚**不再折行。

## 知行 ZhiXing 1.11.0

本地优先的个人待办 + 知识图谱桌面端（Windows x64）。数据只存在本机的一只 SQLite 文件里：无需注册账号，不联网也能完整使用。

### 笔记编辑区：头部再收一层，正文铺满纸面

上一版把 6 张卡片收敛成「一张纸 + 一条信息条」，这一版继续压编辑区的头部（第三轮重排）。

- **标题行四合一**：标题、保存状态、标签、归属同处一行；原先独占一行的元信息行（含格式下拉）整块撤掉。头部实测 104px → 61px，正文又多出约 32px；1280 窗口下正文区占比 77% → 82%。
- **正文铺满纸面**：撤掉上一版试过的「书写列」（限宽 560px 居中），五种笔记形态同宽、左边缘对齐，Markdown 正文不再比标题右缩一格。代价是行宽随窗口变大（1280 窗口约 54 字/行），属已知取舍。
- **笔记类型改为新建时决定**：切换入口从编辑区移到笔记树的「新建笔记」格式菜单。
- **保存状态常驻**：`✓ 已保存` / `未保存` 胶囊一直都在 —— 此前「没在动」和「已经存好」看起来一样。Word / Excel 的文件写回状态也走这个胶囊，写回成功不再弹提示（失败仍提示）。
- **操作组并进工具栏**：预览 / AI 整理 / 链接 / 引用 / 模板 / 全屏 从独占一行改为挂在工具栏左端；富文本与 Word 下它们与格式条落在同一条。编辑区窄于 920px 时左组收成纯图标，把宽度让给格式条。
- **工具栏融进编辑区顶部**：工具行与格式条改无边框、吸附在顶部（正文再长也不跟着滚走）；工具栏到正文首行只剩 12px。
- **点空白就能接着写**：此前只有文字本身能点，正文下方那片空白点不进去，读起来像「只有第一行能编辑」；现在 Markdown / 富文本 / Word 整块画布都可点。
- **编辑区里不再有矩形框**：标题、正文、Excel 单元格、链接表格聚焦时都不画焦点框，落点交给光标与底色。
- **Word 少一行**：「导出 .docx / 用系统应用打开」进了工具栏，Word 与富文本的头部结构完全一致。

### 三处侧栏可以收起了

任务页的清单树、笔记页的笔记树、工作流页的模板树统一了收放行为：**收起时整块不渲染** —— 既不占位，也不留下会被查询与自动化当成「看得见」的隐藏行。

- 按钮落点按「离它管的东西最近」定：任务页在分段控件「列表」旁（**只在列表视图出现** —— 四象限 / 日历 / 看板不按清单组织，此时连按钮一起隐藏），笔记页在页面副标题旁，工作流页在工具栏最左（收起时分隔条一并隐藏）。
- 收放状态记在本地，不跟着数据一起导出 / 同步。

### 修复

- **Word / Excel 写回不再报看不懂的错**：库里有把正文填进「文件路径」那一栏的笔记，写入端此前会拿整段正文当路径去建目录，报 `ENOENT … '…整段正文….docx'` —— 用户既看不懂也没法处理。现在读取端与写入端一致：不是路径就地补一个空白文件，把新路径登记回笔记再写回，且只自愈一次。
- **关联文件缺失时的父目录计算**：原先的正则在路径没有分隔符时会把整串当成目录，改用 `lastIndexOf`。

## 知行 ZhiXing 1.10.0

本地优先的个人待办 + 知识图谱桌面端（Windows x64）。数据只存在本机的一只 SQLite 文件里：无需注册账号，不联网也能完整使用。

### 笔记编辑区：6 张卡片收敛成「一张纸 + 一条信息条」

此前同一篇笔记被切成 6 张各自带边框的卡片（头部 / 标签 / 正文 / 属性 / 反向链接 / 引用 / 归属）加 4 段空白间隙，「标题 → 正文」的连续阅读被打断成四段；空态下底部三张信息卡片固定占掉编辑区约三成高度，正文可用高度只剩约 46%。

- **一张纸**：标题、格式、标签、归属、工具行与正文现在同处一张卡片；内层编辑器（Markdown / 富文本 / Word / Excel / 链接 / 预览）一律去掉第二层边框与底色 —— 边框只标记容器，不再标记分区。
- **信息条默认收起**：属性 / 反向链接 / 引用 / 归属收成编辑区下方一条 34px 的计数行（`属性 N · 反链 N · 引用 N · 归属 N`），点「信息」展开，展开后的可见性与原来完全一致（三组并排、内部滚动）。
- 实测（1280×820、空态）：正文可用高度占比约 **46% → 74%**，编辑区带边框的卡片 **6 张 → 2 张**。
- **窄窗口换形态**：判据是编辑区**自身**宽度（而不是窗口宽度），低于 660px 时展开态改为覆盖式抽屉 —— 盖在正文之上，而不是把正文挤窄（1024 窗口下编辑区只剩约 480px，并排会把提示文案折成两行）。
- **工具行不再折叠**：格式下拉固定 168px（此前通用工具栏会把整行剩余宽度都给它），「模板 / 全屏」不再被挤进「⋯」。

### 全屏编辑

- 工具栏新增「全屏」：页面标题、笔记树、左侧主导航一起让位，只留笔记正文；**标题栏保留**，左上角仍是这篇笔记的标题与工具行。
- **Esc 退出**；离开笔记页自动恢复。

### 链接体检移到笔记树

- 「孤儿笔记 / 失效链接」查的是整个库的链接健康度，不属于「这一篇怎么编辑」，从单篇笔记工具栏移到笔记树工具行（与「AI 整理全库 / 添加附件」同处），点开是两项的子菜单。
- 单篇笔记工具栏因此从 8 个控件降到 6 个。

### 验证

- 新增 `node scripts/notesheetcheck.mjs`：18 项断言守住上面这几件事（卡片收敛、信息条两态、窄窗抽屉、全屏、树上入口）。
- `layoutfitcheck`（10 项）与 `interactioncheck` 里笔记树那条断言顺带修回可用：前者假设正文区上下内边距相等、且仍在找早已不存在的 `.xlsx-grid`；后者量的 `.ntree__tools` 在源码里 0 命中。

### 兼容性

- 数据库仍是 schema v12，无迁移。
- 升级安装不会动你的数据。
- 从 1.9.0 升级：全部是界面布局与入口位置的变化，数据语义不变。

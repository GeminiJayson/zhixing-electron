## 知行 ZhiXing 1.22.0

本地优先的个人待办 + 知识图谱桌面端（Windows x64）。数据只存在本机的一只 SQLite 文件里：无需注册账号，不联网也能完整使用。

### 图谱与工作流：整条渲染栈换成 G6 原生能力

这一版把两个画布从"手写 SVG + G6 当画布用"推进到"**渲染与交互都交给 G6**"：

- **节点**：图谱用内置 `circle` + `iconSrc`（自包含 SVG，颜色按主题算好内联进去）；
  工作流用内置 `rect` / `diamond` + `labelText` + `badges` + 节点 `ports`；
- **连线**：图谱用内置 `cubic` 三次贝塞尔 + 方向箭头；工作流用内置 `polyline` + **A\* 避障路由**
  （线不再穿过节点）+ 分支说明写在**边上的标签**里（满足 / 不满足 / 跳到）；
- **布局**：图谱 `d3-force`、工作流 `antv-dagre`；
- **交互**：选中 / 悬停 / 拖拽 / 平移缩放 / 右键菜单全部是 G6 内置行为；
- **配色**：走 **G6 主题对象**（`register(THEME, …)` + `theme: 'zhixing'`），换主题包 / 强调色自动跟随。

随之删掉了一批"自己造的轮子"：自研正交折线、连线锚点、节点内文字排版、手写端口命中判断等 ——
**净删 579 行**。

### 读图与编辑能力补齐（对照官方能力清单逐项落地）

| 能力 | 说明 |
| --- | --- |
| **邻居高亮** | 悬停或选中一个节点，一跳邻居一起点亮 —— 关系图最基础的读图方式 |
| **悬停提示** | 图谱节点只有图标，现在悬停即见标题 / 类型 / 度数与边的两端 |
| **小地图** | 250+ 节点的图谱右下角有缩略导航 |
| **图例** | 带**节点图标**的图例（自绘：G6 的图例插件只画色块，说不清"星形是任务、便签是笔记"） |
| **拖拽建边** | **按住 Shift** 从一个节点拖到另一个节点即成边（与"拖节点"共用手势，所以用 Shift 区分） |
| **拖拽改挂** | 按住连线靠近某一端拖动、松手落到新节点即改挂；**拖动时有一条预览线跟着鼠标走** |
| **运行时边流动** | 工作流实例跑到某一步时，该步的出边虚线流动，一眼看出卡在哪 |
| **网格 + 对齐线** | 工作流画布 20px 网格；拖节点时显示与其它节点的 x/y 对齐线 |

### 修掉的一批真问题

- **工作流走到「回到前面某一步」的分支时会卡死**：判断"这一步还占着"时只看绑定记录、不看任务状态，
  于是回边重入不再派新待办，实例停在原地什么也不触发。修好派发逻辑后，**又补了一个启动自愈** ——
  把此前卡住的实例在启动时补派一次（幂等）；
- **条件节点的人工确认框点「成立 / 不成立」没反应**：主进程在 `did-finish-load` 时发问询，
  而那一刻渲染层的监听还没挂上，消息丢了。现在渲染层挂载完会**重发一次**；按钮在没拿到问询时置灰，不再静默失败；
- **图谱"看不到东西"**：上一轮为了少跑一次布局，把缓存坐标写进了数据，力导向把它当成初始位置、
  几轮正反馈后节点跑到 ±10 万，`autoFit` 缩到 0.01 —— 整张图空白。现在不塞坐标，让 G6 自己保留位置；
- **点一下画布整个白屏闪一下**：选中节点引起侧栏/滚动条抖动，一次点击触发 5 次 `graph.resize()`，
  每次都会重建 canvas。现在是防抖 + 比尺寸；状态提交也改成差分（点一个节点从 5 次 40ms 级重绘降到 2 次 2ms 级）；
- **工作流节点层级与流程顺序相反**：回边让 dagre 反转了主干边。试过 `ranker` / `acyclicer` / 边权重都改不动，
  最终改成"布局只喂前进边、算完坐标再补回边"；
- **小地图在暗色主题下是白块**：G6 插件把白底写死在它自己的样式里，已按类名覆盖；
- **设置页的快捷键状态一直是空的**：主进程把 IPC 通道名写成了 `app:hotkeyMod.getHotkeyStatus()`（方法名被拼进字符串）；
- **图谱笔记类节点图标全黑**：颜色来自 CSS 变量字符串，写进 SVG 后解析失败静默变黑。

### 界面：把"面板 / 卡片 / 控件"的玻璃层级归位

四档玻璃（窗口底 → 面板 → 卡片 → 控件）此前有几处用错了档位，表现就是"这块和旁边那块看着不一样"：

- 任务树 / 知识库树 / 工作流树 / 两块画布：统一成**面板**层（更透的玻璃 + 羽化阴影），
  不再用更实的底色 + 硬描边；
- 回顾页分区、看板列、四象限等：归到既有的**页面级卡片**规范；
- **氛围光**改成"每个面板各带一份、对角双光源铺满整块" —— 之前放在整窗外层时，
  光源只盖住最左边，右边等于没光（被读成"两边透明度不一致"）。

### 从 1.21.0 升级

直接覆盖安装或换用新的便携版即可，**数据库结构没有变化**（`SCHEMA_VERSION` 仍是 18），
现有的任务、笔记、图谱与工作流实例都原样保留。

> 若你此前有**卡在条件节点之后**的工作流实例（上面那个回边 bug），升级后启动时会自动为它补派一次待办，
> 实例即可继续；已有的历史实例也可以照常中止/重跑。

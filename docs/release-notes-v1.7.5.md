本地优先的个人待办 + 知识图谱桌面端（Windows x64）。数据只存在本机的一只 SQLite 文件里：无需注册账号，不联网也能完整使用。

### 本版要点：堵住「外部页面冒充应用自身页面」

应用窗口里带着完整的本地数据访问能力，所以对「这个页面是不是我自己的」这个问题，
判断必须严格：不是自己的一律拦下，交给系统浏览器去开。

原来的判断用的是**前缀匹配**（这个地址是不是以「我的地址」开头），于是这两种地址会被误判成自己人：

- 开发模式下 `http://localhost:5173.evil.com/` —— 以 `http://localhost:5173` 开头；
- 打包后 `file:///…/renderer/index.html.evil` —— 以入口文件名开头。

放行的后果不是「多打开一个网页」，而是外部页面被装进了应用自己的窗口里。
现在改成**逐段精确比较**（协议、主机、路径都必须一致），上面两种地址都会被正确拦下，
而正常使用完全不受影响：应用内跳转、刷新、`#` 路由地址照常放行。

### 顺带说明

这条最初被审计列为「严重」，后来判定"仅在开发模式可达"降级为「中」—— 降级本身没错，
但降级之后它就**再没人回头修过**：既不在「严重」的必做清单里，状态表里也没有留下它的行。
这次是逐条回代码复核才捞出来的。顺带更正一句：打包分支同样能被前缀命中
（`index.html.evil`），所以原来「仅限开发模式」的说法不准确，只是生产下更难点到而已。

### 兼容性

- 数据库仍是 schema v12，无迁移。
- 与 Python 版继续共用同一只库文件，顺序打开即可，不要同时打开。
- 升级安装不会动你的数据。

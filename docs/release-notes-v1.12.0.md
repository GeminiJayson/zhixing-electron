## 知行 ZhiXing 1.12.0

本地优先的个人待办 + 知识图谱桌面端（Windows x64）。数据只存在本机的一只 SQLite 文件里：无需注册账号，不联网也能完整使用。

### 动效：从「有规范、没落地」到整套补齐

设计规范里的 7 档时长、5 条缓动，此前有 3 档时长与 2 条缓动**从未被引用**，全应用只有 3 个关键帧 —— 而其中 `toast-in` 被 6 处浮层共用。这一版把它们接到真实交互上：

- **完成划线**：勾选圆 0.82→1 弹一下、对勾从左往右画出来、标题的删除线划过（此前是瞬时出现，看不出"刚完成"）。
- **列表行进场**：只给"本次新建的行"播淡入 + 上移，同批最多 8 行按 20ms 依次入场；**滚动进入视口的行一律不播**（虚拟列表滚动会不断重挂载，那会变成"滚到哪都在闪"）。
- **浮层有自己的进出场语言**：弹出菜单从触发点长出来、模态略缩下沉、抽屉侧向滑入、提醒卡向上浮起 —— 而不是所有东西共用同一个"从下 8px 淡入"。**退场**也补上了（此前所有浮层都是直接卸载）。
- **Toast 有生命周期**：停留期底部进度线随自动关闭时间走完，退场下沉淡出。
- **导航选中指示条跨项滑行**（不再瞬间跳位）、看板拖拽有源卡与落点反馈、图谱聚焦有缩放与描边过渡、工作流切布局时节点**飞**到新坐标而不是瞬移。

### 视觉：深度、氛围与玻璃

- **内高光与悬停抬升**：卡片、模态、命令面板多了一条 1px 顶边亮线；可点卡片悬停时抬升 2px 并让阴影进阶。
- **强调色的氛围光**：内容面板与空态背后一层 5–7% 的径向渐变，用 `color-mix(var(--accent))` 派生 —— 14 套主题包 × 8 色强调色自动适配。
- **概览数字滚动**：今日页四张卡的数字首次进入从 0 滚到目标值，之后变化平滑过渡（不再是从头再滚一遍）。
- **玻璃拟态（实验档）**：标题栏、吸顶工具栏、模态、命令面板、菜单用半透明底 + 背景模糊，**设置 → 外观**里可一键关掉（关掉时连合成层都不建，而不是"模糊小一点"）。
- **主题切换有过渡**：切包/切强调色时颜色在 250ms 内过渡，而不是硬切。

### 交互编排

- **共享元素过渡（试点）**：从列表行点开编辑时，任务标题会"长成"弹窗里的标题输入框。
- **页面切换有方向感**：按导航顺序往后走从右侧进、往回走从左侧进。
- **工具栏随滚动抬起**：正文滚过 24px 后工具栏加投影、副标题淡出、标题轻微收紧；未滚动时它与今日页/笔记页的标题行完全同款。

### 番茄钟改成独立小窗

原来的番茄钟是主窗口右下角的一条浮条，主窗口收进托盘/浮窗时它会跟着消失。现在它是一个**独立小窗**：贴在工作区右下角、置顶、不占任务栏，卡片与全局热键的捕获窗、工作流条件确认窗共用同一套骨架。

- 计时、暂停、中断原因、落库都在那个窗口里；主窗口关掉也继续跑。
- 发起入口统一：任务行「专注」、今日页、收件箱、命令面板「开始专注」、桌面浮窗。
- **顺带修掉一个哑掉的入口**：桌面浮窗里的「专注」按钮此前派发的是浮窗自己的窗口事件，主窗口收不到 —— 那条路径一直不工作。

### 标签弹层与状态弹层同构

标签弹层此前一行里挤了三件东西（色块按钮 + 勾选位 + 彩色胶囊），现在与状态/优先级菜单完全一致：**色点 + 标签名 + 选中时的 ✓**，同高同行距；「新建标签」是列表最后一行；点色点改颜色的调色板就地展开在所属标签行下面。

### 修复

- **首屏可能整个白屏、且不报任何错**：主题切换的过渡窗口在首屏读取了计算样式，会强制一次全量样式重算，实测足以把渲染主线程按住（界面白屏、调试协议 45 秒超时、日志里什么都没有）。改成读根元素上的行内变量。
- **两处从未被定义的令牌**（`--ease-standard` / `--space-6`）：因为 `var()` 没有兜底值，引用它们的整条声明会在计算值阶段失效 —— 任务行的时间进度条动画其实一直没跑，图片预览浮层的留白一直是 0。现已补齐，并新增一条**会红的测试**守着令牌完整性。
- **标签菜单弹出来时整块往左跳半个宽度**：它借用了 Toast 的关键帧，而那条关键帧自带 `translateX(-50%)`（Toast 靠它居中）。
- **测试脚本的进程残留会让下一个实例卡死**（对使用者无影响，属开发链路）：清理残留时只杀了主进程，renderer/gpu 子进程活着占住 GPU 与共享内存。现在按整棵进程树清理。

### 验证

本轮回归（全部只在临时库上跑，绝不碰真实数据）：

- 类型检查、**419 项单元测试**（含新增的令牌护栏）、对比度门（14 套主题包 × 双模式）、控件高度门，全绿。
- 端到端：布局成长性与滚动结构、笔记编辑区 50 项、任务交互 36 项、清单 UX 12 项、标签弹层 22 项，全绿。
- 动效性能实测：切页采样窗口内 **75–117fps**、无长任务（>50ms）为 0。

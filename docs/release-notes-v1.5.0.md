## 知行 ZhiXing 1.5.0

本地优先的个人待办 + 知识图谱桌面端（Windows x64）。数据只存在本机的一只 SQLite 文件里：无需注册账号，不联网也能完整使用。

### 下载

| 文件 | 说明 |
| --- | --- |
| **Zhixing-1.5.0-x64-setup.exe** | NSIS 安装包：可选安装目录、创建开始菜单/桌面快捷方式、可在设置里卸载 |
| **Zhixing-1.5.0-x64-portable.exe** | 便携版单文件：双击即用，不写注册表、不建快捷方式 |

### 本版要点

**一、任务行能一眼看出「进行到哪了」。**

- 任务行底部多了一条**时间进度条**：绿（从容）→ 橙（最后三成）→ 红（已过点）。鼠标停留会显示「剩 3 小时 · 12%」这样的说明。已完成的行不画。
- 多了一枚**状态胶囊**（待办 / 进行中 / 等待中 / 已完成 / 已放弃），五种状态五种颜色。**点它就能直接改状态**，不必打开编辑弹窗。

**二、时间可以精确到分钟。**

- 编辑任务时，开始与截止各多了一个时刻：留空表示只精确到天。
- **新建任务的开始时间就是创建那一刻**，所以「进度」从建好就开始算。
- 快速添加里写「明天 14:30」这类日期词，时刻也会被记下来（以前只记到提醒，不进截止时刻）。

**三、日期与时间的选择器全部重做。**

这一版把系统原生的日期/时间面板都换成了应用自己画的：

| | 现在 |
| --- | --- |
| 日期 | 月历（周一为第一列），可翻月，**点标题可跳到指定年月**（1950–2100），今天与选中各有标记，底部有「今天 / 清除」 |
| 时间 | 两列数字（24 小时 × 60 分钟），失焦时把选到的时刻填回去，可清空成「只精确到天」 |
| 尺寸 | 日期格与时刻项都**严格等于「控件高度」设置** —— 你在设置里把它调大调小，它们会跟着变 |

换成自绘的原因是：系统原生面板不进应用的样式体系，格子高度是浏览器写死的，调不了。

**四、修掉两个存在很久的问题。**

- **改键的「保存」按钮以前从来不生效**，只有按回车才存得进去。点它会被当成「点了浮层外面」而取消。现在两条路都正常。
- 改键失败的提示以前会误导：组合被别的程序占用时其实注册不上，界面却说「已降级为托盘菜单」、保存后还弹「已改为」。现在会明说「组合已被别的程序占用」，并在你**按下组合的那一刻**就预检能不能用。

### 兼容性

- 数据库仍是 schema v12。本版新增的两个时刻字段走的是 Electron 私有列（启动时自动添加），没有改动与 Python 版共用的表结构，两版仍可顺序打开同一只库（不要同时打开）。
- 升级安装不会动你的数据；卸载也不会删除数据。

### 运行环境

Windows 10 / 11 x64。首次启动会在数据目录创建或迁移数据库。

### 校验

本版经过 230 项单元测试，以及五套端到端断言（真实窗口 + 数据库副本）：

- `scripts/taskprogresscheck.mjs`（38 项）：进度条与色阶、状态胶囊、分钟精度、自绘日期与时刻选择器（含尺寸、翻月、年月跳转、点选即收起、点击穿透）
- `scripts/hotkeyrebindcheck.mjs`（13 项）：改键全流程、成功与失败两种提示、保存与取消
- `scripts/flashhotkeycheck.mjs`（8 项）：选中入闪念的设置项、热键注册、动作通道
- `scripts/bloubcheck.mjs`（9 项）：悬浮球渲染、体型切换、颜色跟随主题强调色
- `scripts/layoutfitcheck.mjs`（10 项）：Word / Excel 编辑区铺满、行尾按钮组未悬浮不占位

## 1. 设计原则

1. **一件事一个主入口**：每类操作只有一个主要入口位置，备选入口互斥出现。
2. **键盘优先，鼠标不亏**：所有高频动作有快捷键；鼠标路径同样完整。
3. **即时反馈**：每次操作 ≤ 100ms 有视觉回应；破坏性动作给可撤销 Toast 而非确认弹窗。
4. **减法**：默认视图只显示「现在需要」的信息；密度可配置但不堆砌。
5. **图标即语言**：全应用一套 SVG 线条图标族，看到图标即知动作，永不使用 emoji 充当图标。
6. **动效有目的**：每个动画表达空间变化或状态确认，不装饰不炫技。

## 2. 视觉语言

### 2.1 色彩（语义 Token，浅色 / 深色各一套）

| Token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--bg-canvas` | Mica 材质（系统取色） | Mica Dark | 窗口底、侧栏、浮窗底 |
| `--bg-layer` | #FFFFFF 90% | #2B2B2B 85% | 内容面板/卡片 |
| `--bg-hover` | #F5F5F5 | #383838 | 行悬浮 |
| `--fg-primary` | #1A1A1A | #F2F2F2 | 主文字 |
| `--fg-secondary` | #6B6B6B | #A0A0A0 | 次要文字、计数 |
| `--accent` | 主题包定义（默认青 #0D9488） | 同左自动提亮 | 主按钮、选中态、链接 |
| `--accent-warm` | #EA580C 橙 | #FB923C | 逾期/紧急、CTA 点缀（每页 ≤1 处） |
| `--danger` | #DC2626 | #F87171 | 删除、错误 |
| `--success` | #16A34A | #4ADE80 | 完成、保存成功 |
| 优先级色 | 高=--danger · 中=--accent-warm · 低=--accent · 无=灰 | 同左 | 任务行色点（v0.17 起 8 档派生，见下） |

**优先级 8 档色阶（v0.17）**：优先级 8 档色阶由 `kit/priority` 按主题 token 派生（P4≈accent、P5≈warm、P8≈danger，低档灰→accent 渐变），随主题自愈。

规则：颜色承载语义，不做纯装饰；对比度 ≥ 4.5:1；焦点态永远可见（2px `--accent` 外圈）。主题包与强调色机制见 §6。

**accent 派生色阶（v0.14）**：实色按钮/选中底由 `accent` 按明暗派生 `accent_solid`（light 模式深压、dark 模式升亮度并对高饱和蓝紫混白），其上文字 `accent_on` 由 `_best_on` 保证 ≥4.5:1（白/近黑自选），另派生 `accent_solid_hover`/`accent_solid_pressed` 两档；`fg2` ≥4.5、`fg3` 温和 ≈4.0。全 14 主题包 × 双模式由 `apply()` 一次校正，界面禁止直接写白字/黑字盖 accent。

### 2.2 字体 / 形状 / 间距

- 字体栈：`PingFang SC / Microsoft YaHei UI / HarmonyOS Sans / Noto Sans CJK`；正文 13–14px，标题 18–20px，辅助 12px，代码 `JetBrains Mono / SF Mono / Consolas`。
- 形状（v0.14 收敛、v0.16 弹窗终态修订，与 `theme.COMPONENT_TOKENS` 对齐）：内容内嵌/输入 `radius-md` 8px · 小控件/菜单 `radius-sm` 4px（qfluentwidgets 原生按钮取 6px 见 `component_qss`）· 按钮/小控件 `radius-ctl` 6px（UButton 与全局一致）· 卡片/浮层 `radius-lg` 12px（UCard、桌面浮窗；捕获卡/快速捕获壳 **v0.17 起统一 16px 无边框**，见 §10.2）· **大弹窗 `_DIALOG_RADIUS` 16px（v0.16：UDialog 与命令面板，含标题栏顶角 + body 底角四角全圆、背景不透明实色、无外阴影）**；边框 1px `--border`。
- 间距：4px 节奏（4/8/12/16/24）；列表行高 40±4px，命中区 ≥ 32px。

### 2.3 SVG 图标系统 ⭐

**单一图标族**：全部界面图标来自同一套自绘线条 SVG（风格基准 Lucide/Feather）：

| 规范项 | 约定 |
| --- | --- |
| 画布 | 24×24 网格，内容安全区 20×20 |
| 笔画 | 2px 等宽描边、圆头圆角、无填充（双色语义点除外） |
| 命名 | 语义化：`nav.today` `action.add` `task.repeat` `task.subtask` `flash.capture` `graph.filter` `theme.moon` |
| 尺寸 | 16（行内/按钮）/ 20（导航/工具栏）/ 24（空状态）三级，等比缩放不重画 |
| 着色 | SVG 内用 `currentColor`，运行时由图标引擎替换为主题 token：默认 `--fg-secondary` → 悬浮 `--fg-primary` → 激活/选中 `--accent` → 危险 `--danger` → 禁用 40% 透明 |
| 状态 | 悬停/按下/选中/禁用四态着色齐备；图标按钮必有 accessibleName |
| 禁止 | emoji、Unicode 符号、位图切图、混入第二套风格图标 |
| 资产 | 应用图标（Dock/任务栏 icns/ico）与托盘图标（深浅两套）独立制作，不入界面图标族 |

工程实现见架构文档 §10（SvgIconEngine 运行时着色 + 缓存）。**验收标准**：切换主题/强调色时所有图标 ≤200ms 同步换色，2x 高分屏无锯齿。

### 2.4 动效系统 ⭐

| Token | 值 | 用于 |
| --- | --- | --- |
| instant | 100ms | 悬浮色变、按下反馈 |
| fast | 150ms | 弹层、Toast、捕获卡出现、Tab 切页淡入 |
| normal | 250ms | 页面转场、子任务展开折叠、编辑页 |
| slow | 400ms | 浮窗形态切换、图表生长 |
| strike | 200ms | 任务完成划线（从左到右） |
| page | 200ms（v0.16） | 页面标题入场（InOutQuad，8px 上移） |
| panel | 280ms（v0.16） | 浮层面板展开（OutExpo，FloatingDock 项面板等） |

缓动：进入用 decelerate（OutCubic）、退出用 accelerate（InCubic，退出比进入快）、弹性场景（勾选打钩）用轻弹簧 OutBack；**面板展开 panel=OutExpo（v0.16，过冲收尾）· 页面标题 page=InOutQuad（v0.16）**。**场景清单**：

| 场景 | 动效 |
| --- | --- |
| 页面切换 | 淡入 + 8px 上移，250ms |
| 页面大标题入场 | 淡入 + 8px 上移，200ms InOutQuad（`title_enter`，page token） |
| 面板/浮层展开（FloatingDock 等） | 淡入上浮，280ms OutExpo（panel token，`fade_in(...,"panel")`） |
| 任务完成 | 划线从左到右 200ms → 打钩弹簧 → 整行收合进已完成分组 |
| 子任务展开 | 高度展开 250ms + 子行 20ms stagger 逐个淡入 |
| 勾选圆圈 | 打钩路径描画 + 轻微弹跳（spring） |
| UButton hover（solid） | 底色 150ms 渐变（v0.16 P2-a，QVariantAnimation 帧插值；ghost 保持即时态） |
| 笔记树 chevron | 文件夹展开/折叠 120ms 旋转（v0.16 P2-b） |
| QTabWidget 切页 | 150ms 淡入（v0.16 P2-c，`attach_tab_fade`；设置/收件箱/回收站） |
| Toast/InfoBar | 底部滑入 150ms，3–5s 自动退场 |
| 数字滚动 | 统计卡数字 400ms 滚动到新值 |
| 图表进场 | 折线描画、柱状自下生长、热力格 stagger 点亮（不改变终值） |
| 浮窗 | 贴边滑出/收回 200ms（当前为立即切换〔需实现〕） |
| 图谱 | 布局逐帧物理收敛；悬浮邻域高亮 150ms 淡入淡出 |
| 循环子任务重置 | 次日重置时未勾选项轻微抖动一次提示「新的一天」 |

性能预算：只动 opacity/geometry/transform；列表动画仅作用于视口内行；系统开启「减少动态效果」时全部降级为直接切换。

### 4.3 任务页

```
┌──────────────────────────────────────────────────────────┐
│ [列表|四象限|日历|看板] 🔍过滤当前视图…       [+ 新建任务] │

```

- **工具栏**：视图切换（列表 / 四象限 / 日历 / 看板）+ 过滤框 + 「+ 新建任务」（弹输入框，支持语法糖）+ **「速览」开关（v0.16，展开右侧 Context Inspector）**。
- **视图级子树展开（v0.17）**：四象限 / 看板 / 日历 三视图与列表同构地呈现父子层级——父行（父卡片 / 当日清单行）带「▸/▾ N 子」展开 chip（N=可见未完成直接子任务数，0 不显示），点按就地展开/收起：四象限内未完成直接子任务按 **18px/级** 缩进排于父行下、看板为**列内缩进子卡片**（分支前缀「↳」+ 层级收进）、日历为「当日任务」清单行内缩进插入；展开集合为页面级内存态（`_expanded_ids`）三视图共享，**切视图保持展开**；子任务完成判定沿用 roll-up——**已完成子树不外显**、叶子任务不出现 chip。
- **任务树（去分组树）**：中部直接展示「根任务 → 子任务」树（TaskTreeModel），不再有左侧分组树/列表树；**父任务即大任务组、子任务缩进其下**（缩进像素可配置）。
- **任务行**：`优先级彩色 pill（高红/中橙/低青；无优先级不显示）· 勾选圆圈（随行高缩放）· 标题 · 「开始~截止」时间范围 chip · 行内标签 chip（最多 3 个）· 笔记计数 ⇄N · 循环 chip · streak 🔥N · 等待中暂停符号（v0.15，非删除线）`。悬浮时右侧出现「+ / 编辑 / 删除」胶囊按钮（不悬浮不显示）。
- **行交互**：单击=折叠/展开子任务（不再打开编辑）；**双击标题区=行内改标题**（QLineEdit，回车/失焦提交）；点勾选圆圈=完成/取消（roll-up）；点优先级 pill=弹菜单改优先级（**v0.17：菜单/下拉为「无 / P1..P8」8 档**，P1 低 → P8 高；旧「高/中/低」按别名 P8/P5/P2 映射，语法糖 `!1/!2/!3` 对应 P8/P5/P2）；点标签 chip=快捷编辑（移除/添加标签）；「+」=快捷添加子任务（默认「新子任务」并自动触发行内编辑）；`←`/`→` 折叠展开、`Space` 完成/取消、`F2` 弹编辑页聚焦标题；**hover 行 tooltip 显示「关联笔记标题 > 段落首 60 字」（v0.15 上下文速读）**。

## 5. 全局组件与关键交互流

### 5.1 桌面浮窗 ⭐

```
单形态（约 290×380，去紧凑态）
```

- **单形态**：去紧凑态，任务树占满布局；顶部快速输入（语法糖同主窗）+ 左下「打开主程序」图标按钮（SvgIcon 图标，靠左下）。
- **显隐联动**：主程序显示/启动 → 浮窗隐藏；主程序关闭/最小化（缩到浮窗）→ 浮窗显示；从浮窗「打开主程序」→ 主窗显示、浮窗隐藏（`showEvent/hideEvent` 信号联动）。托盘/快捷键 `Ctrl+Shift+D` 手动切换仍可用。

- **拖拽**：按住卡片拖动，松手记忆位置；拖到屏幕边缘吸附为**贴边半隐**（缩成 10px 小把手，鼠标靠近滑出，200ms 滑出〔需实现〕）。
- **同步**：浮窗勾选完成有同主窗一致的完成态；主窗/浮窗任一侧变更，另一侧 <1s 跟随（事件驱动）。
- **右键菜单**：今日视图 / 贴边停靠（取消贴边）/ 隐藏浮窗。
- **外观**：主题、强调色、深浅模式与主窗实时一致；圆角 12px 卡片；默认透明度 85%。
- 托盘菜单提供「显隐浮窗」；主窗关闭时按设置选择退出或缩到浮窗。

### 5.2 划词捕获卡 ⭐

```
        （在其他应用划选文字，按 Ctrl+Shift+S）
┌────────────────────────────────┐
│ 💡 捕获                  Esc 取消 │  ← 鼠标附近浮出（fast 150ms）
│ ┌────────────────────────────┐ │
│ │ 「注意力残渣是深度工作的敌  │ │  ← 来源摘录 ≤3 行，灰底引用样式
│ │ 人…」                      │ │
│ └────────────────────────────┘ │
│ 备注：[写进深度工作读后感______] │
│ [闪念 F] [任务 T] [笔记 N]       │
│ [入分组 G] [子任务 U]            │  ← 新增：直达任务体系
└────────────────────────────────┘
```

**五去向**：`F` 存闪念 / `T` 转任务 / `N` 存入当前笔记 / `G` **加入任务分组** / `U` **加为子任务**，全部支持单键直达、`Enter` 确认、`Esc` 取消。

**目标选择器**（按 `G` 或 `U` 后在卡内展开，不弹新窗）：

```
│ 目标：[ 🔍 搜索分组或任务…        ] │
│  ⏱ 最近: 📁工作/项目A   ⏱最近: ✅ 晨间流程  │  ← 最近使用置顶
│  ▸ 📁 工作                        │  ← 分组树形呈现（G）
│    · 需求评审                     │
│  ↑↓ 选择  Enter 确认  ← 返回      │
```

- `G`：树形列出分组/列表（最近使用 3 项置顶），选定后内容作为新任务落入目标；支持键入即模糊搜索（FTS）。
- `U`：平铺模糊搜索任务标题（排除已完成），选定父任务后内容成为其子待办；父任务下方即时回显「将添加到：晨间流程 ▸」确认条。
- **记忆**：上次目标自动成为本次默认（一键 `Enter` 直达）；设置页可清除记忆。

流程：摘录自动带入（剪贴板备份恢复，不打断原应用）→ 输备注（可空）→ 选去向 → 成功 Toast「已添加 · 去查看」；来源应用自动记录。**权限降级**：macOS 未授辅助功能时首次给出引导弹窗（图示开启路径），之后降级为剪贴板捕获模式（先复制再热键）。

### 5.3 命令面板 `Ctrl+K`

单输入框统一入口，分组结果：**命令**（切换主题包、显隐浮窗、开始番茄钟…）/ **任务** / **笔记** / **闪念** / **标签**；前缀过滤 `task:` `note:` `flash:` `tag:` `due:today`；无结果时给「新建笔记『…』」动作。

### 5.4 快速任务捕获 `Ctrl+N`

480px 迷你窗（Mica、置顶）→ 输入标题 + 语法糖（`!1/!2/!3` 优先级、`@列表`、`#标签`、`明天/周五 9点`，解析结果以 chip 实时回显可删改）→ `Enter` 建（Toast 撤销）→ `Esc` 关。全程 <3s。**方案 A（GTD 收集箱语义）**：默认落收件箱（`list_id=None`），仅当任务页当前视图为具体「列表」时才落该列表。

**划选速记（v0.17）**：任意应用划选文字后按 `Ctrl+Shift+U`（全局热键，默认 `ctrl+shift+u`、可改键；应用内 QShortcut 兜底，全局未注册/平台不支持时仍可用）→ 读取选中并预填本窗——**首行 ≤60 字为标题**（超长截断，光标置行尾便于续输语法糖），**余下原文暂存为待提交备注**，`Enter` 回车建任务（复用 quick_create）；剪贴板备份恢复、不破坏原选区；无选中且剪贴板为空仅提示不弹窗；主窗隐藏时成功/失败提示走托盘气泡。

### 5.5 番茄钟

任务行/详情「▶ 专注」→ 右下角悬浮条 `● 24:31 给客户方案初稿 [暂停][结束]`（呼吸圆点，SVG 实心圆随主题 accent、透明度呼吸）；**休息态换咖啡 SVG 图标、暂停/播放/结束按钮 SVG 图标随主题**（v0.11，去 `●` 字符与 emoji）；结束托盘通知 + 自动记录；中断需选原因。

### 5.6 完成任务 / 删除保护

完成：划线 200ms → 行收合 → InfoBar `已完成「xx」 · 撤销`(5s)；有未完成子任务时询问一次（可记住选择）。删除：软删进回收站 + 可撤销 Toast，**不弹确认框**；回收站在设置管理，30 天自动清理。

### 5.7 FloatingDock 底部快捷新建（v0.16）

- **触发页**：今日页 / 任务页（其余页面隐藏）。
- **形态**：页面右下角悬浮 accent 圆钮「+」；点击后**向上展开**项面板（OutExpo 280ms，4 项逐个 20ms stagger 淡入），含「新建任务 / 新建笔记 / 新建闪念」+ 收起箭头；再次点击或失焦快速淡出收起（fast 150ms）。
- **交互**：任一项点击即唤起对应入口（任务 → 快速捕获迷你窗、笔记 → 新建笔记弹窗、闪念 → 闪念收件箱新条），并收起 Dock；信号 `taskRequested/noteRequested/flashRequested` 由 Controller 路由（见 02 §2）。
- **与命令面板/⌘K 的关系**：⌘K 管「搜与跳」，Dock 管「就地新建」，二者互补（均可用键盘唤起任务新建：Dock 点按 vs Ctrl+N）。

## 10. 设计系统与交互规约（v0.6–v0.8）

本节为 2026-09 统一组件库/主题系统阶段（v0.6→v0.8）对外设计契约，向上覆盖早期零散样式。

### 10.1 设计令牌（Token）与主题

- 三层令牌：`primitives`（每个主题包的 light/dark 原始色值）→ `semantic`（canvas/layer/hover/fg/fg2/fg3/border/border2/input/scroll/accent_soft/warm/danger/success）→ `component`（`radius-sm/md/ctl/lg`、`control-h`，跨主题恒定；`radius-ctl` 6px 为 v0.14 新增，供按钮/小控件与全局对齐）。
- 强调色 `accent` 由设置面板的 8 色单独提供；`accent_hover/pressed/soft/fg` 由 `ThemeEngine.apply` 派生；**v0.14 增派生实色族** `accent_solid`/`accent_on`/`accent_solid_hover`/`accent_solid_pressed`（实底按钮/选中底与其上文字，明暗各 ≥4.5:1，`_best_on` 选白/近黑、`_accent_solid` 按明暗派生）。
- **主题包** = `zhixing/resources/themes/*.json`（自动加载，现 14 款）：青竹/暮色/暖沙/墨黑 + 10 马卡龙（樱花粉/蜜桃橘/柠檬黄/薄荷绿/海盐蓝/薰衣草紫/香芋紫/奶咖棕/冰川蓝/莓果粉）。每款含亮/暗两套。
- 切换三轴：模式(light/dark/system) × 主题包 × 强调色，随 `engine.changed` 即时自愈（≤200ms，纯内存）。

### 10.2 组件库（A 路线，`zhixing/view/ui/`）

- `UButton`：tone ∈ default/accent/danger/success/warn，kind ∈ solid/ghost；自带 hover/pressed/disabled/checked；**focus 可见性（v0.14）**：全 tone/kind 补 `:focus` 边框（实底 2px ring / ghost 1px accent + soft 底，零尺寸跳动）；**hover 渐变（v0.16）**：solid 底色 150ms 渐变（CSS 模板 + QVariantAnimation 帧插值），ghost 保持即时态。
- `UCard`：沉浸圆角卡（自绘 paintEvent：无边框 + 抬升羽影 + 顶部受光 + 随主题面底），`UCard(title).body(widget)`。用于各页交互分区。
- `UStatusPill`：语义状态胶囊（tone→底/字同源）。
- `UTitle`：role ∈ hero/title/sub/muted 层级化标题。
- `UDialog` / `UInputDialog` / `DialogTitleBar`（v0.12，v0.16 大圆角终态）：统一主题化无边框弹窗框架——`DialogType.INPUT`（仅关闭）/ `RESIZABLE`（最小化+最大化+关闭）；自绘标题栏（应用图标 + 标题 + 窗口按钮组）；拖拽移动、双击最大化、边缘缩放（仅 RESIZABLE）；`UInputDialog.get_text()` 替换 `QInputDialog.getText`。**外观终态（v0.16）**：16px 大圆角 + 背景不透明 `layer` 实色 + **无外阴影**——`#uiDialog` 整体 16px 圆角，标题栏带顶角（top-left/right 16px）+ 下 1px `border` 分隔，body 带底角（bottom-left/right 16px），保证四角全圆且标题区可拖拽可选中；移除早期 drop-shadow（曾致「双层边框」观感与透明底不可点问题）；命令面板同规范（16px）。不引入 qframelesswindow（macOS offscreen 下 SIGSEGV），改 Qt 原生无边框 + 自绘。**窗口按钮圆角（v0.17，ea09b5b）**：标题栏 最小化/最大化/关闭钮 的 hover/pressed 背景（关闭钮含 danger 常态）由直角 `fillRect` 改自绘圆角——普通按钮四角 8px，最右关闭钮（danger）**仅右上角取窗口大圆角 16px**、贴合窗口右上弧线不再直角戳出（`_rounded_rect_path` 四角可异圆角）。
- `QuickCapture` / `CaptureCard` 壳（v0.17，ea09b5b）：快速捕获窗与划词捕获卡统一 **16px 圆角 + `layer` 实色 + 无外边框**（与 UDialog/命令面板同族观感；行为/五去向 UI 不动）。
- `CommandPalette`（v0.16）：`WA_TranslucentBackground` + 16px 圆角实色 `layer` 底（无 1px 边框、无外阴影），与 UDialog 同族观感。
- `QToolTip` 气泡主题化（v0.17，b117a2a）：背景 `layer`、文字 `fg`、`border2` 1px 描边、`radius-ctl` 6px 圆角、`5px 10px` padding，字号随全局字号（小一号，`max(12, font_size-1)`），随主题即时自愈。
- 规约：控件颜色一律读 `ThemeEngine` 语义 token，订阅 `changed` 自愈；不写死色值；enums 显示层由组件承接。

### 11.1 今日页

  - UI：勾选处 delegate 画实底 accent + 白勾；已勾选（roll-up 有效完成）标题灰字。

  - 预期：语法糖解析建到「我的清单」（默认列表）；创建任务行出现；空输入忽略。

### 11.2 任务页
- 步骤 TK-1 切到「任务」页（默认「列表」视图）。
  - 预期：中部直接展示「根任务 → 子任务」树（`all_tree()`，无左侧分组树/列表树）；父任务即大任务组、子任务缩进其下；空态提示「还没有任务，点右上角「+ 新建任务」快速添加」。

  - 预期：`TaskFilterProxy` 按标题即时过滤，有命中子孙的行保留（树形过滤）；清空恢复。
- 步骤 TK-3 行交互（与今日页/浮窗同款 TaskDelegate）。
  - 单击标题区=折叠/展开子任务（叶子行选中）；双击标题区=行内改标题（QLineEdit，回车/失焦提交，350ms 去抖防 toggle 双发）；点勾选圆圈=完成/取消（roll-up + Toast 可撤销）；悬浮显示「+ / 编辑 / 删除」胶囊按钮；点优先级 pill=弹 RoundMenu 改优先级；点标签 chip=快捷编辑（移除/添加）；「+」=快捷添加子任务（默认「新子任务」并自动触发行内编辑）。

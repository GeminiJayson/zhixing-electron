## 知行 ZhiXing 1.24.5

本地优先的个人待办 + 知识图谱桌面端（Windows x64）。数据只存在本机的一只 SQLite 文件里：无需注册账号，不联网也能完整使用。

### 新增：任务列表右侧的甘特图侧栏

列表视图的工具栏多了一个「**甘特图**」开关，打开后任务面板右侧出现一条时间轴：行与左侧任务**一一对应**，条按开始/截止画，今天有一条竖线，空白处按住可拖动、双击回到今天。

- **日 / 周 / 月三档视窗**：日档 15px 一天、周档 12px、月档 12px，切换后「上一段 / 下一段」按整屏翻页；月档跨年那格写「27年1月」而不是被截成「27年」；
- **侧栏宽度可拖**：拖左侧分隔条，或者聚焦它按 ← / → 每次 16px，Home 复位；**上限是任务面板的 85%**，且不会把工作区撑出横向滚动条（清单栏会让位）；宽度记在 `tasks.ganttWidth`；
- **任务名称列宽度也可拖**：第二根分隔条在表头名称列的右边界，上限是侧栏宽度的 60%，记在 `tasks.ganttLabel`；
- 侧栏与其余面板同一套玻璃质感，跟随主题与密度；键盘可达（`role="separator"` + `aria-valuenow/min/max`）。

顺带修掉两处实测出来的错位：表头的刻度与行内时间轴差 4px（日档一列才 15px，错位近三分之一列）；月档跨年标签被 `overflow: hidden` 裁掉后半截。

### 修复：循环任务的「截止时间」不生效、任务无限生成

三个叠加的原因，都在这次修掉：

- **结束条件只对「自定义」档位生效**：`nextRecurrence` 里 COUNT / UNTIL 的判断藏在 `period === 'custom'` 分支，而编辑器只给自定义渲染规则控件、保存时又把其它档位的 `repeat_rule` 清成 `null` —— 选「每日」的用户在界面上**根本没有"什么时候停"可设**。现在档位只管周期，结束条件对四个档位一律生效，且每日 / 每周 / 每月也能直接设「一直重复 / 重复 N 次 / 到某天为止」。
- **截止日兼任循环终点**：循环任务填了截止日、又没显式设结束条件时，保存会把它写成 `UNTIL` —— **到那天就不再生成**，不必在「截止日」和「结束」里填两遍同一个日期。截止日留空则一直重复。
- **下一期以完成日为基准**：以前拿这一期的截止日往后推，10-13 的每日任务拖到 10-16 才勾，会一口气补出 10-14、10-15、10-16 三条逾期任务。现在下一期从完成日往后一个周期算，迟做不追补。
- 另外修了三处：子任务跨天重置从不递减 COUNT（设了「重复 2 次」也照样每天滚回待办）；「勾选 → 取消 → 再勾选」会克隆出两条一模一样的下一期；克隆体带着**已经过去**的提醒时刻，完成一次循环任务就立刻弹一次提醒。

### 新增：笔记编辑区 Ctrl + 滚轮缩放

在笔记正文上按住 Ctrl（macOS 是 Cmd）滚滚轮即可缩放，范围 50% – 250%，一档 10%，**Ctrl + 0 复位**。缩放值全局记住，下次打开还是这个比例。

正文、表格、图片、代码块一起缩放；库里的笔记与挂载进来的本地文件（含 Word / Excel 预览）**共用同一个正文容器**，所以一处实现全都生效。滚轮事件在 document 上监听并在命中正文区时 `preventDefault()` —— 否则 Chromium 会把整个界面也缩一遍（实测过：窗口 `innerWidth` 会跟着变）。

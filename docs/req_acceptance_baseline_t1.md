## 0. 状态标记图例

- 〔需实现〕 = 文档自述：现状代码未落地，属设计目标
- 〔风险〕 = 已实现但存在已知边界/缺陷，需人工确认
- 〔已实现〕 = 已落地且自测通过
- 〔已实现·待验收〕 = 代码已落地，但缺真机 GUI 验收
- 〔已修 bug〕 = 历史缺陷已修复
- （未标注） = 文档 §11 未给状态，需以代码为准核验（可能已实现/未实现/弱实现）

## 知行 ZhiXing 1.9.0

本地优先的个人待办 + 知识图谱桌面端（Windows x64）。数据只存在本机的一只 SQLite 文件里：无需注册账号，不联网也能完整使用。

### 下载

| 文件 | 说明 |
| --- | --- |
| **Zhixing-1.9.0-x64-setup.exe** | NSIS 安装包：可选安装目录、创建开始菜单/桌面快捷方式、可在设置里卸载 |
| **Zhixing-1.9.0-x64-portable.exe** | 便携版单文件：双击即用，不写注册表、不建快捷方式 |

### 清单栏：分组能选中，整栏能收起

- **点分组 = 选中这个分组**：列出它下面所有清单（含子分组里的清单）的任务；分组行左侧的箭头只管折叠 / 展开。此前整行都绑在折叠开关上，分组根本选不中。
- **整栏可收起**：表头新增收起按钮，收起后清单栏只剩一条 40px 的竖条，宽度让给任务列表；点一下展开回来。
- 在分组视图里新建任务落回收件箱（分组不装任务）；工具栏的「清单设置」会按目标显示「重命名 / 删除分组」或「重命名 / 删除清单」。

### 已完成：不再出现「待办」

- **状态胶囊跟着有效完成态走**：「已完成」是按 roll-up 收归的 —— 子任务全完成的父任务也会进来，而它自身的状态可能还是「待办」。此前胶囊只读自身状态，于是已完成清单里写着一排「待办」。
- **未完成的子任务不再混进来**：终态视图里每一行都要自己满足条件，不再给「挂在已完成任务下的子任务」开一律放行的后门。

### 笔记图片：正文是缩略图，双击 / 空格看原图

- 新插入的图片仍是「正文缩略图 + 原图存附件」；**旧笔记里内嵌的原图**在打开时会被就地收一次：长边超过 360px 的生成缩略图、原图落成附件，正文只留缩略图（此后打开不再扛着几兆的正文）。
- 正文里的图片高度封顶 240px，竖图不再把正文顶出好几屏；预览里的图不受这条限制。
- **双击**图片看原图；用键盘选中图片后按**空格**同样能预览。旧图没有附件记录时直接用它自身的数据预览，不再「点不开」。
- 附件存不下来时整张跳过：宁可正文大一点，也不会把用户唯一的那张原图换成糊图。

### 悬浮表情：去掉那层矩形底色

- 浮窗（含贴边的悬浮球）画在透明窗口上。此前在 Windows 上给窗口设全局透明度会顶掉逐像素透明，球周围本该透明的部分会浮出一块矩形底色（亮色 / 暗色主题都有）。
- 换主题或系统明暗切换时，也**不再给透明窗口补不透明底色** —— 底色只作用于主窗口。
- 浮窗自身的「透明度」设置保留，只是改由渲染层绘制。

### 兼容性

- 数据库仍是 schema v12，无迁移。
- 升级安装不会动你的数据。
- 从 1.8.0 升级：以上都是界面行为与图片展示的修正，数据语义不变（旧笔记里的内嵌原图会在首次打开该笔记时被收成缩略图，原图同时保存为附件）。

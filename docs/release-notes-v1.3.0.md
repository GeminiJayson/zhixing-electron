## 知行 ZhiXing 1.3.0

本地优先的个人待办 + 知识图谱桌面端（Windows x64）。数据只存在本机的一只 SQLite 文件里：无需注册账号，不联网也能完整使用。

### 本版要点：把工作流连线这几处彻底顺过来

上一版把连线改成了正交折线，但有几处没跟着改完。这一版补齐。

**一、连线的删除按钮回到线上了。** 之前删一条连线，鼠标移到线上会出现一个叉，可它就是悬在空白处、点不到 —— 因为按钮的位置还在按「两个端点的中点」算，而连线改成折线之后那个点早就跑到线外了。现在按钮压在折线的正中间，实测与线的距离是 0；用来改挂端点的小圆点也改成贴着目标那一边。

**二、删得掉步骤了。** 之前删一个被别的节点连线指着的步骤，会提示保存失败、怎么都删不掉，得先手动把别人的连线改到别处去。原因是指向它的连线引用没跟着清掉，校验认为「连到了一个不存在的步骤」而拒绝保存。现在删除步骤时会把指向它的连线一并去掉 —— 删完那两条连线会自然地回到「按顺序走下一步」。

**三、每个步骤都能主动拉线了。** 以前只有条件节点能拖出连线，普通步骤只能等别的节点先连过来、再改挂端点。现在每个节点都有出线口：

- **条件节点**：菱形左右两个尖角，绿色的「满足」与红色的「不满足」；
- **普通步骤**：右边中点一个「跳到」口 —— 平时压暗，鼠标移到该步骤上才亮起文字提示；
- 从任意一个口拖到目标节点就连线，线用中性色虚线，和条件节点的绿 / 红两条区分开；
- 连线随时可以删：鼠标移到线上，按正中间那个叉。

### 兼容性

- 数据库仍是 schema v12，没有新增列、没有迁移。
- 升级安装不会动你的数据；卸载也不会删除数据。

### 运行环境

Windows 10 / 11 x64。首次启动会在数据目录创建或迁移数据库。

### 校验

本版经过 207 项单测 + 两套工作流端到端断言：`scripts/wflinkcheck.mjs` 11 项（删除按钮压在线上、从普通步骤拉线并落库、点叉删线、删除被引用的步骤成功且引用清空），`scripts/wfbranchcheck.mjs` 27 项（两条分支的落库与推进、实例再次运行/删除、模板栏拖拽调宽、条件节点加步骤的分支必选、连线轴对齐与垂直入边）。交互一律通过真实鼠标事件驱动。

### 本版要点：循环任务的勾选恢复正常

**问题**：把一个**循环任务**勾成完成时，程序会报错，任务也勾不动。原因是完成后要克隆出
下一次的子任务，而那条插入语句列了 17 列、只给了 16 个值 —— 数据库直接拒绝执行。
这不是显示问题，是写得进不去的硬错误。

**现在**：列与值对齐，勾选循环任务会照常克隆下一次，循环规则（每 N 天 / 每周 / 按次数 /
到某天为止）都继续生效。

### 顺带说明

这个错误属于「只有在特定路径上才会执行到」的类型：SQLite 是执行到那条语句时才报错，
而「顶层任务 + 带循环规则」不是每次自测都会走到，所以它躺了一段时间。
本版把这类错误变成了一道静态检查：源码里每条 INSERT 的列数与值数都会被数一遍，
不一致就直接让测试失败 —— 这次就是它先报出来的。

### 兼容性

- 数据库仍是 schema v12，无迁移。
- 与 Python 版继续共用同一只库文件，顺序打开即可，不要同时打开。
- 升级安装不会动你的数据。此前受影响的循环任务，升级后直接再勾一次即可正常克隆。

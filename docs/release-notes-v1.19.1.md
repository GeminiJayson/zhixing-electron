### 窗口边框线

主窗口四周有一条取**强调色**的细边，换主题包或强调色时会跟着变。

上一版这条线其实一直没画出来，原因是绘制层级：当时用 inset 阴影当描边，而按 CSS 规范 inset 阴影画在「背景之上、内容之下」—— 标题栏和内容区把它整个铺满了，那条 1px 一直被压在底下。改用 border 后正常（border 画在 padding box 之外，子元素够不到）。

### 窗口阴影：一律向内

窗口四周现在是**向内**的阴影：一圈贴边的细线定义轮廓，一层 14px 的渐隐给出「窗口有厚度」的观感。

**向外画不了**，这一点试过两种做法都失败了：

| 做法 | 结果 |
| --- | --- |
| 直接画外投影 | 超出窗口边界的部分被裁掉，剩四条直边 |
| 留一圈内边距给它 | 那圈是透明的、露出桌面，浅色桌面上是一圈发浅的方角框 |

根子在于：透明窗口**可见的形状就是整个窗口矩形**，而要让圆角成立，圆角外必须完全透明 —— 那就没有任何地方能放外投影。「圆角窗口 + 外投影」在 Windows 的透明窗口上做不到。

### 阴影强度可调

**设置 → 外观 →「窗口阴影」**（0–100，默认 50）：

| 强度 | 边框 | 内阴影 |
| --- | --- | --- |
| 0 | 无 | 无 |
| 50（默认） | 15% | 9% |
| 100 | 30% | 18% |

它不受「玻璃拟态」总开关影响 —— 窗口轮廓与玻璃无关，关了玻璃同样需要。

### 验证

本轮回归全绿（只在临时库与隔离实例上跑，不碰真实数据）：

- 类型检查（主进程 + 渲染层）、**495 项单元测试**、对比度门、控件高度门
- 阴影强度三档实测：变量与 .app 的实际 box-shadow 都跟着变（0 时两层 alpha 均为 0）
- 边框线：截图确认窗口上沿与左沿可见（此前因绘制层级完全不可见）

### 说明

主窗口的玻璃观感不可能与弹窗完全一致 —— 弹窗背后是遮罩与整个页面，模糊能糊出层次；主界面各层背后是彼此的同色底，模糊接近恒等变换。差别在层级，不在写法。

## 知行 ZhiXing 1.3.1

本地优先的个人待办 + 知识图谱桌面端（Windows x64）。数据只存在本机的一只 SQLite 文件里：无需注册账号，不联网也能完整使用。

| 文件 | 说明 |
| --- | --- |
| **Zhixing-1.3.1-x64-setup.exe** | NSIS 安装包：可选安装目录、创建开始菜单/桌面快捷方式、可在设置里卸载 |
| **Zhixing-1.3.1-x64-portable.exe** | 便携版单文件：双击即用，不写注册表、不建快捷方式 |

### 本版修的两处布局

**一、工作流侧栏的编辑按钮不再占着位置。** 模板树与分类树每一行右边的那组按钮（重命名 / 复制 / 删除），以前只是「看不见」—— 它们其实一直占着宽度，于是标题永远少一截、每行右侧也对不齐。现在不悬浮时它们**收拢为 0 宽**，鼠标移到这一行才展开，标题相应让位。任务列表早就是这么做的，这一版把工作流也对齐了。

**二、Word / Excel 笔记的编辑区铺满了。** 这两种笔记的编辑区以前被**居中又内缩**，四周留着一圈空白，怎么调窗口都不填满。原因是样式表里 .editor__office 定义过两次：旧的那份是给「正文在本地文件里」的居中提示写的，它的居中与内边距没有被新的一份覆盖，一并作用到了可编辑预览上。现在两者分成不同的类，编辑区正常铺满；顺带让内嵌的富文本编辑器吃满剩余高度、Excel 网格撑满可用宽度（格数少的表以前只占左边一条）。

### 兼容性

- 数据库仍是 schema v12，没有新增列、没有迁移；与 Python 版继续共用同一只库文件，顺序打开即可，不要同时打开。
- 升级安装不会动你的数据；卸载也不会删除数据。

### 运行环境

Windows 10 / 11 x64。首次启动会在数据目录创建或迁移数据库。

### 校验

本版经过 207 项单测 + 三套端到端断言：scripts/layoutfitcheck.mjs 10 项（编辑区与父容器等宽、编辑器吃掉剩余高度、网格撑满、行尾按钮组未悬浮 0 宽 / 悬浮展开）、scripts/wfbranchcheck.mjs 27 项、scripts/wflinkcheck.mjs 11 项。

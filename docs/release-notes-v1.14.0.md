### 到点提醒：现在能记下「为什么」

提醒卡重做了，气泡窗与主窗口兜底卡现在是**同一个实现**（原先两处各写一遍、按钮文案还不完全一样）。

- **状态设置**：卡片上多了一排状态胶囊（待办 / 进行中 / 等待中 / 已完成 / 已放弃），点中就地展开一行原因输入 —— 不叠第二层弹窗。原因可留空。
- **改状态即视为处理完**：点「进行中」说明你已经在想这件事，不必再点一次「知道了」。
- **不再提醒**：明确拒绝这一条（只关掉这一次；以后重新设了提醒照样会响）。
- **任务速览多了「活动记录」**：这条任务被提醒过几次、每次怎么处理的、状态为什么改，按时间倒序列成一条时间轴。

这些记录写在一张新的追加表里（`task_activity`），并且**全部在主进程记账** —— 不管你是从气泡还是从主窗口处理的，都不会漏。

### 工作流：每次运行都有执行详情

实例列表每行多了「执行详情」：就地展开一条**节点级时间轴** —— 每一步什么时候跑的、结果如何、实例现在停在哪、起止时间。

原先实例上只存了「最近一次节点结果」（那是给下一个节点做条件判定用的），跑完就只剩最后一步的痕迹。现在每一步都留档：进入节点（区分"已派待办"与"自动节点"）、执行完成（带结果摘要与退出码）、流程结束。

### 八处界面修复

1. **完成态对号不在正中** —— 它的旋转中心落在勾的左下角，转 45° 后整体偏了。这一处返工过两次（中间按公式加过一笔方向相反的补偿），最终值是把截图放大 8 倍量出来的。
2. **各胶囊"大小不一致"** —— 既不是字号也不是字重：是普通胶囊写死 11px，而按钮形态的胶囊为了拿回按钮字体写了 `font: inherit`，被顶到 14px。
3. **清单树折叠按钮与「列表」之间那道"分隔线"** —— 按钮从来没有边框，那个观感来自它跟着选中态拿到的白底 + 投影，以及分段控件 2px 间隙露出的底色。
4. **Word 笔记的间距与其它格式不一致** —— 根因是容器内边距叠加，不是 Word 专属规则。五种格式现在都是 4px / 12px，Word 正文可用高度 557 → 585。
5. **笔记类型改为只读胶囊** —— 类型在新建时决定，编辑区不再提供切换。
6. **工作流节点文字溢出** —— SVG 的 `<text>` 既不换行也不缩放，旧写法按"字符数 > 10"截断，而一个汉字约等于两个西文字母宽。现在按**像素**排版（12px 起、放不下降到 10px、再截断），条件节点按菱形腰部宽度另算。
7. **Markdown ↔ Word 来回切换后正文空白** —— 修掉一个一直存在的同步 bug：内容同步的守卫用了"编辑器是否有焦点"，把"外部真的换了内容"也一起挡掉了（Word 的 HTML 是异步取回来的）。现在区分"自己编辑产生的回流"与"外部换的内容"，后者无视焦点写入。
8. **提醒卡与实例详情的时间轴**（见上两节）。

### 树：路径跟踪与折叠记忆

- **路径跟踪**：清单树 / 笔记树 / 工作流模板树都会在缩进区画一条竖向点线，并在当前层级补一小段横向连接线 —— 一眼看出这一行挂在哪一支下。**设置 → 外观**里可关。
- **折叠记忆**：收起某个文件夹 / 分组 / 分类之后，切页、切标签、重启应用都还保持原样。三棵树共用同一套行为。
- 笔记树的文件夹**点整行就能展开**（原先只有那个 16px 的箭头可点）。
- 工作流的展开箭头与笔记树对齐了大小与颜色（实测发现是笔记树那颗被压扁，不是工作流偏大）。

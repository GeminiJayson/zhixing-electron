## 知行 ZhiXing 1.22.1

本地优先的个人待办 + 知识图谱桌面端（Windows x64）。数据只存在本机的一只 SQLite 文件里：无需注册账号，不联网也能完整使用。

这一版是 **1.22.0 之后的修复版**，主要是「**字号调了、界面没跟着调**」这一族问题，外加图谱页的两处。

### 设置页的「字号」现在真的管全局了

根因是同一个：**字号体系里只有正文那一档会动，其余全写死了**。这一版把整条链路接上：

- **文字**：字号阶梯原来除正文外全是固定 px（`--text-aux: 12px` 之类），所以任务行上的**标签胶囊怎么调都不动**。
  现在各级都从 `--text-body` 按比例派生，调一次正文，胶囊 / 徽标 / 标题一起等比缩放；
- **行高**：6 处写死像素的行高（`line-height: 16px` 这种）会在字号调大后**把文字压住** —— 改成相对字号的档位；
- **图标**：全应用的图标尺寸原本是 `size={16}` 这类**数字**（被当成 px），现在统一折算成 `em`，跟着所在上下文的字号走；
- **侧栏统计数字**：徽标原来是 18px 写死 + `line-height` 居中，字号一变数字就偏上或偏下 —— 改成 flex 居中 + 尺寸随字号；
- **勾选框**：任务项的圆圈与里面的对勾原本都是固定 px，字号调大后勾选框显得过小；
  连对勾的**居中补偿**（按 13.5px 字号量出来的 0.7 / 1.2px）也一起改成相对值——否则大字号下勾会重新偏离圆心。

### 图谱页

- **「全部 / 1 度邻域 / 2 度邻域」切换原本不起作用**：邻域子图算出来了、也存进了 state，
  但**只有搜索与侧栏在用**，画布和计数照旧画全图。现在都跟着邻域走（实测：全部 268 节点 → 1 度 4 节点 → 2 度 5 节点）；
  另外切到邻域而还没选中心节点时，会**自动选中度数最高的那个**（否则退回全图，切换依然"看起来没反应"）；
- **页面右侧多出一条滚动条**：小地图是绝对定位元素、又带一圈边框，比插件给它的内联尺寸多出 1–2px，
  这点溢出沿着 `.graph → .graph-shell → .graph-wrap → .page__body` 一路顶到页面级滚动条。现在画布容器裁剪溢出。

### 标题栏

- **双击标题栏 = 最大化 / 还原**。标题栏虽然是拖窗区，但 Electron 不会像系统标题栏那样自带双击最大化，
  得自己接。落在按钮上的双击不触发。

### 从 1.22.0 升级

直接覆盖安装或换用新的便携版即可，**数据库结构没有变化**（`SCHEMA_VERSION` 仍是 18）。

## 知行 ZhiXing 1.22.2

本地优先的个人待办 + 知识图谱桌面端（Windows x64）。数据只存在本机的一只 SQLite 文件里：无需注册账号，不联网也能完整使用。

这一版是 **1.22.1 之后的界面收敛版**：把下拉控件整条链路重写了一遍，又把「面板层」的底色、阴影与留白从头理清。

### 下拉控件：44 处原生 select 全部换掉

原生 `<select>` 展开后的列表**由浏览器/系统渲染，CSS 完全够不着** —— 浅色下是系统白底、深色下也不跟主题，
与全应用的玻璃层、圆角、描边、阴影都对不上。这不是样式没写对，是**根本没法写**。

新写了一个统一的 `Select` 组件替换全部 44 处，浮层复用弹出菜单那一套（与右键菜单、优先级菜单**同源**），
因此下拉在深色主题下也跟随主题。同时把原生本来就有的**键盘与无障碍行为**补齐：

- `role="combobox"` + `aria-expanded` / `aria-controls` / `aria-activedescendant`（焦点始终留在触发器上）；
- ↑/↓ 移动、Home/End 到首尾、Enter/Space 选中、Esc 关闭并回到触发器、Tab 关闭；
- **首字符匹配**（1 秒内连续输入拼成前缀，依次匹配 —— 原生 select 的行为）；
- 层级缩进：清单树、文件夹树这类有父子关系的数据用缩进表达（原生那种 `<optgroup>` 只能分一层、不能嵌套）；
- 弹出位置：**吸附在原控件下方优先**、随视窗自动避让、**任何情况都不遮盖原控件**。

顺手修掉两个交互问题：**弹窗里的下拉位置会偏掉**（弹窗这类容器会创建新的「包含块」，`fixed` 坐标被当成相对它），
以及**知识库「所有类型」出现过两个箭头**（旧类名自画的箭头没清掉）。箭头也统一成了应用图标，与树、日期选择器同一形状。

### 面板层：底色、阴影、留白重新理了一遍

这一串的根源是同一个：**玻璃层是半透明的，卡片铺一层、又叠在同样半透明的页面底之上 ——
两层相加就比「只有页面底」的留白区更实，交界处显出一条淡淡的色带**。

- **面板与卡片不再自己铺底**，层次改由阴影与圆角表达（留白与卡片从此是同一层底，色差归零）；
- **阴影不再外扩**（原来最远扩到 11px，而页面四周只有 4px 留白，那圈阴影整个落在留白里，看着「留白比内容区重」）；
- **留白统一取「布局圆角半径」**（12px），且**不留任何背景色** —— 留白就是圆角的延续；
- **内边距给在滚动容器自己身上**，而不是它的父面板（父面板的 padding 在裁切边界之外，内容滚到那里会被切）；
- 末项**与侧栏「折叠」按钮落在同一条基线上**，并留 2px 呼吸。

### 其他修复

- **任务页切 tab 时布局向左收缩一下**：滚动条槽位没预留（各 tab 内容高低不同，滚动条一出一进，宽度就变几像素）；
- **任务页主布局出现滚动条**：看板的 `min-height` 与网格行高把它连同父级一起顶高；
- **切 tab 时滚动条闪一下**：那是视图交替的中间态（新视图已挂载、旧视图未卸载），改成让主布局根本不滚；
- **回顾页**：去掉滚动条、底部不再空一段、末卡片与侧栏折叠按钮底边对齐；
- **知识库 / 工作流的分隔条不再画线**，只保留拖拽改宽度的功能（鼠标移上去仍是左右箭头）；
- **双击标题栏 = 最大化 / 还原**（Windows 的习惯 —— Electron 不会给无边框窗口自带这个行为）。

### 从 1.22.1 升级

直接覆盖安装或换用新的便携版即可，**数据库结构没有变化**（`SCHEMA_VERSION` 仍是 18）。

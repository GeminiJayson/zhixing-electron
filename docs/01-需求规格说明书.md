# 01 · 需求规格说明书（Electron 实现）

> **文档对象**：知行 ZhiXing 的 Electron 实现（仓库 `zhixing-electron`）。
> **路径约定**：文内所有代码路径相对仓库根。
> **事实基准**：`src/**` 当前工作树。
> **取证口径**：每条需求给出可核对的 `文件:行号`；本轮未在代码中找到确证的一律写「未取证」，不采信任何旧文档结论。

---

## 0. 口径与快照

### 0.1 状态定义

| 状态 | 判定标准 |
| --- | --- |
| 已实现 | 主链可用：写路径接通 + 有 UI 入口（或按设计无 UI 入口）+ 必要护栏存在 |
| 部分实现 | 后端/IPC 已具备但渲染层零调用或缺入口；或主链可用但关键子能力缺失 |
| 有意简化 | 实现方**显式记录过取舍**（代码注释、`docs/optimization-proposals.md` O1–O11），属主动决策而非遗漏 |
| 未实现 | 全仓无等价代码（grep 零命中） |

### 0.2 完成度快照

分域按「主链可用 / 写路径接通 / UI 入口 / 护栏」四项加权（非条数比例）：

| 域 | 完成度 | 主要缺口 |
| --- | ---: | --- |
| 任务 | ~78% | 清单「移动到清单」无 UI、任务↔笔记段落上下文、resume_at 不可写、子任务 list 继承、日历口径 |
| 笔记 | ~65% | 富文本无编辑器、Office 只读、附件与改格式、笔记↔任务/文件夹关联无 UI、MD 导入 |
| 图谱 / 搜索 / 回顾 | ~58% | 破环未接线、引用边与 anchor 不入图、无 delta、无过滤/图内搜索、无预览；搜索缺 MRU |
| 收件箱 / 工作流 / 捕获 | ~65% | source_url 无 UI、转子任务/指定目录无 UI、模板复制/重命名/删步/排序/SOP 绑定、捕获五去向 |
| 设置 / 平台 / 窗口 | ~68% | mica/浮窗开关无 UI、字号行高偏移、浮窗启动联动、边缘缩放、托盘图标、热键状态 |
| 数据 / 统计 / 维护 | ~78% | 只读模式/横幅、before-import 未 prune、导入非导出表残留、域广播不完整、番茄 reason/休息记账 |
| 打包与发布 | ~70% | 无代码签名、无自动更新、仅 Windows 目标 |
| 渲染与交互 | ~80% | 工作流页节点浮卡与分支连线之外的编辑能力 |
| **综合（按域功能面加权）** | **~70%** | 三处结构性断链：段落级上下文、笔记格式体系、图谱语义完整性 |

### 0.3 需求编号

`R-<域>-<序号>`：域取 `T` 任务 / `N` 笔记 / `I` 收件箱与工作流 / `G` 图谱搜索回顾 / `D` 数据与维护 / `S` 设置与平台 / `P` 打包发布；非功能需求用 `NFR-<序号>`。

## 10. 范围外清单（Out of Scope）

以下项目**不在**本实现的需求范围内，不应作为缺口统计：

1. **移动端 / Web 端**：本实现是桌面应用，无手机端与浏览器独立部署形态（`electron.vite.config.ts` 仅构建 Electron 三端产物）。
2. **多用户、账号体系与云同步**：与「本地优先 + 单库本地存储」定位冲突（NFR-01/NFR-02）。
3. **代码签名证书与自动更新服务端**：需要外部凭据/服务，当前列为未实现而非待办（R-P-05/R-P-06）。
7. **全量多语言**：i18n 仅骨架，出英文版不在本期（NFR-10）。
8. **跨应用选区抓取**：Electron 无等价 API，划词捕获按剪贴板降级（R-I-17），不作为待修缺陷。

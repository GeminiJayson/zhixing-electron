## 1. 产品概述

### 1.1 定位

一款给「既要管事、又要积累知识」的个人用户的桌面应用。市面上待办工具（Todoist、滴答清单）不管知识沉淀，笔记工具（Obsidian、Notion）不管任务执行，两者之间靠复制粘贴缝合。本产品把**待办**与**知识图谱**放进同一个数据域：

- 一条任务可以直接引用一篇笔记（「写周报 → [[周报模板]]」）；
- 一篇笔记可以随时长出任务（「读到一半的论文 → 待办：查相关文献」）；
- 图谱把任务与知识的关系可视化，形成个人认知地图。

**v0.2 强化**：知识的采集不止发生在本应用内——在其他应用里**划词**就能把零散知识存进闪念收件箱；**桌面浮窗**让待办常驻屏幕一角，不必打开主程序。

### 1.2 目标用户

- 单用户、单机使用，**无协作、无云同步**（v1 范围外）。
- 熟悉 Markdown、愿意用快捷键的高效个人用户。

### 1.3 核心价值主张

1. **本地优先**：数据 100% 在本机 SQLite，启动快、离线可用、无隐私顾虑。
2. **知识-行动闭环**：任务与笔记双向引用；划词即存、闪念成链。
3. **键盘优先 + 常驻可达**：命令面板一处直达；浮窗让今日待办永远一瞥可见。
4. **轻快且精致**：统一的 SVG 矢量图标系统、克制的精巧动效、可换装的主题系统，不塞浏览器内核。

| F1-7 | 任务树（去分组树） | P0 | 中部列表直接展示「根任务 → 子任务」树（TaskTreeModel），不再有左侧分组树/列表树；`list_id` 仍作为任务归属（收件箱/智能清单使用） |

| F1-11 | 看板视图 | P2 | 按状态分列拖拽（**v0.15 起含「等待中」列**）；**支持父任务展开为子树卡片**（「N 子」chip、子任务缩进） |
| F1-12 | 日历视图 | P1 | 月历日期单元格内绘制任务胶囊（优先级色圆角 pill）；悬浮 tooltip 详情、点击跳转任务；有开始+截止的任务在区间内每天显示、仅截止当天、仅开始当天、无日期显示在今日；「日历显示已完成任务」设置项（默认关）；**当日清单中父任务行可展开显示子任务**（「N 子」chip、子任务缩进） |
| F1-13 | 拖拽排序 | P0 | 同列表内拖拽排序；拖拽移动归属，顺序持久化 |
| F1-14 | 批量操作 | P1 | 多选后批量完成/改期/打标签/删除 |
| F1-15 | 智能清单 | P1 | 内置「今天」「已逾期」「进行中」等智能清单（「今天/已逾期」经今日页概览卡跳转任务页；收件箱为独立入口，不计入智能清单） |
| F1-16 | 收件箱 | P0 | 未整理任务默认落点，未整理数角标；计数按 roll-up 有效未完成统计 |
| F1-17 | 今日待办规则 | P0 | `today_tree()`：有效未完成 且 未逾期（无截止、仅开始无截止、或截止≥今天）；逾期任务单列「已逾期」 |
| F1-18 | **完成递归判定（roll-up）** | P0 | `effective_done_map`：无子任务看自身（完成/放弃均算终态）；有子任务仅当所有后代（递归）都完成才算完成；任一后代未完成则父链未完成；全完成父默认完成。今日页/浮窗勾选态、逾期、四象限、收件箱计数、概览卡均用 roll-up |
| F1-19 | **等待中（WAITING）全链路** | P1(v0.15) | 状态五态之一：5 处界面文案 + 看板列 + 任务行暂停符号（非删除线）+ 编辑页状态选择器 + **「恢复于」resume_at 日期**（waiting 专属字段，改回其他状态自动清除）；启动/跨天自动把到期 waiting 恢复为待办；waiting 任务不触发到点提醒；恢复逻辑见 §业务规则 |

> **业务规则（F1-17/F1-18/F1-19）**：`today_roots()` = 顶层 + 有效未完成（roll-up）+ 未逾期（无截止 或 截止≥今天）；`today_tree()` 在今日根集合之上闭包保留每个根的完整后代（不依赖中间任务自身的 due/完成态）。roll-up 是纯派生值（不落库），与 `Task.is_done`（DONE/ABANDONED 均终态）一致，供今日待办/逾期/四象限/收件箱/概览/日历胶囊共用。**WAITING 语义**：waiting 属有效未完成（计入 roll-up 的未完成判定）但**不触发到点提醒**；`resume_at` ≤ 今天时，应用启动/跨天事件把任务自动恢复为待办（`resume_due_today`），恢复后走普通到点提醒。

## 6. 验收要点（抽样）

- 快速捕获一条任务 ≤ 3 秒（热键 → 输入 → 回车）。
- 在笔记 A 中 `[[笔记 B]]` 保存后：笔记 B 反链面板出现 A 且含上下文；图谱新增一条边；无需重启。
- 「晨间流程」的循环子任务在次日启动时自动重置为未完成，昨日完成情况计入打卡统计。
- 浮窗勾选完成任务 → 主窗口今日列表与统计卡 **1s 内同步**；反向亦然。
- 在浏览器划选文字按 `Ctrl+Shift+S` → 捕获卡 ≤ 500ms（目标 300ms）出现在鼠标附近 → 回车后闪念收件箱 +1，且原应用选区/剪贴板不被破坏。
- 划词 → 「加为子任务」→ 模糊搜索选定父任务 → 主窗口该任务的子任务树 **1s 内**出现新子待办；「加入分组」同理落入目标列表。
- 切换「暮色」主题包：全窗口 + 浮窗 ≤ 200ms 完成重绘，无对比度缺陷、无残留旧色控件。
- 全应用图标均为同一 SVG 图标族：高分屏任意缩放清晰、颜色随主题 token 实时联动，无 emoji 或位图图标混入；图表进场动画结束后数据精确呈现（动画不改变终值）。
- 完成任务后 Toast 可 5s 内撤销，撤销后列表与统计即时还原。
- 删除笔记 → 进回收站 → 反链面板中引用处变为「待建链接」态而非报错。
- 导出 JSON → 清库 → 导入，任务/笔记/链接/标签/闪念数据一致。
- 父任务含未完成子任务时：今日页/浮窗勾选态与「已逾期/四象限/收件箱/概览卡」均显示为未完成；子任务全部完成后父任务自动算完成（roll-up），无需手动勾父任务。
- 日历视图：有开始+截止的任务在区间内每天出现胶囊、仅截止/仅开始的任务只在对应日出现、无日期任务显示在今日；点胶囊跳转任务、悬浮显示详情；「日历显示已完成任务」默认关。
- 富文本笔记粘贴/插入图片后：图片以内嵌 base64 data URI 存于笔记内容，随笔记保存并在重新打开时原样显示；Markdown/富文本两种格式新建可选、编辑正确切到对应编辑器。
- **深链（v0.15）**：终端执行 `zhixing://task/1`（或浏览器访问）→ 已运行实例切到任务页并定位/高亮任务 1；`zhixing://note/2?block=xxx` 追加定位笔记段落；未运行时则正常启动后派发。
- **段落跳转（v0.15）**：笔记中选中段落 → 右键「转为任务并关联段落」→ 在任务编辑页点「§ 首行…」→ 切回笔记页滚动高亮原段落（1.4s 后消失）；任务行悬浮出现「笔记标题 > 段落首 60 字」提示。
- **时刻 NLP（v0.15）**：快速捕获输入「明天3点 交周报」→ 任务 due=明天、提醒时刻=15:00，速记窗/语法糖 chip 回显「明天 15:00」；「下午3点半」等自然说法同样解析。
- **等待中状态（v0.15）**：任务改「等待中」并设「恢复于」某日期 → 任务行显示暂停符号而非删除线、看板「等待中」列出现、到点提醒不触发；跨过恢复日后启动/跨天自动回到待办；改回其他状态后恢复日期字段自动清除。
- **对比度与焦点（v0.14）**：亮/暗各主题包下 accent 实底按钮前景字与底对比 ≥4.5:1（白字/近黑自选）；Tab 键聚焦 UButton 可见 2px accent 焦点环且无尺寸跳动；辅助文字均 ≥12px。

## 7. v0.6–v0.8 主题、设计系统与全局视觉需求

### 7.1 主题系统（扩展）

- 主题包由 `zhixing/resources/themes/*.json` 自动加载，支持任意款（现 **14 款**，每款含亮/暗两套）：
  - 原有：青竹、暮色、暖沙、墨黑（保留原样）；

- 每款定义 semantic token（canvas/layer/hover/fg/fg2/fg3/border/border2/input/scroll/accent_soft/warm/danger/success）；`accent` 由设置面板 8 色独立提供，派生 accent_hover/pressed/soft/fg。
- 切换三轴：模式(light/dark/system) × 主题包 × 强调色，`engine.changed` 即时自愈（≤200ms 纯内存，含浮窗/各页/图表）。
- 所有界面颜色不写死，一律读语义 token；亮/暗两套对比度达标（含列表/树/下拉选中、日期弹层、图谱按钮、收件箱 Tab、图表背景）。

### 7.2 统一组件库（A 路线）

- 自有 token 化组件层 `zhixing/view/ui/`：`UButton`(tone×kind)、`UCard`(沉浸圆角)、`UStatusPill`、`UTitle`(hero/title/sub/muted)。
- 新控件并入统一 UI 层；控件外观随主题自愈；页面不使用零散裸 `QPushButton/QToolButton` 自写样式（历史零散统一收编）。
- 沉浸式 `UCard`：无边框 + 抬升羽影 + 顶部受光 + 随主题面底；各页交互分区以此分区。

### 7.3 页面/交互视觉统一

- 各页顶部统一 hero 标题（今日/回顾/任务/笔记/收件箱/图谱/设置）。
- 今日概览 4 卡等宽且高度自适应；任务编辑区（状态/优先级/循环/专注）单列、禁水平滚动（minWidth 360）。

- 收件箱 Tab 关 documentMode 使 QSS 生效，Tab 条随主题；图谱工具栏/选中信息卡 + 画布不拆；回顾 QtCharts 背景随主题 canvas 并随切换重刷。
- 移除各页无效尾部 stretch；分区靠羽影/顶光/面差分层，不靠硬边框割裂。

### 7.4 验收要点（v0.6–v0.8 补充）

- 设置→外观→主题包出现 14 款；每款亮/暗切换后全 UI 与回顾图表背景实时吻合，无残留旧色/无对比度缺陷。

- 10 款马卡龙包每一款亮/暗均无对比度/可读性问题；强调色 8 色在每款下协调。
- `python3 -m unittest discover -s tests -q` 保持绿（含主题包加载、页面构造 e2e、控件冒烟）。

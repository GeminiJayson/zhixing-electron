### 快速笔记浮窗（新）

一个能**连着写**的浮窗：`Ctrl+Enter` 存一条、输入框清空、光标不丢，写完整批归到笔记。

与既有的「快速捕获」分工不同 —— 那个是"写一条就走人"（快速建任务 / 划词捕获），一次一条。

**怎么打开**：托盘右键 →「快速笔记」；或到**设置 → 快捷键**里给「快速笔记」录一个组合键（**默认留空**，不与你的既有习惯冲突）。

**输入区带完整样式工具栏** —— 与笔记编辑器是**同一份实现**：字号、10 色文字色板、加粗/斜体/下划线/删除线、H1–H3、无序/有序列表、引用、代码块（含 13 种语言标记）、三种对齐。

**归档有三条路**：整批**新建一篇**、**追加到已有笔记**（按目标笔记格式拼接）、或列表每行**单条转**。

**窗口**：可拖四边四角改尺寸、标题栏滑块调透明度，都会记住。可以**📌 钉住**常驻；不钉住时点别处会隐藏（不是关闭，内容都在）。

**数据落在闪念**（收件箱）—— 每条即时入库，关窗或崩溃都不丢；**这些内容在收件箱里也能看到**，归档后才会从那里移走。

### 闪念现在装得下富文本

快速笔记的富文本条目存的是 HTML，这牵出三处必须改的地方：

- `content` 上限从 2000 提到 **8000** —— 富文本的标签本身就要占几百字符，2000 会在句子中间截断，截出来还是**标签不配对**的破损 HTML
- 转笔记时**按内容自动判定格式**：原先固定建 markdown 笔记，HTML 落进去打开就是满屏标签源码。闪念这张表两种来源共用（快速笔记存 HTML、收件箱剪藏存纯文本），只能靠内容分辨
- 取标题不能直接剥标签：那样 `<p>标题</p><p>正文</p>` 会连成"标题 正文"一整行，取首行拿到的是**全篇**。改成先按块级标签切段再取第一段

### 编辑器

富文本工具栏抽成了共享组件（`RichTextToolbar`），笔记编辑器与快速笔记浮窗共用 —— 行为与外观没有变化，纯粹是为了不再有第二份实现。

### 几个 Windows 上的坑（都记在代码注释里了）

- **不设 `box-shadow`**：无边框透明窗口会把投影裁成窗口矩形，圆角外面露出一圈方角阴影
- **不开 `resizable`**：透明窗口在 Windows 上的原生缩放会闪烁；改成自绘八向热区 + 程序化 `setBounds`
- **不用 `win.setOpacity`**：它设的是整窗全局 alpha（layered window），会破坏逐像素透明、圆角外立刻出现方角；改成调卡片底色
- **卡片要撑满窗口**：否则拖大之后留一片空白，看着像"高度调不动"

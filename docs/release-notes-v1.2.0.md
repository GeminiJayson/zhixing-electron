## 知行 ZhiXing 1.2.0

本地优先的个人待办 + 知识图谱桌面端（Windows x64）。数据只存在本机的一只 SQLite 文件里：无需注册账号，不联网也能完整使用。

| **Zhixing-1.2.0-x64-portable.exe** | 便携版单文件：双击即用，不写注册表、不建快捷方式 |

### 本版要点：工作流的连线与「加一步」

这一版把工作流画布上两处一直别扭的地方改掉了。

**一、在条件节点上「加一步」，现在一定是分支步骤。**

以前在条件节点上新增步骤，可以「不挂分支」—— 于是新步骤落进顺序链，条件节点等于被绕过去了。现在：

- 分支是**必选**的：下拉里没有「不挂分支」这一项，没选之前保存按钮点不动；
- 新步骤只通过「满足」或「不满足」的彩色虚线连到条件节点，**不会再出现一条常规顺序实线**；
- 条件节点自己也不再画顺序出边：两条槽位都配了就只画两条分支；只配了一条，另一条会以**灰色点线**连到兜底目标（按顺序顺延到第一个不属于该条件分支目标的节点）。

**二、连线改成垂直进出节点边，不再和节点的边重合。**

以前条件节点从菱形尖角水平出线、却要接到目标的上边时，折线会走成「竖—横—竖」，最后那段竖线正好压在目标的左右边框上 —— 看上去就是线和节点的边粘在一起；跨层的分支还会从被跳过的中间节点身上穿过去。现在：

- 每条连线都是**按它所在的那条边折的**：首段垂直于出发的边、末段垂直于进入的边，中间的过渡段落在节点之外；
- 条件节点的两条分支都从菱形端口水平出线，沿着节点外侧绕行，不再穿过中间节点；
- 所有连线都是轴对齐折线，不会出现斜线。

### 顺带修掉的两个缺陷

- **插入步骤后节点会重叠**：原先「点一下选中」就把 dagre 的临时排布固化成手动坐标，保存时又把画布上所有节点的临时坐标一起写回库；于是新插入的步骤按新分层拿到旧位置，正好压在原有节点上。现在只有真的拖动过才写坐标，保存也不再写回临时坐标。
- **发版脚本在受限环境里跑不起来**（1.1.0 之后修的）：Windows 上 `npx` 是 `.cmd`，Node ≥20 不允许不经 shell 直接执行；受限环境的 `PATH` 里也没有 `C:\\Windows\\System32`，electron-builder 收集 node 模块时找不到 `powershell.exe`。

### 兼容性

- 数据库仍是 schema v12，没有新增列、没有迁移；与 Python 版继续共用同一只库文件，顺序打开即可，不要同时打开。
- 升级安装不会动你的数据；卸载也不会删除数据。

### 运行环境

Windows 10 / 11 x64。首次启动会在数据目录创建或迁移数据库。

### 校验

本版经过 203 项单测 + 26 项工作流端到端断言（`scripts/wfbranchcheck.mjs`：两条分支的落库与推进、实例再次运行/删除、模板栏拖拽调宽、条件节点加步骤的分支必选、连线轴对齐与垂直入边）。

# 知行 ZhiXing 打包说明（Windows）

## 前置条件

- Windows 10/11（x64）
- Python 3.11+（与项目运行时一致）
- 能访问 PyPI（安装依赖）

## 快速打包

1. 在 Windows 上克隆/复制本项目。
2. 双击运行 build_windows.bat，或在项目根目录执行：

    build_windows.bat

3. 脚本会自动：
   - 安装 requirements.txt 依赖 + pyinstaller
   - 用 zhixing.spec 打包
   - 输出到 dist/ZhiXing/ZhiXing.exe

## 手动打包

    cd 项目根目录
    python -m pip install -r requirements.txt pyinstaller
    pyinstaller --clean --noconfirm zhixing.spec

## 产物

- 可执行文件：dist/ZhiXing/ZhiXing.exe
- 运行库/资源：dist/ZhiXing/ 目录下其余文件（Qt DLL、主题 JSON 等）

> 分发时请把整个 dist/ZhiXing/ 目录一起打包（zip），不能只拷 exe。

## 关键配置（zhixing.spec）

- 入口：run.py -> zhixing.__main__.main()
- 图标：assets/zhixing.ico（多尺寸 ICO，由 SVG 矢量图标生成）
- 数据文件：zhixing/resources/themes（14 个主题 JSON）
- 隐藏导入：PySide6.QtCharts、PySide6.QtSvg、qfluentwidgets 子模块、Pygments 词法分析器、**python-docx / openpyxl 及其依赖（Word/Excel 笔记只读预览）**
- collect：qfluentwidgets 资源、jieba 字典
- 控制台：关闭（GUI 应用，无黑窗）
- 应用名：ZhiXing

## 数据目录

首次运行后，数据保存在 %APPDATA%/ZhiXing/zhixing.db（可设环境变量 ZHIXING_HOME 覆盖）；日志保存在 %APPDATA%/ZhiXing/logs/（zhixing.log、stderr.log、stdout.log）。

> 注：v0.13 无新增第三方依赖——Word/Excel 编辑复用 python-docx/openpyxl，图片仍 base64 内嵌、文件附件为本地路径链接。

## v0.12 运行时日志重定向（windowed 冻结）

PyInstaller `console=False` 冻结后 `sys.stdout`/`sys.stderr` 为 None，任何 print/traceback 静默丢弃、loguru 的 `add(sys.stderr)` 会抛错。`core/logging_util.ensure_std_streams` 在启动早期（`__main__` 创建 QApplication 前）按需把标准流重定向到 `<logs>/stdout.log、stderr.log`（行缓冲、幂等）；`setup_logging` 仅当 `sys.stderr` 非 None 才 add 控制台 sink。这样早期错误（含 QApplication 创建失败）与全部日志均有真实 sink。

## 注意事项

- PyInstaller 不支持跨平台打包：必须在 Windows 上打包 Windows exe。
- 首次启动可能被 Windows Defender 误报，属 PyInstaller 常见情况，可做代码签名。

## 1. 软件简介

**知行 ZhiXing** 是一款**本地优先**的个人效率桌面应用，把「**待办（行）**」与「**知识图谱（知）**」放进同一个数据域：

- 一条任务可以直接关联一篇笔记、甚至关联笔记里的**某一段落**（任务侧可一键跳回定位）；
- 一篇笔记可以随时「长出」任务（选中文字 → 转为任务并关联段落）；
- 图谱把任务、笔记、文件夹、闪念的关系可视化，形成个人的认知地图。

### 1.1 核心特点

| 特点 | 说明 |
| --- | --- |
| 本地优先 | 数据 100% 保存在本机 SQLite，离线可用、无云无账号、无隐私顾虑 |
| 待办 × 知识一体 | 任务与笔记双向引用；快速捕获、闪念收件箱、桌面浮窗、划词捕获闭环 |
| 键盘优先 | 命令面板一处直达；全局热键随时捕获；快捷键总表可在设置页查阅 |
| 轻快精致 | PySide6 原生实现（非浏览器内核）；全 SVG 矢量图标；14 款主题包 × 8 色强调色可换装 |

### 1.2 支持平台

macOS（13+）、Windows（10+）与主流 Linux。安装包 / 打包方式见《docs/打包说明.md》，Windows 打包产物为 `dist\ZhiXing\ZhiXing.exe`。

## 2. 安装与启动

### 2.1 源码方式运行（开发/预览）

```bash
# 1. 安装依赖（Python 3.11+）
pip install -r requirements.txt

# 2. 启动
python -m zhixing
```

首次启动会看到欢迎页（SVG 图标 + 进度条），初始化完成后自动打开主窗口。首次运行时应用会自动创建默认分组（工作 / 生活 / 我的清单）与一条欢迎任务「欢迎使用知行：试试 Ctrl+Alt+N 快速添加任务」。

### 2.2 数据存放位置

数据目录按平台自动选择（可用环境变量 `ZHIXING_HOME` 覆盖）：

| 平台 | 路径 |
| --- | --- |
| macOS | `~/Library/Application Support/ZhiXing/` |
| Windows | `%APPDATA%\ZhiXing\` |
| Linux | `~/.zhixing/` |

目录内包含：数据库文件 `zhixing.db`、自动备份目录 `backups/`、日志目录 `logs/`。在 **设置 → 数据与关于 → 数据** 中可查看数据库完整路径并一键「打开目录」。

### 2.3 单实例运行

知行是**单实例**应用：重复启动不会开第二个窗口，而是提示「『知行』已经在运行了（查看系统托盘）」。若第二次启动时命令行带了 `zhixing://` 深链参数，该链接会自动转发给已运行的主实例并跳转定位（详见 §14）。

### 3.1 自定义标题栏

顶部标题栏由左到右依次为：

| 元素 | 说明 |
| --- | --- |

### 3.2 左侧导航

| 导航项 | 作用 | 快捷键 |

- `Ctrl+Tab` 可在最近两页之间往返。

### 3.3 底部快捷浮条（FloatingDock）

在**今日页与任务页**的内容区右下角，有一个圆形「**+**」快捷胶囊（v0.16 P0-3）：

- 点击展开三个快捷入口：**新建任务**（唤起快速捕获迷你窗）、**新建笔记**（新建笔记弹窗）、**记闪念**（跳到收件箱「闪念」页签）；
- 只在今日/任务页显示（收件箱/笔记/图谱页已有各自的页内新建入口，避免重复）；
- 在其他页面自动收起隐藏；
- **收起方式（v0.17.2）**：点击主「+」按钮、**点击浮条以外的任意位置**、或按 **`Esc`** 均可收起（此前只能再点一次主按钮）；点击浮条内部不会误收。

## 4. 今日页

今日页是启动后的默认主页，自上而下分为三块。

### 4.1 概览四卡

| 卡片 | 颜色 | 数值含义 | 点击跳转 |
| --- | --- | --- | --- |
| 今日待办 | 强调色 | 尚未完成且未逾期的顶层任务数（无截止日期也会计入） | 任务页「今日」清单 |
| 已完成 | 绿色 | 今天被勾选完成的任务数 | 任务页「已完成」清单（含已放弃） |
| 已逾期 | 橙色 | 已过截止日仍未完成的任务数（含子级） | 任务页「已逾期」清单 |
| 闪念收件箱 | 紫色 | 未整理闪念条数 | 收件箱「闪念」页签 |

卡片数字随操作实时刷新；标题栏上方为「9月9日 周二 · 今日概览」式日期问候。

### 4.2 今日待办规则（今日页 / 浮窗 / 收件箱计数等共用）

- **今日待办** = 未完成（按 roll-up 有效判定）且**未逾期**的顶层任务：无截止日期、或截止日期不早于今天；逾期任务会单列到「已逾期」，不混在今日清单里。
- 每个根任务都会带上它的**完整子树**显示（子任务即使自身条件不同也随父展示，便于一次看清整组）。
- **完成判定（roll-up）**：无子任务的任务看自身状态（已完成/已放弃均算终态）；**有子任务的任务只有它的所有后代（递归）都有效完成时才判定为完成**——子任务全部勾完后父任务自动变完成，无需再单独勾父任务；反过来只要有一个子任务未完成，父链始终显示未完成。今日待办勾选态、已逾期、四象限、收件箱计数、概览卡、统计均遵循同一规则。

### 4.3 勾选完成 / 撤销

- 点击任务行左侧圆圈：完成任务（标题划线灰字收进完成态）；再次点击或按 `Ctrl+Z` 可**撤销最近一次完成/恢复**（底部弹出 InfoBar 提示）。
- 完成任务若有关联笔记，Toast 会额外提供「**写篇笔记记一下**」按钮，一键生成复盘笔记。
- 勾选动作带弹簧打钩动画与 200ms 划线进度（设置「动效=减弱」或系统开启减少动态效果时自动降级为直接切换）。

### 4.4 循环子任务打卡

带周期的子任务（每日/每周/每月/自定义）是「打卡清单」：

- 到期（次日启动或应用运行跨过零点）自动重置为未完成，并在重置后累加连续完成次数（streak 🔥N）；
- 跨天重置时会弹出「新的一天：N 个打卡子任务已重置」提示；
- 连续完成情况进入「回顾」页热力图与成就统计。

### 4.5 最近笔记与快速添加

- **最近笔记**卡列出最近更新/创建的 5 篇笔记，整行可点击跳转到该笔记。
- 页面中部有**快速输入框**：输入标题（支持语法糖，见 §6）后回车即建任务（空输入忽略）。

## 5. 任务管理

### 5.1 任务页工具栏

任务页顶部工具栏：**视图切换**（列表 / 四象限 / 日历 / 看板）+ **过滤框**（按标题即时过滤树）+ **速览**（右侧 260px 上下文栏，默认折叠）+ **批量**（多选后批量操作）+ **+ 新建任务**。

- 切换视图后数据即时刷新；任务任何字段修改后，四象限/日历/看板也同步重算，不会看到旧数据。
- **速览栏（v0.16 P1-c，v0.17 分三卡）**：在列表视图点「速览」展开右侧栏（260px），随选中任务**分三张卡片**展示：**任务**（标题 / 状态 / 优先级 / 截止 / 等待至）、**关联段落**（§ 按钮 → 打开笔记定位高亮）、**标签**；标题行带「任务速览 · #任务ID」，无内容的分组不生成。

### 5.2 列表视图：任务树

「列表」视图直接用一棵树展示所有任务：**父任务 = 大任务组，子任务缩进其下**，无独立的分组侧栏。

任务行的可视元素（自绘 delegate）：

| 元素 | 说明 |
| --- | --- |
| 勾选圆圈 | 完成/取消（roll-up 规则见 §4.2）；等待中显示为「暂停符号」而非勾选 |
| 优先级旗子 | 单面旗子 SVG 展示当前优先级（颜色=8 档色阶，无文字）；点击旗子弹菜单改优先级（无 / P1–P8，8 档语义与色阶见 §5.3） |
| 时间范围 chip | 「开始 ~ 截止」日期区间，逾期标红 |
| 标签 chip | 行内标签，点击可快捷增删（放不下时与右侧 chips 一起折叠，见下） |
| 笔记计数 ⇄N | 关联笔记数量（有笔记时显示） |
| 循环 chip / streak | 每日/每周/每月/自定义；打卡连续 🔥N |
| **+N 省略胶囊** | 行右侧 chips（笔记/循环/streak/日期）+ 标签总宽放不下时折叠为「+N」，鼠标悬浮向下展开列出被折叠的全部胶囊 |

**行交互（鼠标）**

| 动作 | 行为 |
| --- | --- |
| 单击标题区 | 折叠/展开子任务（叶子任务则选中该行） |
| 双击标题区 | 行内改标题（回车/失焦提交） |
| 悬浮行 | 右侧浮现「专注 / ＋ / 编辑 / 删除」图标按钮（仅悬浮时出现，不占行宽；图标化：开始专注、加子任务、编辑、删除） |
| 点优先级旗子 | 弹菜单改优先级（无 / P1–P8，8 档） |
| 点标签 chip | 弹菜单移除标签 / 添加标签（可逗号分隔批量添加） |
| 按住拖拽到另一行 | 拖动排序 / 改挂父子（拖到行内=成为其子任务，拖到空白=移回顶层；自动防成环） |
| 悬浮任务行 | 若该任务关联了笔记段落，tooltip 显示「笔记标题 > 段落首 60 字」上下文速读 |

**行交互（键盘，任务树获得焦点时）**

| 快捷键 | 行为 |
| --- | --- |
| `←` / `→` | 折叠 / 展开子任务 |
| `Space` | 完成 / 取消当前行（roll-up） |
| `F2` | 打开任务编辑页并聚焦标题框 |
| `Ctrl+↑` / `Ctrl+↓` | 同级内上下移动排序 |

行高（24–72px）与子任务缩进（8–48px）可在设置中调整，今日页/任务页/浮窗三处同步生效。

> **v0.17.1 交互修复**：任务行悬浮「专注 / ＋ / 编辑 / 删除」图标按钮**点击可靠**（此前个别情况下「编辑」按钮无效）；勾选完成或编辑任务后，列表**焦点/选中保持在原任务行**，不再跳行。

### 5.3 优先级、标签与状态

**优先级**（v0.17 起为 8 档）：**无 + P1–P8 共 8 档**，数字越大优先级越高，**P8 为最高档（紧急度最高）**、P1 最低；旗子颜色固定为 **「绿→黄→橙→红」8 档递进色阶**（v0.17.1 起不再随主题派生，一眼即可辨出优先级高低）：P1 最低=**绿**、P5=**琥珀黄**、P8 最高=**深红**；深浅主题与 14 款主题包下均固定可读。改法：点任务行 pill 弹菜单选档，或在编辑页「基本」页签的优先级下拉中选（无 / P1–P8）。

**状态**（编辑页「基本」页签，或看板拖拽）：

| 状态 | 说明 |
| --- | --- |
| 待办 | 默认状态 |
| 进行中 | 正在推进 |
| 等待中 | 暂停执行；可设「**恢复于**」日期，到期自动恢复为待办（应用启动或跨天时执行），等待中**不**弹到点提醒、不打扰 |
| 已完成 | 终态（含子任务的按 roll-up 判定） |
| 已放弃 | 终态 |

> 等待中离开该状态（改为其他状态）时，「恢复于」日期自动清除；看板上有独立的「等待中」列。

**标签**：任务与笔记共用同一套标签。任务行点标签 chip 可快捷编辑；重命名、合并、删除标签统一在 **设置 → 任务与番茄钟 → 标签管理 → 打开标签管理…** 中处理。

### 5.4 时间范围与提醒

在任务编辑页「时间」页签可设置：

- **开始**与**截止**日期（改开始日期会自动联动截止的最小可选值，防止「截止早于开始」）；
- 「**今天**」「**明天**」快捷按钮一键设截止；
- **循环**：不重复 / 每日 / 每周 / 每月 / 自定义（自定义填 RRULE 子集，如 `FREQ=DAILY;INTERVAL=2`）；
- 循环任务完成后会自动**克隆出下一次**（推进截止日，连同子任务、标签、提醒一起复制；COUNT/UNTIL 用尽则不再生成）。

**到点提醒**：设置提醒时刻后，到点弹出托盘提醒窗，可「稍后 5/15/30 分」或「查看」；提醒为一次性语义（发过一次后自动清除）。提醒功能总开关与提醒轮询见设置页「任务与提醒 → 到期提醒」。

**日期与时刻的自然语言输入**：在快速捕获、今日页快速输入、任务页新建任务中都可写日期词甚至**具体时刻**（v0.15 P0-2 增强），解析结果在速记窗里以彩色 chip 实时回显：

| 类别 | 写法示例 |
| --- | --- |
| 日期词 | 今天、明天、后天、大后天、周五、下周一、9月10日、2026-09-09、09-09 |
| 时刻（配合日期） | `明天3点`、`明天下午3点半`、`周五 14:30`、`明天凌晨5点`、`中午12点` |
| 语义 | `明天3点` → 截止=明天 + 提醒=明天 15:00（纯时刻自动按口语时段换算，如「3点」=15:00） |

### 5.5 任务编辑页（编辑任务弹窗）

点任务行「编辑」或按 `F2` 打开统一的**无边框「编辑任务」弹窗**（可最小化/最大化/缩放）。编辑区（v0.17）改为 **3 个页签**，各页内容随页签独立滚动：

| 页签 | 内容 |
| --- | --- |
| 基本 | 标题、状态（待办/进行中/等待中/已完成/已放弃）、「恢复于」日期（仅等待中显示）、优先级（无 / P1–P8） |
| 时间 | 开始 / 截止（今天/明天快捷钮）/ 循环 + 自定义 RRULE |
| 详情 | 标签（输入框回车添加 + 已有标签 chip）、备注（支持 Markdown 与 `[[笔记链接]]`，输入 `[[` 弹出补全）、关联笔记（「+ 挂笔记」搜索挂载；列表每项可「移除」；**关联段落**（§ 按钮）打开笔记并滚动高亮定位）、子任务（「+ 添加子任务」+ 下方勾选/删除列表） |

弹窗重新加载（打开另一任务）时回到「基本」页签。标题栏窗口按钮 hover 时呈圆角填充，关闭钮右上角贴合弹窗圆角。

弹窗底部动作栏从左到右：**开始专注**（启动番茄钟）/ **删除任务**（浅红警示钮）/ …… / **取消** / **保存**。

### 5.6 删除 → 回收站 → 撤销

- 行内「删除」或编辑页「删除任务」：**软删除**，不进确认框，直接弹 Toast「已删除… · Ctrl+Z 撤销」；
- 删除的是**整棵子树**（连同所有子任务），`Ctrl+Z` 可连同子孙一起还原；
- 所有删除内容进入回收站（设置 → 数据与关于 → 回收站…），默认保留 30 天，可还原/彻底删除/清空（详见 §16）。
- 笔记、闪念的删除同样走回收站 + `Ctrl+Z` 撤销链路（文本框有焦点时 `Ctrl+Z` 让位于原生文本撤销，不会误触）。

### 5.7 多选与批量操作

列表视图下可用 `Ctrl/⌘+点选` 或 Shift 范围多选，再点工具栏「**批量**」：

| 操作 | 行为 |
| --- | --- |
| 批量完成（N） | 全部标记完成 |
| 批量改期到今天 | 截止统一改到今天 |
| 批量打标签… | 统一追加标签（逗号分隔） |
| 批量删除 | 全部软删除（可 Ctrl+Z 撤销） |

未选中任何任务时点「批量」会提示先在列表视图中多选。

### 5.8 四象限 / 日历 / 看板

**四象限（Eisenhower）**：行 = 优先级（上重要 / 下不重要），列 = 时间（左紧急 / 右不紧急）。**重要 = 优先级 ≥ P5**（P5 及以上，8 档语义见 §5.3）。

| 象限 | 规则 |
| --- | --- |
| 左上 重要且紧急 | 重要（≥P5）+ 今天截止 |
| 右上 重要不紧急 | 重要（≥P5）+ 无截止 |
| 左下 紧急不重要 | 不重要（<P5）+ 今天截止 |
| 右下 不重要不紧急 | 不重要（<P5）+ 无截止 |

已完成（roll-up）任务不进入象限；每个任务行自带独立勾选框可完成/恢复；**按住任务拖到另一个象限**即改优先级与截止（换象限），单击标题打开编辑页。

**子树展开（v0.17，四象限/看板/日历通用）**：含未完成子任务的父任务行右侧有 **「▸/▾ N 子」chip**（N = 未完成子任务数，叶任务不显示）；点击展开/收起其**未完成子任务**——子任务以缩进形式排在父任务下方（四象限内随父框显示、日历里排在「当日任务」清单、看板上在父卡所在列内），每行可勾选完成或点击打开。展开状态跨视图切换保持（切走再回来不重置）。

**日历**：月历每个日期格内按优先级色绘制任务**胶囊**：有开始+截止的任务在区间内每天都显示、仅截止的任务只在截止当天、仅开始的任务只在开始当天、无日期的任务落在「今日」格。悬浮胶囊显示详情 tooltip；点击胶囊打开该任务编辑页；**按住胶囊拖到另一天即改期**。右侧「当日任务」面板列出所点日期的任务清单（行内可勾选完成/点击打开，父任务行同带「▸/▾ N 子」展开 chip）；「日历显示已完成任务」开关（默认关）在设置中调整，改动即时生效。

**看板**：按状态分列——待办 / 进行中 / 等待中 / 已完成 / 已放弃。**拖拽卡片到其他列即改状态**；每列顶部可「+ 新建任务」直接落入该列状态；列计数与标签溢出（+N）实时更新；父任务卡同样带「▸/▾ N 子」chip，在列内展开/收起其未完成子任务（缩进卡片显示，可勾选/打开）。

### 5.9 收件箱（未整理任务）

GTD 方案 A（收集箱语义）：**所有「新建/快速新建任务」默认落收件箱**，只有当你明确处在一个具体「列表」上下文时（任务页当前视图为该列表），新建才落进该列表——在智能清单、分组、标签、收件箱、今日等视图里新建一律先进收件箱（`list_id=None`）。

- 收件箱页签「**任务收件箱 · N**」，N = 未完成且未归列表的任务数（按 roll-up 有效统计）；
- 任务行右键「**移动到列表**」→ 弹出分组树形菜单，选定列表即完成整理闭环（选列表时也可直接键入过滤）；
- 空状态提示「收件箱是空的，快速收集的任务会先落在这里」。

## 6. 快速捕获与语法糖

### 6.1 入口

| 入口 | 触发 | 说明 |
| --- | --- | --- |
| 快速捕获迷你窗（应用内） | `Ctrl+N` | 480px 置顶小窗，输入回车即建 |
| 快速捕获迷你窗（全局） | `Ctrl+Alt+N`（默认，可在设置改键） | 任何应用里直接唤起 |
| 划选速记（全局，v0.17） | `Ctrl+Shift+U`（默认，可在设置改键） | 读取任意应用里**划选的文字** → 预填快速捕获窗（详见下） |
| 今日页快速输入框 | 回车 | 同一条快速建任务管线 |
| 桌面浮窗快速输入 | 回车 | 同语法糖 |
| 新建笔记 | `Ctrl+Shift+N` | 弹出「新建笔记」名称+类型弹窗 |

小窗**失焦自动关闭**，不会残留；外观统一为「标题栏 + 16px 圆角」弹窗样式（v0.17.1，与其他弹窗一致）；唤出位置优先落在**鼠标所在屏幕**（多屏用户不会跑到主屏去）。输入时语法糖解析结果以彩色 chip 实时回显（如「优先级 P8」「截止 明天 15:00」），可边输边核对。 **窗口高度自适应（v0.17.2）**：小窗高度会随语法糖提示（彩色 chip）的**行数自动伸缩**——没有语法糖时紧凑（约 120px），语法糖较多换行时自动变高，不会出现大片空白或被挤压；标题栏同时改为**紧凑样式**，把更多高度留给输入内容。

**划选速记（v0.17）**：在任意应用里划选一段文字后按 `Ctrl+Shift+U`，知行会读取该选区并**预填快速捕获窗**：选区首行作标题填入输入框（超长自动截断），余下原文暂存，回车即建任务并**把原文一并写入任务备注**（内容不丢失）；光标停在标题行尾，可继续追加 `!1 @列表 #标签` 等语法糖。与划词捕获（§6.4）同走选区读取管线：macOS 需要辅助功能授权，未授权时**自动降级读取剪贴板**并提示；无选中且剪贴板为空时只提示、不弹窗；主窗隐藏时提示改走系统托盘气泡。

### 6.2 语法糖一览

在任意快速输入（速记窗 / 今日快速输入 / 新建任务弹窗）中：

| 写法 | 含义 | 示例 |
| --- | --- | --- |
| `!1` / `!2` / `!3`（也支持 `!!!`/`!!`/`!`） | v0.17 语义：`!1`=最高档 **P8**、`!2`=中档 **P5**、`!3`=低档 **P2**；`!!!`=P8、`!!`=P5、`!`=P2（保留旧肌肉记忆，完整 8 档 P1–P8 见 §5.3） | `!2 给客户回邮件` |
| `@列表名` | 放入同名**列表**（需已存在，仅匹配列表不匹配分组；找不到则回落默认落点） | `@我的清单 周报` |
| `#标签` | 打标签（可多个） | `#工作 #客户` |
| 日期词 | 设截止日（今天/明天/后天/周五/下周一/9月10日/MM-DD…） | `周五前 交付方案` |
| 日期词+时刻 | 设截止 + 到点提醒 | `明天3点 交周报`、`下午3点半 开会` |
| 修饰词 | `周五前`、`明天之内` 中「前/之内」会被剔除，不影响日期 | `明天前 给老板答复` |

### 6.3 默认落点（收件箱）

快速捕获 / 今日页 / 浮窗产生的任务**默认进入收件箱**（未整理区），保证「先收集、后整理」不打断心流；只有 `@列表` 命中了真实列表、或任务页当前正处在一个具体列表中时才直接落列表。

> **默认截止**：快速输入未写日期词时，任务截止日自动设为**今天**（写 `周五前`/`明天` 等才落到对应日期）。要设「无截止」请到任务编辑页清除截止日期。

### 6.4 划词捕获（全局）

在**任意应用**里划选文字，按默认全局热键 **`Ctrl+Shift+S`**（可在设置改键），会在鼠标附近浮出**捕获卡**：

- 顶部标题「捕获 · Esc 取消」，下方灰底引用显示摘录（截断）与来源应用；
- 一行备注（可空）；
- **五去向按钮**（点按或单键直达）：

| 去向 | 按键 | 行为 |
| --- | --- | --- |
| 闪念 | `F` | 存入闪念收件箱（记录来源应用/URL） |
| 任务 | `T` | 新建任务（标题取摘录首行，备注带回「捕获内容：…」） |
| 笔记 | `N` | 以摘录为正文**新建一篇笔记**（备注作标题） |
| 入分组 | `G` | 卡内展开目标选择器 → 摘录作为新任务落入所选列表/分组 |
| 子任务 | `U` | 目标选择器 → 摘录成为所选父任务下的子待办 |

- `G`/`U` 展开**内联目标选择器**：最近使用目标置顶 + 键入即模糊搜索；选定后卡片即时回显「将添加到：…」；**上次选择会被记忆**，下次再划词可一键直达默认目标；
- 提交成功弹 Toast，多数带「去查看」按钮可直接跳转定位；
- 全程不打断原应用：程序备份并恢复你的剪贴板，不破坏原选区。

**平台权限与降级**：

- macOS：划词需要「辅助功能」权限（系统设置 → 隐私与安全性 → 辅助功能）。未授权时自动降级为**剪贴板捕获**（先复制、再按热键），捕获卡内会显示引导提示，设置页「捕获与浮窗 → 捕获」也有说明文字；
- Windows：无需特殊权限；Linux：X11 下可用，Wayland 降级为应用内捕获；
- 捕获内容只在本地处理，不写入日志明文。

## 8. 桌面浮窗（F10）

### 8.1 开关与显隐

- 默认开启（设置 → 捕获与浮窗 → 桌面浮窗 → 启用桌面浮窗）；
- 手动显隐：托盘菜单「显示/隐藏浮窗」、全局热键 `Ctrl+Shift+D`（默认，可改键）、命令面板「显隐桌面浮窗」；
- **与主窗联动**：主窗显示/启动 → 自动隐藏浮窗；主窗关闭/最小化（或关闭主窗时选择了「缩到浮窗」）→ 自动显示浮窗；从浮窗点「打开主程序」→ 主窗回到前台、浮窗自动收起；
- 关闭主窗口的默认行为是「缩到浮窗」继续常驻托盘（可在设置改回直接退出）。

### 8.2 形态与操作

单形态卡片（约 290×380，最小可缩到 200×160）：

- 顶部**快速输入框**：输入回车即建（语法糖同主窗，见 §6）；
- 中部**今日任务树**：占满布局，默认全部展开，显示父任务 → 缩进子任务；行控件与主窗同款——勾选完成（roll-up）、单击折叠/展开、双击行内改标题、悬浮「+/编辑/删除」胶囊、点优先级 pill / 标签 chip 快捷编辑、行内「专注」；
- 左下角「打开主程序」图标按钮；
- 勾选/添加/编辑与主窗口**事件驱动双向实时同步**（同一数据库 + 事件总线，延迟 < 1s）。

### 8.3 外观与几何

- **拖拽**：按住卡片拖动，松手自动记忆位置与尺寸（下次启动还原）；
- **边缘缩放**：鼠标移到卡片边缘/四角出现缩放光标，可自由调大小（下限 200×160）；
- **透明度**：设置 → 桌面浮窗 → 透明度滑杆（60–100%，默认 85%），改值即时生效；
- **贴边半隐**：把浮窗拖到屏幕左/右边缘即吸附成 10px 小把手，鼠标靠近时 200ms 滑出完整卡片；双击把手或右键菜单可恢复；
- **鼠标穿透**：设置 → 桌面浮窗 → 鼠标穿透（默认关）。开启后浮窗不挡鼠标操作（仍可用热键/托盘菜单唤回操作）；
- 主题、强调色、深浅模式与主程序实时一致；外观为 12px 圆角卡片。

### 8.4 右键菜单

浮窗上右键：**今日视图**（打开主程序今日页）/ **贴边停靠** / **取消贴边** / **隐藏浮窗**。

## 9. 笔记管理

### 9.1 五类笔记格式

| 格式 | 说明 |
| --- | --- |
| Markdown | 默认；语法高亮 + `[[链接]]` + 代码块高亮（pygments）+ 三态预览 |
| 富文本 | 所见即所得：字号/颜色、加粗斜体下划线、H1–H3、列表、对齐、**贴图**、文件附件 |
| Word (.docx) | 应用内编辑并写回文件（python-docx，尽量保留格式） |
| Excel (.xlsx) | 应用内编辑（表格控件，保留原工作簿格式），可新建空白文件 |
| 链接 | **可保存多条链接**：每条含**标题 + 目标**（网页 URL 或本地文件路径），可逐条**单独打开**；本地文本/可解析文件提供内嵌预览 |

新建笔记统一走**新建笔记弹窗**（`Ctrl+Shift+N`、笔记页「＋ 新笔记」、图谱「新建」等入口皆同）：输入**笔记名称**、选择**类型**；选 Word/Excel/链接时还需填写「目标」（可「浏览…」选本地文件，Word/Excel 不选文件则自动建空白文件）。名称留空自动回退「未命名笔记」。

> **链接笔记的多链接（v0.17.2）**：打开链接型笔记后，编辑区上方有「**添加链接 / 编辑 / 删除**」：点「添加链接」先填**标题**（用来区分同类链接，如「项目文档」「设计稿」）、再填**地址**；列表里每条右侧都有独立的「**打开**」按钮，可分别打开，互不影响。既有只存一条链接的旧笔记会自动按单条显示，直接编辑即可升级为多条。

### 9.2 笔记树（文件夹体系）

笔记页左侧为**单棵笔记树**（文件夹为父节点、笔记为子节点）：

- 顶层虚拟节点「**全部笔记**」只收纳**未归属任何文件夹**的笔记（不再强制聚合全部笔记）；
- 文件夹可**嵌套**；若系统没有任何文件夹，会自动建一个默认「**我的笔记**」；
- 顶部搜索框按标题即时过滤整棵树（命中笔记会保留其文件夹祖先路径）；
- 笔记行（v0.17.1 起）标题前带**类型小图标**，悬浮右侧「**重命名 / 置顶 / 删除**」为**图标按钮**（与任务行悬浮按钮风格一致）；置顶笔记排在列表最前并带强调色小竖条；
- **文件夹行**悬浮右侧「**＋笔记 / ＋文件夹 / 重命名 / 删除**」同为**图标按钮**（v0.17.1）：＋笔记在该文件夹下新建、「＋文件夹」建子文件夹（可递归）、删除文件夹时其内笔记回落「全部笔记」、子文件夹上移一级（**不会删除任何笔记**）；
- 点击**文件夹行**会**高亮选中**该行（v0.17.1，选中反馈与笔记/任务行一致）；
- 展开/折叠文件夹带 chevron 平滑旋转动画；刷新后恢复原选中节点。

### 9.3 Markdown 编辑器

- 格式工具栏：B / I / H1 / H2 / H3 / • 列表 / 1. 列表 / 链接 / 代码块 / **保存 · 版本历史 · 查找替换** / 预览（v0.17.2：后三个按钮与格式按钮同款样式，统一排在工具栏右端）；

- **自动保存**：停止输入 1s 后防抖保存，工具栏出现「已保存 HH:MM」；也可 `Ctrl+S` 或点工具栏「保存」主动保存；

### 9.4 富文本编辑器

- 工具栏含 B/I/U、H1–H3、无序/有序列表、左/中/右对齐、字号、颜色、插入图片、插入附件；

- 同样 1s 防抖自动保存 + `Ctrl+S`；选中文字右键可「转为任务」。

## 10.5 工作流（Workflow）

工作流用于把**重复发生、步骤固定**的事情沉淀成模板，一键启动后**自动拆解为待办**，
并和你的知识库、任务列表连成一体。一句话：**用笔记做指引，用流程定步骤，用任务去落地**。

### 10.5.1 界面构成

从左侧导航进入「**工作流**」，页面分三栏：

| 区域 | 内容 |
| --- | --- |
| 左·流程模板 | 模板列表（显示「名称（N 步）」）；底部「新建 / 删除」；**右键**模板可「复制一份 / 重命名… / 启动实例」 |
| 中·流程编排 | 工具栏 + **节点画布**（矩形步骤节点 + 连线）+ 底部提示行 |
| 右·运行实例 | 实例列表（`[状态] 标题 进度`）；底部「启动实例 / 终止」；选中实例后列出各步骤完成情况 |

### 10.5.2 编排一个流程

1. **新建模板**：点左下「新建」，输入名称（如「新项目启动审核」）——会自动带上一个「第一步」节点。
2. **添加步骤**：点工具栏「＋ 步骤」，填写（**v0.17.4**：若当前已选中某个节点，新步骤会**插入到它之后**，并可勾选「作为其条件分支」）：
   - **标题**（必填）：这一步要做什么；
   - **说明**：补充信息（可选）；
   - **SOP 文档**：从你的笔记里选一篇作为这一步的指导文档（可选，很有用）；
   - **动作**：这一步要不要顺带做点什么 ——
     - `无动作`：纯人工步骤（默认）；
     - `打开绑定文档`：执行时直接打开上面那篇笔记；
     - `打开网址`：执行时在浏览器打开指定网址；
     - `运行本地命令（有风险）`：执行时启动本机进程。**选择它时保存与执行都会二次确认**，请确保命令来源可信。
   - **条件**：进入这一步的前提（自由文本，供你自己/团队判断，不会自动求值）。
3. **调整顺序**：选中节点后用「上移 / 下移」；也可以在画布上**拖动节点**摆放位置。
4. **设置条件分支**：选中某节点 →「设为条件分支」→ 画布进入连线模式 → **点击目标节点**即建立分支（画布上以**虚线**表示，与顺序实线区分）。按 `Esc` 取消。
   - 执行时：**满足分支就走分支**，否则按顺序走下一步。
   - 如果分支形成了环，保存会被拒绝并在提示行说明原因。
5. **选择启动策略**（工具栏右侧）：
   - `只生成第一步待办`（默认）：待办列表更干净，完成一步自动出现下一步；
   - `一次性生成全部待办`：适合想一揽全局的场景。

> **画布操作（v0.17.4 起）**：滚轮缩放；**空白处按住左键拖动**即可平移画布（连线模式下点空白同样平移），中键/右键拖动也保留；左键点节点=选中/拖动节点、点连线=选中连线。「**适配视图**」把所有节点收进视野，「**一键对齐**」把散落的节点重置为整齐的纵向排布。
>
> **节点编辑（v0.17.4 起）**：**双击节点**即可打开编辑；也可先单击选中节点，再用工具栏「编辑 / 上移 / 下移 / 删除步骤」。节点信息分三层显示：左上角序号、标题（最多两行，超长自动省略）、底部角标（文档 / 动作 / 条件 / 分支）。

### 10.5.3 启动与运行

点「**启动实例**」（或在模板右键菜单里选）即开始一次具体运行。实例列表会显示它的状态与进度：

- **进行中**：还没走完；
- **已完成**：所有步骤都完成了（自动标记）；
- **已终止**：你手动终止了它。

选中实例可看到各步骤的完成情况（✅ / ⬜）。运行中的实例可以「终止」；**有运行中实例的模板不允许删除**（避免流程走到一半失去定义）。

### 10.5.4 与任务的双向绑定 ⭐

这是工作流最有用的地方 —— 流程和任务可以互相驱动：

**① 任务 → 流程：从一个任务启动流程**

在任务页选中一个任务，打开右侧「**速览**」面板，里面有一张「**工作流**」卡片：

- 若该任务还没启动过流程，点「**启动工作流…**」选择模板即可；
- 若已启动，卡片会列出实例的状态、进度与各步骤完成情况。

启动后，流程的**第一步会立刻变成这个任务的子任务**（在任务列表里能看到），后续步骤随进度逐步出现。

**② 流程 → 任务：完成任务即推进流程**

流程的每一步都是**真实任务**（标题带流程名前缀，如「新项目启动审核：提交立项」）：

- 勾选完成该任务 → **流程自动推进到下一步**，并把新步骤下发为待办；
- 走到最后一步完成 → 整个实例**自动标记为「已完成」**。

所以日常使用中你**只需要专注任务列表**：该做什么、下一步是什么，流程会自动帮你铺好。

**③ 与知识库联动**

如果步骤绑定了 SOP 文档，下发的任务备注里会自动写入 `[[笔记标题]]` 链接 —— 点开任务就能直达那篇指导文档，不用再去翻笔记库。

### 10.5.5 一个例子

把「新项目启动审核」做成模板：

| 步骤 | SOP 文档 | 动作 |
| --- | --- | --- |
| 提交立项申请 | 《立项材料清单》 | 打开绑定文档 |
| 主管审批 | 《审批要点》 | 无 |
| 归档并通知 | — | 运行本地命令（如归档脚本） |

之后每次有新项目，只需在任务里点「启动工作流…」选它：第一步「提交立项申请」立刻出现在待办里，
并带着《立项材料清单》的链接；做完一步，下一步自动出现，直到流程走完。

## 11. 专注与提醒

### 11.1 番茄钟

- **启动**：任务行悬浮「专注」图标、任务编辑页「开始专注」按钮、任务页/浮窗行内入口；
- 倒计时悬浮条常驻窗口角落（置顶小条：呼吸圆点 + 倒计时 + 任务名 + 暂停/结束），专注结束托盘通知并**自动记录**（时长与任务进入统计）；
- 专注时长（5–90 分钟，默认 25）与休息时长（1–30 分钟，默认 5）在 **设置 → 任务与番茄钟 → 番茄钟** 调整；可开启「专注结束自动休息」；
- **中断**：专注中点「结束」会先弹出原因选择（被打断/临时有事/分心/任务调整/其他），中断记录与正常完成区分；休息态可继续/跳过；
- 番茄钟在窗口最小化/缩到浮窗时继续运行。

### 11.2 任务提醒

- 任务的提醒时刻到点后弹**托盘提醒窗**：「稍后 5 分 / 15 分 / 30 分」= 顺延提醒（snooze），「查看」= 跳到任务；
- 提醒一次性发出后自动清除，不会每 30s 重复打扰；
- 「等待中」任务**不弹**到点提醒（暂停不打扰）；「到期提醒」总开关在设置中。

### 11.3 系统托盘

- 托盘常驻，图标随主题换色；tooltip 实时显示「知行 ZhiXing · 今日待办 N」；
- 右键菜单：**显示主窗口 / 快速添加任务 (Ctrl+Alt+N) / 划词捕获 (Ctrl+Shift+S) / 显示隐藏浮窗 / 退出**；
- 关闭主窗口默认「缩到浮窗」（可设置退出）；从托盘可随时恢复。

## 14. 深链（zhixing://）

应用内置 `zhixing://` 深链解析与单实例转发（v0.15 P1-4），可让外部工具唤起应用并定位到具体对象：

| URL | 跳转目标 |
| --- | --- |
| `zhixing://task/<id>` | 打开任务编辑 |
| `zhixing://note/<id>` | 打开笔记 |
| `zhixing://note/<id>?block=<key>` | 打开笔记并**滚动高亮定位段落**（Markdown 笔记） |
| `zhixing://flash/<id>` | 跳收件箱「闪念」页签并定位该闪念 |
| `zhixing://folder/<id>` | 定位笔记文件夹 |

**使用场景与示例**：

- 正式打包安装版将 `zhixing` 协议注册到系统后，在浏览器/快捷指令/Alfred 等中点击或调用 `zhixing://task/12` 即唤起并定位；
- 源码/命令行运行时可把 URL 作为启动参数：`python -m zhixing "zhixing://note/3?block=..."`；
- 若应用已在运行，深链会经本地 IPC 转发给主实例（先唤起主窗口再跳转）；应用未在运行则随启动参数解析并在主窗口就绪后派发。

## 16. 数据安全与迁移

### 16.1 存储与可靠性

- 数据库采用 **SQLite + WAL 模式**，读写并发安全、崩溃不损坏数据；
- 结构升级采用**线性版本迁移**（当前 schema v7），启动自动升级，**升级前强制自动备份**；迁移失败会进入**只读模式**并在窗口顶部显示红色横幅 + 「恢复备份」入口（不会崩坏数据）。

### 16.2 自动备份

- 每次启动在后台自动备份主库到数据目录 `backups/`，**保留最近 10 份**（超出自动清理）；
- 备份用 SQLite 在线备份 API 保证一致性；
- 手动「立即备份」/「恢复备份…」在设置 → 数据与关于中执行（恢复前先自动备份当前库）。

### 16.3 导出与导入

| 操作 | 内容 |
| --- | --- |
| 导出 JSON | 全量：任务/笔记/链接/标签/闪念等（含四表以上，供完整迁移/备份） |
| 导出笔记 MD | 全部笔记打成 Markdown zip |
| 导出任务 CSV | 任务表格 |
| 导入 MD 文件夹… | 把一个本地 Markdown 文件夹作为笔记导入 |
| 导入 JSON 备份… | 恢复全量 JSON（会**覆盖当前全部数据**；导入前自动备份，且有明确确认） |

### 16.4 回收站

- 删除任务/笔记/闪念 = 软删除进回收站（不弹确认框，可 `Ctrl+Z` 撤销）；
- **回收站对话框**（设置 → 数据与关于 → 回收站…）：任务 / 笔记 / 闪念三个页签，可「还原」（任务连同子孙）/「彻底删除」/「清空回收站」；
- 默认保留 **30 天**（保留天数可在设置调整 1–365）；应用运行中跨天时自动清理超过保留期的记录。

### 16.5 迁移小贴士

要换电脑 / 重装时：新机器装好后，先用「设置 → 数据与关于 → 数据 → 打开目录」找到 `backups/`，或直接导出一份 JSON；随后在设置里「导入 JSON 备份…」即可整库还原（推荐保留 JSON 到外部介质）。

## 17. 常见问题 FAQ

**Q1：我的数据存在哪里？怎么备份？**
数据 100% 在本机：macOS `~/Library/Application Support/ZhiXing/`、Windows `%APPDATA%\ZhiXing\`、Linux `~/.zhixing/`（`ZHIXING_HOME` 可覆盖）。设置 → 数据与关于可打开目录；每次启动自动备份到 `backups/`（保留 10 份），也可以手动「立即备份」「导出 JSON」并定期把 JSON 存到外部介质。

**Q2：全局热键（划词捕获 / 读取选中并速记 / 快速任务 / 浮窗）不生效怎么办？**
先看设置 → 捕获与浮窗中该热键后的注册状态：未授权/冲突会显示提示并自动降级（如划词降级为「剪贴板捕获」，功能仍可用）。macOS 需到 系统设置 → 隐私与安全性 → 辅助功能 授权；Linux Wayland 下全局热键不可用属平台限制（应用内快捷键仍可用）；Windows 需确认热键没被其他软件占用——可在设置里点「改键」换一组。

**Q3：桌面浮窗不显示 / 不见了？**
① 设置 → 捕获与浮窗 → 桌面浮窗 → 启用桌面浮窗是否打开；② 主窗可见时浮窗会**自动隐藏**（联动），把主窗最小化/关闭（缩到浮窗）它才会出现；③ 用托盘菜单「显示/隐藏浮窗」或 `Ctrl+Shift+D` 手动唤出；④ 若开了「鼠标穿透」，需要先用热键/托盘退出穿透模式才能点它。

**Q4：怎么切换主题 / 换颜色？**
设置 → 外观：模式（浅/深/跟随系统）× 主题包（14 款）× 强调色（8 色）三轴组合，即时全局生效（含浮窗与图表）。「关于」页显示的 `v0.1.0` 是代码占位版本号，不代表功能版本（见文首导航）。

**Q5：重复打开会开两个窗口 / 数据会冲突吗？**
不会。应用是单实例：第二次启动会提示已在运行并直接退出；若带了 `zhixing://` 深链会转发给主实例定位。数据库同时被两个进程打开时会给出明确错误提示（请勿手动复制数据库文件边运行边改）。

**Q6：删除的东西还能找回吗？**
能。任务/笔记/闪念的删除是软删除：先按 `Ctrl+Z` 可立即撤销；也可在 设置 → 数据与关于 → 回收站… 中还原（默认保留 30 天）。只有「彻底删除 / 清空回收站」或超过保留期被自动清理才是不可逆的。

**Q7：为什么父任务勾了「完成」却不显示完成？**
任务带子任务时按 roll-up 规则判定：只有**所有子任务（递归）都完成**，父任务才会被统计为完成并显示完成态（勾选/逾期/统计各处一致）。请把子任务逐条勾完——最后一条完成后父任务会自动变完成，无需再勾父任务。

**Q8：笔记里怎么链接别的笔记？反链在哪里看？**
在 Markdown/任务备注编辑区输入 `[[` 会自动弹出标题补全，回车插入链接。打开任意笔记时，编辑器底部「链接」面板按 **引用 / 反链 / 归属** 三组页签展示（v0.17，见 §9.5）：想看「谁链接到我」切到**反链**页，附上下文摘录可点击跳回；「图谱」页也能看到对应连线。

**Q9：任务时间能不能用自然语言填？「明天3点」是什么意思？**
可以。速记窗/快速输入支持 今天/明天/周五/下周一/9月10日 等日期词与 `3点`/`下午3点半`/`14:30` 等时刻（见 §6 语法糖表）。`明天3点 交周报` = 截止明天 + 提醒明天 15:00（口语无修饰的 1–6 点按下午处理）；纯日期词只设截止。

**Q10：快捷键在设置里能改吗？**
划词捕获（Ctrl+Shift+S）、读取选中并速记（Ctrl+Shift+U）、快速任务（Ctrl+Alt+N）、浮窗显隐（Ctrl+Shift+D）四个全局热键可改（设置 → 捕获与浮窗 → 改键，直接按下新组合键即识别）；其余快捷键为内置固定，可在设置 → 快捷键页查看全表。

**Q11：能不能用 zhixing:// 从浏览器唤起定位？（深链）**
支持。URL 格式见 §14：`zhixing://task|note|flash|folder/<id>`，段落定位加 `?block=<key>`。正式打包版注册协议后，浏览器/快捷指令点击即可唤起并跳转；命令行运行时也可作为启动参数传入（未运行时随启动解析、已运行时经 IPC 转发给主实例）。

**Q12：v0.17 起优先级变成 P1–P8，原来习惯的「低 / 中 / 高」怎么办？**
优先级现在是 **无 + P1–P8 共 8 档**，数字越大越紧急（P8 最高）。旧数据已自动迁移：原来「低 / 中 / 高」对应 **P2 / P5 / P8**。快速输入里 `!1` / `!2` / `!3`（或 `!!!`/`!!`/`!`）仍保留旧手感，等价于 P8 / P5 / P2（详见 §6.2）；四象限里的「重要」判定为 **优先级 ≥ P5**。

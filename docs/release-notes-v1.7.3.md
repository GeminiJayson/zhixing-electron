### 本版要点：先写 [[标题]]、回头再建笔记，链接也会补上

任务备注里写 [[笔记标题]] 会变成任务与笔记的关联（任务行的 ⇄N、图谱里的边）。但此前有个
很自然的顺序会静默失效：**先在任务正文里写下 [[某个标题]]，过一会儿才真的去建那篇笔记**。
写正文的那一刻笔记还不存在，解析不到标题自然不落链 —— 而之后再没有任何人去重解析一遍。
结果就是 [[标题]] 明明写在正文里，⇄N 却一直是 0，全程不报错。

现在笔记一旦建出来（或改名成该标题），正文里已经写着它的任务会自动补上关联；
改名时旧标题对应的关联也会跟着掉，不会留下指向旧名的残链。

另外新增了一个「重新解析正文链接」的接口，专门用来修**在这版之前就已经写坏**的历史数据。

### 一并说明

上一轮我报过一条「中文检索跨分词边界查不到」的问题，**复核后不成立**：我当时是用裸 SQL 直接
测全文索引下的结论，绕过了应用自己的检索路径。实际上应用会先把查询词按中文分词切开再拼前缀
匹配，跨分词边界的检索是正常的（实测命中 8 条）。这条已从缺陷清单移除，并改写成一条回归护栏，
防止以后改动把它弄坏。

### 兼容性

- 数据库仍是 schema v12，无迁移。
- 与 Python 版继续共用同一只库文件，顺序打开即可，不要同时打开。
- 升级安装不会动你的数据；已存在的错误关联不会自动修复，需要时可用新接口重跑一遍。

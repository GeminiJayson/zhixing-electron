### 甘特图：条的颜色改成看「临期状态」

以前整条时间轴上的颜色只表达优先级，满屏同一个色系，看不出哪几件事快到期了。现在改由**截止日与今天的关系**决定：

| 档位 | 条件 | 颜色 |
| --- | --- | --- |
| 已逾期 | 截止日早于今天、且未完成 | `--danger` |
| 今天到期 | 截止日 = 今天 | `--accent-warm` |
| 三天内到期 | 今天之后 1~3 天 | `--accent-warm` 与 `--accent` 的 55% : 45% 混色 |
| 更远 / 无截止 | 其余 | 强调色（默认） |
| 已完成 | 已完成 | 转灰，不再喊"逾期" |

判据与任务行标题的 `dueLabel` 是**同一套语义**（`shared/gantt.ts` 的 `ganttTone`），阈值 `GANTT_SOON_DAYS = 3`。

**优先级没有被丢掉**：它仍是名称列前那个小圆点（与列表的旗子、日历的圆点同一份色板）。两维各表一维，不再抢同一条色带 —— e2e 里专门造了三条**优先级相同**的临期任务，验的就是"颜色确实不跟优先级走"。

顺带堵了一个数据坑：库里有些任务带着哨兵日期（如 `1753-09-14`，原版留下的"无截止"写法），离今天两万七千天。照差值判会得到一条"逾期两万天"的红条，所以加了 `GANTT_FAR_DAYS = 3650` 的防护（`dueLabel` 里本来就有同一条）。颜色之外，条的悬浮提示里也写明了档位（"已逾期 / 今天到期 / 三天内到期"），不靠辨色。

### 甘特图：时间窗口可按住拖动

在内容区空白处按住左右拖，视窗跟着平移 —— 往右拖露出更早的一段，读起来就是"内容跟着手走"。**日 / 周 / 月三档同一套手势。**

- 位移按「轨道实测宽度 → 视窗天数」折算，所以三档拖同样的像素走的天数各不相同；
- **松手才对齐**到粒度边界（周档落到周一、月档落到月初）—— 拖动过程中对齐会一跳一跳；
- **双击空白处回到今天**；
- 从任务条或标题上起手**不**触发平移（它们各自要打开任务），从名称列起手也不触发；
- 拖动时整块禁止选中文本（光标 `grab` → `grabbing`），否则一路拖过去会把标题刷成蓝色选区。

### 顺带修掉：甘特图的刻度字号不跟设置走

上一版把字号做成一条完整阶梯时，`--text-2xs` 漏写成了硬编码的 `9px`（其余各级都是 `calc(var(--text-body) * k)`）。甘特图的刻度与视窗范围用的正是这一级，于是设置里调字号时**只有它不动**。现在改成 `calc(var(--text-body) * 0.667)`，实测：基准 12px 时 8.004px、14px 时 9.338px。

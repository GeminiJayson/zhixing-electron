### 日历口径可以配了（README 进度表里的最后一项结构性缺口）

同一批任务在日历上有两种都合理的读法：「**排期占用**」（这周有多满）与「**交付节点**」（哪天必须交）。
此前写死了前者 —— 有开始与截止的任务按 `start_date` 逐日铺开，想按截止日看的人只能自己脑补。
设置页「任务与提醒」现在有三项：

| 设置 | 取值 | 默认 |
| --- | --- | --- |
| 日历展开方式 | 区间逐日展开 / 只按截止日 / 只按开始日 | 区间逐日展开 |
| 日历里的无日期任务 | 归入今日 / 不显示 | 归入今日 |
| 每周起始日 | 周一 / 周日 | 周一 |

口径逻辑抽到 `src/shared/calendar.ts`（`groupTasksByDate` / `weekdayLabels` / `addDays`），带 **11 个单测**守着
「哪一天算哪天」—— 这类规则最容易被写散。顺带修掉两处：`calendar_show_done`（日历显示已完成）
此前只写不读，以及 `docs/03` 里一段说「只看 due_date、不展开 start_date」的过时描述。

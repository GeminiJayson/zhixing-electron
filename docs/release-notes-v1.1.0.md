## 知行 ZhiXing 1.1.0

本地优先的个人待办 + 知识图谱桌面端（Windows x64）。数据只存在本机的一只 SQLite 文件里：无需注册账号，不联网也能完整使用。

| 文件 | 说明 |
| --- | --- |
| **Zhixing-1.1.0-x64-setup.exe** | NSIS 安装包：可选安装目录、创建开始菜单/桌面快捷方式、可在设置里卸载 |
| **Zhixing-1.1.0-x64-portable.exe** | 便携版单文件：双击即用，不写注册表、不建快捷方式 |

### 本版要点：工作流

**条件节点现在能拉出两条分支。** 以前条件节点只有一条「成立时跳到」，不成立只能沿着顺序往下走。现在它是完整的两岔路口：

- 菱形节点下方直接写着**判定内容**（例如「人工确认：资料齐全、可以进入审批吗？」），不用再点开详情才知道这个关卡在判什么；
- 菱形左右两个尖角各有一个端口，常驻地标着绿色的**「满足」**与红色的**「不满足」**，两条分支连线也用这两种颜色区分；
- 从端口拖到目标节点就连线，鼠标移到虚线上可删除或拖动端点改挂；编辑弹窗里也可以分别指定两条分支的目标；
- 两条分支都可以留空 —— 留空就按顺序走下一步，**旧模板的行为完全不变**。

跨层的分支（跳过中间节点的那种）改成了「走同侧车道」再进入目标，不会再出现折线穿过中间节点、看起来像线断掉的情况。

**模板栏宽度可以调了。** 模板栏与画布之间多了一条分隔条：拖动改宽（170–460px），也可以聚焦后用 ← / → 微调、Home 复位。宽度记在本地，下次打开还是你调过的宽度。

**实例可以再次运行或删除。** 实例列表每一行新增两个按钮：

- **再次运行**：按同一模板再开一个新实例，旧实例记录原样保留当历史；
- **删除**：只删这一次运行的记录（含步骤↔任务绑定），**模板不会删，已经生成的任务也不会删**，删除前有二次确认。

### 兼容性

- 数据库仍是 schema v12，只增加了一列 Electron 私有附加列（`branch_false_node_id`），打开旧库会自动补列。
- 升级安装不会动你的数据；卸载也不会删除数据。

### 运行环境

Windows 10 / 11 x64。首次启动会在数据目录创建或迁移数据库。

### 校验

本版经过 186 项单测 + 15 项工作流端到端断言（`scripts/wfbranchcheck.mjs`：分支落库与推进、实例再次运行/删除、画布端口与标签、分隔条拖拽）。

本地优先的个人待办 + 知识图谱桌面端（Windows x64）。数据只存在本机的一只 SQLite 文件里：无需注册账号，不联网也能完整使用。

### 本版要点：把 [[标题]] 从任务正文里删掉，关联真的会消失了

任务备注里写的 [[笔记标题]] 会变成任务与笔记的关联，任务行上显示成 ⇄N，图谱里连成一条边。
此前这套关联**只增不减**：把 [[标题]] 从正文里删掉，行还留在库里 —— 于是 ⇄N 计数一直挂着，
图谱里的边也永远不消失，只能眼看着。

现在正文是权威：删掉 [[标题]]，对应的关联、计数、图谱边一起消失。

反过来也不会误伤：手动拉的关联（笔记页「归属任务」、图谱里直接连）**不在正文里出现**，
所以不会被这次对账顺带清掉。库里给每条关联记了来源，两类分别处理：

- 从正文派生的：跟着正文走，正文里没有了就删；
- 手动建立的：只在你自己解除时才删；
- 升级前留下的、分不清来源的：能从正文证实的按派生处理，其余一律保守保留 —— 宁可留一条旧关联，也不误删你手动连的。

### 另外两处（内部质量，用户可感知行为不变）

- 覆盖最广的那个端到端冒烟脚本（seedmonitor）此前统计了问题数却从不设退出码，
  等于这道检查永远不会红。现在有失败就以非零退出。
- 端到端脚本共用的 CDP 骨架抽成了 scripts/lib/cdp.mjs，并加了护栏：样板份数只许减少、不许再长。

### 兼容性

- 数据库仍是 schema v12；新增的一列（关联来源）由初始化逻辑自动补齐，无需迁移。
- 升级安装不会动你的数据。

## 知行 ZhiXing 1.8.0

本地优先的个人待办 + 知识图谱桌面端（Windows x64）。数据只存在本机的一只 SQLite 文件里：无需注册账号，不联网也能完整使用。

| 文件 | 说明 |
| --- | --- |
| **Zhixing-1.8.0-x64-setup.exe** | NSIS 安装包：可选安装目录、创建开始菜单/桌面快捷方式、可在设置里卸载 |
| **Zhixing-1.8.0-x64-portable.exe** | 便携版单文件：双击即用，不写注册表、不建快捷方式 |

### 任务清单：左侧清单栏

任务页左侧新增清单栏，三块内容：

- **清单与分组**：分组树 + 每个清单的未完成计数；右键可新建子清单 / 子分组、重命名、移动到分组、删除。
- **拖拽**：清单和分组都能拖 —— 拖到行与行之间是排序，拖到分组行中间就是移进这个分组。
- **已完成 / 已放弃**：完成或放弃的任务会从所有清单里收走，集中到这两个入口；每一行标出它原来属于哪个清单，并按结束时间倒序。此前完成任务后它只是从当前视图消失，「已完成」藏在工具栏下拉里。

### 智能清单进清单栏

保存的查询（智能清单）从工具栏下拉挪进清单栏第二段：点一下即按表达式过滤，右键可重命名 / 删除，右上 ＋ 把当前筛选存成新的智能清单。选中智能清单会退出清单筛选，两者不叠加 —— 免得两层过滤把结果筛空却看不出是哪一层。

### 标签：笔记也能打标签，颜色可自定义

- 笔记页新增标签条：点「加标签」勾选已有标签或新建；左侧笔记树的行内也会显示标签胶囊（最多两个 +N）。
- 任务与笔记共用同一套标签；点标签弹层里标签左侧的色块即可改色（12 个预设 + 系统取色器），标签管理弹窗里同样能改。
- 胶囊改成实心色块并自动翻转文字色：浅黄、深蓝这类自定义颜色都不会变成「看不见的标签」。

### 外观：强调色与主题包配色都可自定义

- **强调色**：预设色板之外多了一个取色器，任意颜色都能用；强调色上的文字仍会自动校正到可读下限。
- **主题包配色**：设置页新增「主题包配色」一组取色器 —— 页面背景、卡片背景、正文、次要文字、边框、强调浅底。改过的项会被标出来，也可以一键「恢复主题包默认」。
- **浅色 / 深色各存一套**：自定义只覆盖你明确改过的那几个 token，其余仍跟随主题包；换主题包不会丢掉自定义，切明暗也互不影响。
- 清单栏的**计数改用主题强调色**；行内操作按钮**未悬浮时不再占位**，清单名与右侧数字不再被挤。

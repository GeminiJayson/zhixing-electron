### 笔记编辑器：样式终于管用了

富文本与 Word 笔记的工具栏重做。此前**字号和颜色点了没反应** —— 根因是 TipTap 里这两个扩展都往 `textStyle` 这个 mark 上写属性，而它**从来没被注册过**：mark 不在 schema 里，命令就静默失效，不抛错、不进历史。

- **字号**：下拉**显示光标处的实际值**（旧版选完自己弹回，看不出设没设上）
- **颜色**：一排 10 个预设色块，当前色带高亮环；旧版是系统取色器，选完看不出当前色
- **加粗 / 标题 / 列表 / 引用 / 对齐**：全部有了**激活态** —— 光标落在加粗文字里，按钮会亮
- **代码块**：新增语言下拉（13 种），代码块有底色、边框、等宽字体与右上角语言角标

### 任务与笔记的关联：从"手填内部键"到"从列表里挑"

任务编辑器里原有一个让你填「段落块键」的输入框 —— 那是内容指纹（`fp:` + sha1），你无从得知该填什么。现在两步：**选笔记 → 从可关联项列表里挑**。

- **普通笔记**：按段落列出（markdown 一行一段、富文本按块级元素）
- **链接笔记**：一条链接一项（键按 URL 算 —— 改标题不会让关联失效）
- **Excel 笔记**：正文在本地表格里、应用读不到内容，所以填「工作表 + 单元格」（如 `数据!B3`）

**选择笔记的下拉也换了**：带**类型图标** + 按**文件夹分组** + 顶部搜索。原生下拉放不下图标、做不出缩进，所以自绘。

### 循环任务

- **完成时间**：收归到「已完成」时会显示**什么时候完成的**（`今天 14:30` / `昨天 09:05` / `09-28 14:30`）。时刻必须留着 —— 每天循环的任务一天攒好几条
- **自定义循环改成可视化**：不再手写 `FREQ=WEEKLY;INTERVAL=2;COUNT=5`，改成三个选择（频率 / 间隔 / 结束条件）。生成的规则串仍显示出来并配一句人话

### 玻璃拟态与设计系统

- **毛玻璃**：模糊 20→28px、底色不透明度 72%→56%，边框改用一直没人用的 `--glass-border`（此前所有玻璃面走的是 9% 黑的 `--border`，在模糊底上是一条灰线）
- **补了 `.btn` 家族**：它在计划弹窗里被用过一次、却**从未定义**，那个「保存」按钮因此完全没有样式
- **布局原语**：`.u-stack` / `.u-row` / `.u-grid`（自适应）+ `--2/3/4`（固定列），替换掉三个各写一份的栅格
- **卡片外观统一**：七张卡此前底色分两派、圆角两档、内高光只有一张有。按"页面级卡片 = 不透明底 + 8px 圆角 + 顶部内高光"统一
- **标签胶囊**：实心高饱和底改成**同色系淡底 + 同色系文字**，亮暗主题自动适配
- **主题包与强调色联动**：换主题包会带出配套的强调色（14 个包各有推荐色）；你自己挑过色之后不再覆盖。顺带修了**复选框不跟随强调色**（`accent-color` 原来只挂在滑块上）

### Word 笔记：代码块不再丢失

代码块在 docx 往返中会散架。根因有两处：转换器**不认识 `<pre>`**（整块落到"按换行拆段"的兜底分支，缩进与等宽全丢），以及 HTML 清洗白名单里没有 `pre[data-language]`，会**静默剥掉**语言标记。

现在写回时把代码块转成等宽段落（Consolas + 浅灰底纹），语言存成首行的可见标记 `[sql]`；读回时再还原。**在 Word 里直接打开那个 .docx 会看到首行有个 `[sql]`** —— 这是语言不丢的代价，我选了"看得见"而不是"悄悄消失"。

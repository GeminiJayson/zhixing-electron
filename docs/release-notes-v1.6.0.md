## 知行 ZhiXing 1.6.0

本地优先的个人待办 + 知识图谱桌面端（Windows x64）。数据只存在本机的一只 SQLite 文件里：无需注册账号，不联网也能完整使用。

### 下载

| 文件 | 说明 |
| --- | --- |
| **Zhixing-1.6.0-x64-setup.exe** | NSIS 安装包：可选安装目录、创建开始菜单/桌面快捷方式、可在设置里卸载 |
| **Zhixing-1.6.0-x64-portable.exe** | 便携版单文件：双击即用，不写注册表、不建快捷方式 |

### 本版要点

**一、笔记编辑器换了内核，并且全面提速。**

- 富文本换成 **TipTap**（ProseMirror）。原来的实现依赖 `document.execCommand` —— 那个 API 已被标准废弃，只有 Chromium 还在兼容。工具栏全部改用 TipTap 的正式命令，并并入应用原有的 `Toolbar` 框架（字号、颜色、加粗、标题、列表、对齐、链接、图片、附件）。
- 图片一律**缩略图展示**：正文只存几百像素的缩略图，原图经附件接口存到数据目录。**双击图片用原图预览**，完整分辨率不丢。这一条同时也是性能的关键 —— 原来图片以 data URI 内嵌在正文里，一篇笔记放几十张图就会把 HTML 撑成几兆、输入必然卡。
- **存储格式没有变化**：富文本正文仍是 HTML 片段，**已有笔记一条都不需要迁移**。

**二、Excel 换成 ag-grid 虚拟滚动。**

- 用 ag-grid 社区版（MIT）替掉原来手写的 `<table contentEditable>`。原来每一格都进 DOM，行数一多必然卡；ag-grid **只渲染可见的那几十行** —— 实测 3000 行的表，DOM 里只有 20 行。
- 单元格约定写成 `img:<附件路径>` 即渲染成缩略图，双击看原图。
- 它是**懒加载**的：ag-grid 解压 21 MB，只有真的打开 Excel 笔记才会下载（主 bundle 只增加了 5 KB）。

**三、Word 笔记可以导出 .docx。**

- 编辑区里新增「导出 .docx」按钮：把当前内容导成新的 .docx，**原文件保持不动**。
- 说明一点技术边界：.docx 的排版能力严格大于 HTML，**往返一定会有损失**（分页、页眉页脚、精确字号这些 HTML 表达不了）。所以「完整性」由**原件**保证，而不是指望往返无损 —— 导出是另存新文件，原件随时可回溯。

**四、两棵树的阅读体验。**

- 笔记树与工作流树的标题**宽度不足时换行**（原来是省略号，长名字看不全），行尾的按钮与统计胶囊保持垂直居中。
- 文件夹的展开/收起用**不同箭头**；笔记按类型显示**不同图标与颜色**（Markdown / 富文本 / Word / Excel / 链接）。

**五、任务。**

- **已完成的任务可以释放回当前清单**，恢复到待执行状态，**任务层级原样保留**；释放时如果父任务仍是终态，会**连带把祖先一起恢复**（否则子任务会变成找不到父亲的孤儿）。
- **任务清单分类可以编辑**：任务页新增「＋ 清单」与「清单设置」（重命名 / 删除）。
- 进度条改为**从勾选框位置开始**（原先压在缩进与展开箭头上）。

### 兼容性

- 数据库仍是 schema v12，本版没有改动表结构；与 Python 版继续共用同一只库文件，顺序打开即可，不要同时打开。
- 升级安装不会动你的数据；卸载也不会删除数据。

### 运行环境

Windows 10 / 11 x64。首次启动会在数据目录创建或迁移数据库。

### 校验

本版经过 230 项单元测试与多套端到端断言（真实窗口 + 数据库副本）：

- `scripts/taskarchivecheck.mjs`（13 项）：任务归档与释放（含**层级保留**与**连带恢复祖先**）、清单增改删、Word 导出（落盘、不覆盖原件、合法 docx）
- `scripts/attachmentcheck.mjs`（14 项）：附件落盘、图片缩略图、树标题换行与垂直居中、笔记类型图标、编辑器工具栏
- `scripts/excelcheck.mjs`（3 项）：造 3000 行 xlsx → ag-grid 渲染、**虚拟滚动只渲染 20 行**
- `scripts/hotkeyrebindcheck.mjs`、`scripts/flashhotkeycheck.mjs`、`scripts/bloubcheck.mjs`、`scripts/layoutfitcheck.mjs`

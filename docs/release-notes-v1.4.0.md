## 知行 ZhiXing 1.4.0

本地优先的个人待办 + 知识图谱桌面端（Windows x64）。数据只存在本机的一只 SQLite 文件里：无需注册账号，不联网也能完整使用。

### 本版要点

**一、悬浮球换了个形象，还能换体型、换颜色。**

贴在屏幕边缘收成的那颗小球，现在是另一种机器人造型（bloub）：

- **右键 →「身体形状」** 八选一：圆、鹅卵石、方圆、胶囊、三角、六边形、云朵、水滴。选中立刻生效，下次启动还记得。
- **颜色跟着主题强调色走** —— 你在设置里换强调色，球当场就换色，不用重启。
- **去掉了原来那圈白色底盘**：球就是那个形状本身，两只眼睛是真正镂空的，透出它下面的桌面。

有两个细节先说清楚，免得以为是没生效：

1. 自定义体型只在**基础体态**（待机、眨眼、睁大眼、通知）上看得见。其余状态（旋转、爆裂、彗星……）的轮廓**本身就是那段动画**，这是上游的设计。
2. 也是上游的做法：身体下面本来会铺一层与轮廓同色的底，用来遮住绕到球背面的光环。去掉那层底之后，这类状态里光环可能从**眼睛的洞里**闪过一点 —— 球只有 96~160px，实测几乎看不出来。

顺带一提：新形象是 **MIT** 许可，而原来那颗球明确写着「球形角色的视觉形象禁止任何商业用途、且永不提供商业授权」。这一版顺手解掉了第三方清单里那条「将来若商业分发必须移除」的隐患。

**二、新热键：选中的文字直接进闪念（默认 Ctrl+Shift+F）。**

在任意应用里选好文字，直接按 **Ctrl+Shift+F**，这段字就进了闪念收件箱 —— **不弹任何窗口**。改键在「设置 → 任务与提醒 → 全局热键 → 选中入闪念」，托盘菜单里也有同一项。

用法上注意一点：按之前不要先切回知行。一旦把知行带到前台，焦点就离开目标应用了，模拟复制会取不到东西。

**三、改热键不再「假装成功」。**

以前改键有个坑：组合被别的程序占用时其实注册不上，界面却说「已降级为托盘菜单」、保存后还弹「热键已改为 xxx」，于是按下去没反应也不知道为什么。现在：

- 组合被占用时，状态直接写「✗ 未注册：组合已被别的程序占用」；
- 保存后按结果给话：成功才说已改好，失败会提示换一个再试；
- **按下组合的那一刻**就预检，当场告诉你「✓ 这个组合可用」还是「✗ 已被别的程序占用」。

### 兼容性

- 数据库仍是 schema v12，没有新增列、没有迁移。
- 升级安装不会动你的数据；卸载也不会删除数据。

### 运行环境

Windows 10 / 11 x64。首次启动会在数据目录创建或迁移数据库。

### 校验

本版经过 211 项单测 + 四套端到端断言：

- scripts/bloubcheck.mjs（9 项）：球挂着 bloub 的 SVG、mask 里是「身体 + 两只眼睛」、动画在跑、换体型后形状改变、球色等于主题强调色且改色后实时跟随
- scripts/hotkeyrebindcheck.mjs（11 项）：改键全流程 + 成功与失败两种提示文案
- scripts/flashhotkeycheck.mjs（8 项）：设置项、热键注册、动作通道、空选区不写入、不弹新窗口
- scripts/layoutfitcheck.mjs（10 项）：Word / Excel 编辑区铺满、行尾按钮组未悬浮不占位

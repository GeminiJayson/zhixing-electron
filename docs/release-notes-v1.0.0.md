## 知行 ZhiXing 1.0.0

本地优先的个人待办 + 知识图谱桌面端（Windows x64）。数据只存在本机的一只 SQLite 文件里：无需注册账号，不联网也能完整使用。

### 下载

| 文件 | 说明 |
| --- | --- |
| **Zhixing-1.0.0-x64-setup.exe** | NSIS 安装包：可选安装目录、创建开始菜单/桌面快捷方式、可在设置里卸载 |
| **Zhixing-1.0.0-x64-portable.exe** | 便携版单文件：双击即用，不写注册表、不建快捷方式 |

### 本版要点

**任务**：多层子任务、清单、标签、优先级、截止与重复规则；列表 / 四象限 / 日历 / 看板四视图；软删除与回收站。

**笔记**：Markdown（CodeMirror 6）、富文本、Word / Excel、链接笔记（三列表格，可打开/删除）；文件夹树、双链、标签、版本历史与回滚。

**捕捉**：三个全局热键都会**真正读取你当前选中的文字** —— 划词捕获、读取选中并速记、快速任务（先模拟一次 Ctrl+C 取走选区的文本与 HTML，再把剪贴板原样还回）。三者都跑在**独立小窗口**里：无边框透明圆角卡片、置顶居中，**不会把主窗口拽到前台**。

**工作流**：把「做事的顺序」固化成模板 —— 步骤、条件（人工确认 / 任务状态 / 脚本退出码 / 上一步结果）、命令与脚本动作（带期望退出码）。模板支持分类树与行内编辑；实例的每一步都会自动落成待办，可在任务页完成并自动推进。人工确认节点同样走独立小窗。

**外部任务源**：填一个返回 JSON 的 GET 接口即可同步任务；字段映射支持 JSON 路径（\`data.rows[0].attributes.name\`）；按 \`(source, id)\` 幂等 upsert，可按标题「认领」本地同名任务而不重复创建；可设自动同步间隔。

**AI 整理**（可选，需自备兼容 OpenAI / Anthropic / Gemini 的接口）：单篇整理与整库整理各有一份提示词，整库那份默认更克制（只规整排版、不重写句子）。

**其它**：图谱、回顾、闪念收件箱、番茄钟、桌面浮窗与托盘、主题包与强调色、应用内确认弹框（带图标）。

### 运行环境

Windows 10 / 11 x64。首次启动会在数据目录创建或迁移数据库；卸载不会删除你的数据。

### 校验

本版经过 162 项单测 + 一整套端到端回归（热键选词、条件确认窗、捕获窗、外部同步、模板分类、AI 链路等），并有一份 56 步的全功能冒烟脚本 \`scripts/seedmonitor.mjs\` 可在副本库上重复运行。

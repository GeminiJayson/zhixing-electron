## 知行 ZhiXing 1.23.0

本地优先的个人待办 + 知识图谱桌面端（Windows x64）。数据只存在本机的一只 SQLite 文件里：无需注册账号，不联网也能完整使用。

### 用户脚本成了知识库的一种**笔记类型**

此前脚本是磁盘目录里的一份文件，树上只有一个固定入口。这一版把它收进 `note` 表
（`format = 'script'`，运行环境存在私有列 `script_runtime`）—— 于是**打链、引用、属性、归属文件夹、
图谱**这些长在笔记上的能力全部自动生效：

- 树上它就是普通笔记项（同一个图标映射、同一个右键菜单、同样的钉住/重命名/移动）；
  「用户脚本」是一个普通的顶层文件夹，**可以改名、可以删、可以在它下面继续建子文件夹分类**。
- 编辑区的外壳与别的格式**完全一样**：标题栏三个胶囊（类型 / 语法状态 / 保存状态）、工具栏
  （多一个「检查语法」）、底部四栏信息区（属性 / 反向链接 / 正向引用 / 归属文件夹）。只有正文换成
  代码编辑器：等宽 + 行号 + 校验状态条，点某条问题跳到那一行。
- **运行环境可切换**（PowerShell / CMD 批处理 / Python / JavaScript (Node)）：运行时不是「笔记类型」，
  它随时可能改 —— 先写 PowerShell 试、要调 python 就换过去。切换即时入库并按新运行时重跑语法校验。
- 工作流的「用户脚本」动作改存 **note id**；旧模板里按文件名存的值仍兼容（走 `<数据目录>/scripts/`）。
- 图谱上脚本节点有自己的**终端图标**，图例单列一项「用户脚本」；任务的「关联笔记」也能选它。

### 番茄钟：开始时就调参数、能拖、能收起

- **设置面板**（页脚滑杆图标）四项：专注 / **休息间隔（每几个番茄）** / 短休息 / 长休息。
  改完立即写库，与设置页「任务与提醒」同名四项共用同一份；**还没跑起来的这一段**就地用上新值
  （已经跑了一半的不动 —— 时间突然跳变更莫名其妙）。数够休息间隔就进一次**长休息**，标题写明。
- **小窗可拖动**：标题栏即手柄；松手后位置被记住，下次发起专注回到原处（读回时会校验还在某个
  工作区内 —— 拔掉显示器后老坐标会把窗口丢到看不见的地方）。
- **可收起成悬浮表情上的倒计时**：页脚「收起」把小窗**隐藏**（不是关闭 —— 计时宿主在它里面），
  倒计时落到桌面浮窗上：球形态叠在悬浮表情下缘，卡片形态挂在标题行；点那行倒计时把窗口叫回来。
  隐藏时窗口不参与后台节流（否则每秒一次的计时会被压到约一分钟一次，倒计时当场失真）。

### 交互修复

- **弹窗里的下拉选完/点别处不消失**（两个叠加的原因）：弹窗为「点内部不关自己」在冒泡路上
  `stopPropagation`，而浮层的「点外部关闭」挂在冒泡阶段 → 收不到事件；改成**捕获阶段**。
  另一个是 `<label>` 的「点击即激活关联控件」默认行为会在选项 click 之后再合成一次针对触发器的
  点击 —— `stopPropagation` 挡不住默认行为，必须 `preventDefault`。两条都写进了 `docs/03` §9.0。
- 今日页习惯输入行铺满剩余宽度；快速添加任务的按钮补上 `+` 图标（与习惯那张卡一致）。
- 回顾页「任务用时」的条形铺满卡片（此前有条数上限与被标题列挤占的问题）。
- 图谱页节点详情卡片补上四周内边距（此前只写了底部留白，内容整排贴边）。
- 番茄钟页脚不再折行：次要动作收成纯图标，显式禁止折行。

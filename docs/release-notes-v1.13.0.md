## 知行 ZhiXing 1.13.0

本地优先的个人待办 + 知识图谱桌面端（Windows x64）。数据只存在本机的一只 SQLite 文件里：无需注册账号，不联网也能完整使用。

| 文件 | 说明 |

| **Zhixing-1.13.0-x64-portable.exe** | 便携版单文件：双击即用，不写注册表、不建快捷方式 |

### 全新的应用图标：一本书 + 一个对勾

图标重做了。寓意很直白：**摊开的书是「知」，书页上的对勾是「行」** —— 知行合一。

不是一块纯色：深墨渐变的圆角方底（带一圈极淡的内描边）→ 强调色三段渐变的书（左页两条文字线代表知识，右页压着粗对勾代表行动）→ 底部一层强调色光晕。缩到 16px 时仍有专门的**托盘版**（去掉文字线与光晕、书与勾都加粗），保证小尺寸下还认得出。

### 图标会跟着强调色变

窗口图标与托盘图标都跟随「设置 → 外观 → 强调色」：换成蓝色、品红、紫色…… 任务栏与托盘上的那本书就跟着换色。

- 8 个预设强调色各烘了一份窗口图标与托盘图标，换色时立即生效。
- 用色板之外的自定义色时，取最接近的预设（256px 的位图上这点色差看不出来）。
- 上一版托盘是「按主题包文字色单色重着色」的模板图，现在是完整的三层彩色图标。

### 两处限制（平台事实，不是没做）

1. **exe 自身的图标是静态资源** —— Windows 只在构建时读它，所以安装包与 exe 上固定是默认的「青竹」色；运行时跟随强调色的是窗口图标（任务栏）与托盘图标。
2. **macOS 的菜单栏图标仍用模板图** —— macOS 会按菜单栏明暗自动反色，彩色图标在那里反而是异类。

### 验证

- 类型检查（主进程 + 渲染层两个 tsconfig）、**419 项单元测试**全绿。
- 图标资源由 `npm run gen:app-icons` 从 `resources/icon.svg` 生成：ICO 含 16/24/32/48/64/128/256 七档，
  外加 8 个强调色 × 应用/托盘两形态。
- 运行时实测：改强调色后任务栏图标随之变色（青竹 → 蓝 → …）。
